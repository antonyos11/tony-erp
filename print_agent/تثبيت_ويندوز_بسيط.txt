📌 الطريقة الأولى (الأسهل):
═══════════════════════════════════════════════════════════════

1. اضغط دبل كليك على: install_simple.bat
2. انتظر حتى ينتهي التثبيت
3. بعدين اضغط دبل كليك على: run_windows.bat
4. خلاص! 🎉


📌 الطريقة الثانية (يدوي):
═══════════════════════════════════════════════════════════════

1. افتح Command Prompt (كمسؤول):
   - اضغط Windows + R
   - اكتب: cmd
   - اضغط Ctrl + Shift + Enter

2. روح للمجلد:
   cd C:\path\to\print_agent
   (غير المسار حسب مكان المجلد عندك)

3. ثبت المكتبات:
   pip install websockets pywin32 --user

4. إعداد pywin32:
   python -m pywin32_postinstall -install

5. شغل الخدمة:
   python agent_windows.py


📌 المكتبات المطلوبة فقط:
═══════════════════════════════════════════════════════════════

للويندوز تحتاج مكتبتين فقط:
✓ websockets  (للاتصال بالسيرفر)
✓ pywin32     (للطباعة على ويندوز)


📌 إذا واجهت مشكلة:
═══════════════════════════════════════════════════════════════

❌ المشكلة: Python غير مثبت
   ✅ الحل: حمل Python من https://www.python.org/downloads/
          ⚠️ مهم: اختر "Add Python to PATH"

❌ المشكلة: pip لا يعمل
   ✅ الحل: python -m pip install websockets pywin32 --user

❌ المشكلة: Permission denied
   ✅ الحل: شغل Command Prompt كمسؤول (Run as Administrator)

❌ المشكلة: pywin32 لا يعمل
   ✅ الحل: python -m pywin32_postinstall -install


📌 التحقق من التثبيت:
═══════════════════════════════════════════════════════════════

افتح Command Prompt واكتب:

python -c "import websockets; print('✓ websockets جاهز')"
python -c "import win32print; print('✓ pywin32 جاهز')"

إذا طلعت ✓ معناها كل شيء تمام!
