🖨️ خدمة الطباعة المباشرة

تثبيت خدمة الطباعة على جهازك المحلي

⚠️ تنبيه مهم: هذه الخدمة تعمل على جهازك الشخصي وتسمح للسيرفر بطلب الطباعة على طابعتك مباشرة.
1

📥 تحميل الملفات

اختر طريقة التحميل:
الطريقة الأسهل - حمّل كل الملفات دفعة واحدة:
📦 حمّل print_agent_windows.zip
بعد التحميل:
  • اضغط كليك يمين على الملف
  • اختر "Extract All..." أو "استخراج الكل"
  • اختر المسار:
    C:\TonyERP\
حمّل هذه الملفات من المسار: /print_agent/
  • agent_windows.py
  • run_windows.bat
  • install_simple.bat
  • test_print.html
  • requirements.txt
ثم ضعها في المجلد:
C:\TonyERP\print_agent_windows\
2

🔧 تثبيت المكتبات

شرط أساسي: Python يجب أن يكون مثبت على جهازك.
حمّل Python (عند التثبيت اختر: Add Python to PATH ✅)
فتح Command Prompt كـ Administrator:
  1. اضغط Win + R
  2. اكتب: cmd
  3. اضغط Ctrl + Shift + Enter (لتشغيله كـ Admin)
انتقل للمجلد:
cd C:\TonyERP\print_agent_windows
تحقق من Python:
python --version
ثبّت المكتبات:
pip install websockets pywin32 --user
إكمال تثبيت pywin32:
python -m pywin32_postinstall -install
✅ لا تقلق إذا رأيت رسائل - المهم ألا تكون هناك أخطاء حمراء
3

🚀 تشغيل الخدمة

شغّل هذا الملف:
C:\TonyERP\print_agent_windows\run_windows.bat
أو عن طريق Command Prompt:
python agent_windows.py
✅ ستظهر نافذة سوداء مع الرسالة:
WebSocket Server running on ws://localhost:9876
⚠️ مهم جداً: اترك هذه النافذة مفتوحة طول الوقت. إذا أغلقتها = الطباعة توقفت.
4

🧪 اختبار الطباعة

افتح هذا الملف في المتصفح (Chrome أو Edge):
C:\TonyERP\print_agent_windows\test_print.html
✅ يجب أن ترى:
  • "متصل بخدمة الطباعة" (أخضر)
  • اسم طابعتك الحرارية
  • زر "طباعة اختبارية"
اضغط على "طباعة اختبارية":
🖨️ طابعتك يجب أن تطبع استلام تجريبي الآن!
5

🌐 استخدام النظام

✅ الآن عندما تطبع من السيرفر (مثلاً فاتورة أو استلام):
  • السيرفر سيطلب الطباعة من جهازك تلقائياً
  • طابعتك ستطبع مباشرة بدون تدخل منك
  • لا داعي لفعل أي شيء إضافي

📋 ملخص الخطوات السريعة

1. حمّل: print_agent_windows.zip من الرابط أعلاه 2. استخرج إلى: C:\TonyERP\ 3. افتح Command Prompt كـ Admin 4. cd C:\TonyERP\print_agent_windows 5. pip install websockets pywin32 --user 6. python -m pywin32_postinstall -install 7. python agent_windows.py 8. افتح test_print.html واختبر
⚠️

حل المشاكل الشائعة

❌ "Python غير مثبت":
→ حمّل Python من: python.org
→ مهم: أثناء التثبيت اختر: ✅ "Add Python to PATH"
→ أعد تشغيل Command Prompt
❌ "لا توجد طابعات":
→ تأكد أن الطابعة موصولة (USB أو Network)
→ في Windows: Settings → Devices → Printers & Scanners
→ تأكد أنها ظاهرة في القائمة
→ إذا ظاهرة: أعد تشغيل run_windows.bat
❌ "خطأ pip install":
→ جرّب: python -m pip install --upgrade pip
→ ثم: python -m pip install websockets pywin32
