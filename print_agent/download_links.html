صفحة التحميل الرسمية

📋 خطوات التثبيت

الخطوة 1: تثبيت Python

1. حمّل Python من الرابط أعلاه

2. شغل الملف المحمل

3. ✅ اختر "Add Python to PATH"

4. اضغط "Install Now"

الخطوة 2: تثبيت المكتبات

افتح Command Prompt واكتب:

pip install websockets pywin32 --user

الخطوة 3: إعداد pywin32

python -m pywin32_postinstall -install

✅ أسهل طريقة

بعد تثبيت Python، فقط اضغط دبل كليك على:

run_windows.bat

سيثبت كل شيء تلقائياً!

⚡ أوامر سريعة

التحقق من Python

python --version

تثبيت المكتبات

pip install websockets pywin32 --user

تشغيل الخدمة

python agent_windows.py

اختبار المكتبات

python -c "import websockets; import win32print; print('✓ كل شيء تمام')"

🔧 حل المشاكل

المشكلة: 'python' is not recognized

الحل:

1. أعد تثبيت Python وتأكد من اختيار "Add Python to PATH"

2. أو أعد تشغيل الكمبيوتر

المشكلة: Permission denied

الحل:

شغل Command Prompt كمسؤول (Run as Administrator)

المشكلة: pip لا يعمل

الحل:

python -m pip install websockets pywin32 --user
