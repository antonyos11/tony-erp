Google
  1. اذهب إلى Google Cloud Console
  2. أنشئ مشروع جديد أو اختر مشروعاً موجوداً
  3. اذهب إلى APIs & Services → Credentials
  4. أنشئ OAuth 2.0 Client ID
  5. أضف Redirect URI: {{ request.scheme }}://{{ request.get_host }}/store/auth/google/callback/
  6. انسخ Client ID و Client Secret
Facebook
  1. اذهب إلى Facebook Developers
  2. أنشئ تطبيق جديد (Consumer type)
  3. اذهب إلى Settings → Basic
  4. أضف Valid OAuth Redirect URI
  5. انسخ App ID و App Secret

  2. أنشئ تطبيق جديد
  3. فعّل OAuth 2.0
  4. أضف Callback URL
  5. انسخ Client ID و Client Secret
