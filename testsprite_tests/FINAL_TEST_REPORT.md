### 3. TC003 - المحاسبة والقيود
**الحالة:** ❌ **فشل**  
**الخطأ:** `404 Not Found` - نقطة النهاية غير موجودة  
**السبب:** وحدة المحاسبة قد لا تحتوي على REST API

**الحل المقترح:**

- أو قد تكون المحاسبة Web-only وليست REST API
- يحتاج لتحقق يدوي من البنية

### 4. TC006 - نقاط البيع (POS)
