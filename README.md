## حل المشاكل

### المشكلة: لا يمكن الوصول من أجهزة أخرى
**الحل:**
1. تأكد من الاتصال بنفس الواي فاي
2. تحقق من إعدادات الجدار الناري
3. جرب IP address بدلاً من hostname

### المشكلة: النظام بطيء
**الحل:**
1. أعد تشغيل جهاز الخادم
2. تحقق من قوة الواي فاي
3. قلل عدد المستخدمين المتزامنين

### المشكلة: خطأ في قاعدة البيانات
**الحل:**
1. استخدم النسخة الاحتياطية من مجلد `backups/`
2. شغل: `python manage.py migrate`

## حالة التكامل المستمر (CI)

يتم تشغيل خط تجميع آلي (Workflow) عند كل دفع (push) وطلب دمج (Pull Request) ويتضمن:
- فحص منع الإيموجي `tools/check_no_emojis.py`
- فحص صحة Django (system check) وفحص المهاجرات
- تنسيق وجودة الشيفرة (Black / isort / Flake8 / mypy جزئي)
- تشغيل الاختبارات مع تغطية واختبار حد أدنى للتغطية ورفع تقرير HTML كأرتيفاكت
- فحص النصوص غير المترجمة في القوالب `tools/scan_untranslated_templates.py`
- فحص النصوص العربية غير المترجمة في ملفات بايثون `tools/scan_untranslated_python_strings.py`
- تدقيق أمان أولي (safety / pip-audit / Bandit)

لتفعيل الشارة أعلاه استبدل `OWNER/REPO` بالمسار الفعلي للمستودع.

لإضافة شارة تغطية (Coverage) مستقبلًا يمكن استخدام Codecov أو Coveralls بعد رفع التقارير وإضافة خطوة رفع token.

## سياسة النصوص (منع الإيموجي)

لضمان التوافق مع محطات Windows القديمة (cp1252) ومنع أخطاء UnicodeEncodeError:
- يمنع استخدام الإيموجي والرموز الزخرفية في الشيفرة والمخرجات.
- استخدم نص عربي بسيط أو علامات قياسية مثل - أو * عند الحاجة لقوائم.
- تم إضافة فحص آلي في `tools/check_no_emojis.py`.
- للتشغيل اليدوي:

```bash
python tools/check_no_emojis.py
```

### تفعيل فحص ما قبل الالتزام (Git pre-commit)

```bash
git config core.hooksPath .githooks
```

يمكن تخطي بعض الفحوص عبر متغيرات بيئة (للحالات الطارئة فقط):
- `SKIP_EMOJI=1` لتخطي فحص الإيموجي
- `SKIP_DJANGO_CHECK=1` لتخطي `manage.py check`
- `SKIP_I18N=1` لتخطي فحص وترجمة الرسائل
- `STRICT_I18N=1` لتفعيل الوضع الصارم في فحص النصوص العربية داخل الشيفرة البايثونية (بدون هذا المتغير يكون تحذيري فقط)

يُفضل عدم التخطي إلا عند الضرورة.
