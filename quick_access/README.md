# 🚀 نظام الوصول السريع - Quick Access System

## نظرة عامة

نظام الوصول السريع هو مجموعة شاملة من الأدوات والميزات المصممة لتحسين تجربة المستخدم وتوفير الوقت وزيادة الإنتاجية في نظام Tony ERP.

---

## ✨ الميزات الرئيسية

### 1. 🎯 لوحة التحكم الموحدة
لوحة تحكم مركزية توفر وصولاً سريعاً لجميع المهام والإجراءات الشائعة.

**المسار:** `/quick/`

**المميزات:**
- إحصائيات سريعة (مبيعات، مشتريات، مخزون منخفض)
- إجراءات سريعة منظمة حسب الفئة
- التقارير الأكثر استخداماً
- واجهة حديثة وسهلة الاستخدام

### 2. 🔍 البحث الشامل الذكي
بحث موحد عبر جميع أنحاء النظام بنتائج فورية.

**الاختصار:** `Ctrl + K`

**يبحث في:**
- المنتجات (الاسم، الكود، الباركود)
- الفواتير (رقم الفاتورة، اسم العميل)
- العملاء المحتملين (الاسم، البريد، الهاتف)
- الموظفين (الاسم، رقم الموظف)
- وأكثر...

### 3. ⌨️ اختصارات لوحة المفاتيح
مجموعة شاملة من اختصارات لوحة المفاتيح لتسريع العمل.

**المسار:** `/quick/shortcuts/`
**الاختصار:** `Ctrl + /`

**أمثلة على الاختصارات:**
- `Ctrl + Shift + I` - فاتورة مبيعات جديدة
- `Ctrl + Shift + P` - فاتورة مشتريات جديدة
- `Ctrl + Shift + N` - منتج جديد
- `Ctrl + Shift + J` - قيد محاسبي جديد
- `Alt + A + C` - دليل الحسابات
- `Alt + R + S` - تقرير المبيعات

### 4. ⚡ العمليات الجماعية
تنفيذ إجراءات على سجلات متعددة في وقت واحد.

**المسار:** `/quick/bulk-actions/`

**العمليات المتاحة:**
- تحديث أسعار المنتجات بالجملة
- تحديث كميات المخزون
- إرسال رسائل بريد إلكتروني جماعية
- تصدير بيانات متعددة
- حذف سجلات متعددة (بحذر!)

**الفوائد:**
- توفير الوقت بشكل كبير
- تقليل الأخطاء اليدوية
- سجل كامل لجميع العمليات
- إمكانية التراجع والمراجعة

### 5. 📊 التقارير المتكررة والمجدولة
تتبع التقارير الأكثر استخداماً وجدولتها للإرسال التلقائي.

**الميزات:**
- تتبع تلقائي للتقارير المستخدمة
- جدولة التقارير (يومي، أسبوعي، شهري)
- إرسال تلقائي عبر البريد الإلكتروني
- حفظ معاملات التقارير المفضلة

### 6. 🎨 تخصيص تفضيلات المستخدم
كل مستخدم يمكنه تخصيص تجربته.

**الخيارات المتاحة:**
- وضع العرض (شبكة، قائمة، مضغوط)
- السمة (فاتح، داكن، تلقائي)
- القائمة الجانبية (ممتدة/مطوية)
- الإشعارات (مفعلة/معطلة)
- الاختصارات المفضلة
- Widgets لوحة التحكم

## 🚀 التثبيت والإعداد

### 1. الهجرة (Migration)

```bash
python manage.py makemigrations quick_access
python manage.py migrate quick_access
```

### 2. إضافة الإجراءات السريعة الافتراضية

```bash
python manage.py setup_quick_actions
```

هذا الأمر سيقوم بإضافة جميع الإجراءات السريعة الافتراضية للنظام (35+ إجراء).

### 3. إعداد Celery (للتقارير المجدولة) - اختياري

```bash
celery -A accountant_pro worker -l info
celery -A accountant_pro beat -l info
```

## 📖 كيفية الاستخدام

### للمستخدمين النهائيين

1. **الوصول للوحة التحكم:**
   - انتقل إلى `/quick/` أو انقر على أيقونة البرق في القائمة

2. **استخدام البحث السريع:**
   - اضغط `Ctrl + K` من أي مكان
   - ابدأ بكتابة ما تبحث عنه
   - انقر على النتيجة للانتقال إليها

3. **تعلم الاختصارات:**
   - اضغط `Ctrl + /` لعرض دليل الاختصارات
   - مارس الاختصارات الأكثر استخداماً

4. **العمليات الجماعية:**
   - انتقل إلى `/quick/bulk-actions/`
   - اختر العملية المطلوبة
   - أدخل المعاملات والسجلات
   - نفذ العملية

### للمطورين

#### إضافة إجراء سريع جديد

```python
from quick_access.models import QuickAction

QuickAction.objects.create(
    name='إجراء جديد',
    name_en='New Action',
    description='وصف الإجراء',
    icon='bi-star',  # أيقونة Bootstrap Icons
    url='/path/to/action/',
    category='sales',  # sales, purchases, inventory, etc.
    color='#3b82f6',
    keyboard_shortcut='Ctrl+Shift+X',
    permission_required='app.permission_name',
    sort_order=1
)
```

#### تتبع استخدام تقرير

```javascript
// في صفحة التقرير
fetch('/quick/track/report/', {
    method: 'POST',
    headers: {
        'X-CSRFToken': csrfToken,
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        report_name: 'تقرير المبيعات الشهري',
        report_url: window.location.pathname,
        report_type: 'sales',
        parameters: { month: '2026-01', branch: 1 }
    })
});
```

#### إنشاء عملية جماعية مخصصة

في `views.py`:

```python
@login_required
@require_http_methods(["POST"])
def execute_custom_bulk_action(request):
    data = json.loads(request.body)
    action_type = data.get('action_type')
    target_ids = data.get('target_ids', [])
    
    # منطق العملية
    success_count = 0
    error_count = 0
    
    for id in target_ids:
        try:
            # تنفيذ الإجراء
            success_count += 1
        except Exception as e:
            error_count += 1
    
    # سجل العملية
    BulkActionHistory.objects.create(
        user=request.user,
        action_type=action_type,
        affected_count=len(target_ids),
        success_count=success_count,
        error_count=error_count
    )
    
    return JsonResponse({
        'success': True,
        'success_count': success_count,
        'error_count': error_count
    })
```
