# شجرة الحسابات الافتراضية - نشاط مختلط (تجاري + خدمي + تصنيعي)

## 📋 نظرة عامة

شجرة حسابات شاملة مصممة خصيصًا للمنشآت ذات **النشاط المختلط** (تجاري + خدمي + تصنيعي)، مع **4 مستويات فقط** للتبسيط والوضوح.

---

## 🌳 البنية الهرمية

```
المستوى 1: الحساب الرئيسي (5 حسابات)
    └─ المستوى 2: الحساب الفرعي الأول (20-25 حساب)
        └─ المستوى 3: الحساب الفرعي الثاني (40-50 حساب)
            └─ المستوى 4: الحساب التفصيلي (100+ حساب)
```

## 📊 ملخص الشجرة

| المستوى | عدد الحسابات |
|---------|--------------|
| المستوى 1 (رئيسي) | 5 حسابات |
| المستوى 2 (فرعي أول) | ~25 حساب |
| المستوى 3 (فرعي ثاني) | ~60 حساب |
| المستوى 4 (تفصيلي) | ~150 حساب |
| **الإجمالي** | **~240 حساب** |

## 🎯 مبادئ الترميز

### نظام الترميز المستخدم:
```
X.Y.Z.NNN
│ │ │  └─ رقم تسلسلي (001-999)
│ │ └──── فئة فرعية ثانية (1-9)
│ └────── فئة فرعية أولى (1-9)
└──────── المجموعة الرئيسية (1-5)
```

### أمثلة:
- `1.1.1.001` = أصول > أصول متداولة > نقدية وبنوك > الخزينة الرئيسية
- `4.1.1.002` = إيرادات > إيرادات رئيسية > مبيعات تجارية > مبيعات آجل
- `5.2.1.003` = مصروفات > تشغيلية > بيع وتسويق > دعاية وإعلان

## 🔧 كود Python لإنشاء الشجرة

```python
# accounting/management/commands/create_default_coa.py

from django.core.management.base import BaseCommand
from accounting.models import Account, AccountType


class Command(BaseCommand):
    help = 'إنشاء شجرة حسابات افتراضية للنشاط المختلط'
    
    def handle(self, *args, **options):
        """إنشاء شجرة الحسابات الافتراضية"""
        
        self.stdout.write(self.style.SUCCESS('🌳 بدء إنشاء شجرة الحسابات...'))
        
        # 1. الأصول
        assets = self.create_account_tree({
            'code': '1',
            'name': 'الأصول',
            'type': AccountType.ASSET,
            'is_group': True,
            'children': [
                {
                    'code': '1.1',
                    'name': 'الأصول المتداولة',
                    'is_group': True,

        """إنشاء شجرة الحسابات بشكل تكراري"""
        account = Account.objects.create(
            code=data['code'],
            name=data['name'],
            account_type=data.get('type', parent.account_type if parent else None),
            parent=parent,
            is_group=data.get('is_group', False),
            can_post=data.get('can_post', False),
            description=data.get('description', ''),
        )
        
        for child_data in data.get('children', []):
            self.create_account_tree(child_data, account)
        
        return account
```
