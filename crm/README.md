# نظام إدارة علاقات العملاء (CRM)

## 📋 نظرة عامة

نظام CRM متكامل لإدارة علاقات العملاء، الفرص التجارية، الأنشطة، عروض الأسعار، تذاكر الدعم، والحملات التسويقية.

## 🎯 الميزات الرئيسية

### 1. إدارة العملاء
- إنشاء وتعديل بيانات العملاء
- تصنيف العملاء حسب النوع والمصدر
- إدارة جهات الاتصال
- تتبع حالة العميل (نشط، غير نشط، محتمل)
- البحث المتقدم في بيانات العملاء

### 2. إدارة الفرص التجارية
- تتبع الفرص التجارية من البداية للنهاية
- مراحل الفرصة قابلة للتخصيص
- تعيين الفرص للموظفين
- حساب احتمالية النجاح
- تتبع القيمة المتوقعة

### 3. إدارة الأنشطة
- جدولة المكالمات والاجتماعات
- تتبع المهام والمتابعات
- إرسال رسائل البريد الإلكتروني
- تسجيل الملاحظات
- التذكيرات التلقائية

### 4. عروض الأسعار
- إنشاء عروض أسعار احترافية
- إضافة منتجات وخدمات
- حساب الضرائب والخصومات
- تحويل العروض إلى فواتير
- طباعة وإرسال العروض

### 5. تذاكر الدعم
- استقبال وإدارة طلبات الدعم
- تصنيف التذاكر حسب الأولوية
- تعيين التذاكر للموظفين
- تتبع حالة التذكرة
- إضافة تعليقات ومرفقات

### 6. الحملات التسويقية
- إنشاء وإدارة الحملات
- تتبع الاستجابات
- قياس نجاح الحملات
- ربط العملاء بالحملات

### 7. نظام العمولات
- حساب عمولات الموظفين تلقائياً
- مخططات عمولات مرنة
- ربط مع نظام المحاسبة
- تقارير العمولات

## 🔧 التكامل مع الأنظمة الأخرى

### المبيعات
- تحويل عروض الأسعار إلى فواتير
- مشاركة بيانات العملاء
- ربط الفرص بالمبيعات

### المحاسبة
- تسجيل العمولات كمصروفات
- ربط مع حسابات الموظفين
- القيود المحاسبية التلقائية

### المخزون
- ربط المنتجات في عروض الأسعار
- التحقق من التوفر
- حساب الأسعار

### الموارد البشرية
- ربط الموظفين بالفرص
- حساب العمولات
- تقارير الأداء

## 🚀 الاستخدام

### إنشاء عميل جديد
```python
from crm.models import Customer, CustomerType

customer = Customer.objects.create(
    first_name='أحمد',
    last_name='محمد',
    email='ahmed@example.com',
    phone='0123456789',
    customer_type=CustomerType.objects.get(name='عميل محتمل')
)
```

### إنشاء فرصة تجارية
```python
from crm.models import Opportunity, OpportunityStage

opportunity = Opportunity.objects.create(
    name='فرصة بيع سيارة',
    customer=customer,
    stage=OpportunityStage.objects.get(name='مؤهل'),
    expected_value=100000,
    probability=50
)
```
