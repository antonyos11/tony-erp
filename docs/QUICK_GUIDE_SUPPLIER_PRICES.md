# 📖 دليل سريع: إدارة أسعار الموردين

## 📍 كيفية الوصول

### الطريقة الأولى: من القائمة الرئيسية ⭐

```
القائمة الجانبية → المشتريات → التقارير → أسعار المواد الخام لكل مورد
```

### الطريقة الثانية: الرابط المباشر

```
/purchases/material-prices/
```

---

## 📋 ماذا ستجد في الصفحة؟

### 1. قائمة الموردين
- عرض جميع الموردين
- عدد المنتجات لكل مورد
- معلومات الاتصال (الهاتف)

### 2. أسعار المواد لكل مورد
لكل مورد، ستجد جدول يحتوي على:

| العمود | الوصف |
|--------|-------|
| **المنتج** | اسم المادة الخام |
| **الفئة** | فئة المنتج |
| **التكلفة** | السعر بالجنيه |
| **وحدة الشراء** | متر مكعب، كيلو، متر، إلخ |
| **الحد الأدنى** | الحد الأدنى للطلب |
| **مدة التوريد** | عدد الأيام |
| **الحالة** | نشط / غير نشط |
| **تاريخ السريان** | تاريخ بدء السعر |
| **إجراءات** | تعديل / حذف |

### 3. إحصائيات
- متوسط السعر
- أقل سعر
- أعلى سعر

---

## ➕ إضافة سعر جديد

### الخطوات:

1. **اضغط على زر "➕ إضافة سعر جديد"** (في أعلى الصفحة)

2. **املأ النموذج**:
   - **المادة الخام**: اختر من القائمة (مثل: إسفنج كثافة 25)
   - **المورد**: اختر المورد (مثل: شركة الإسفنج المصري)
   - **السعر**: أدخل السعر الجديد (مثل: 5000)
   - **العملة**: EGP (افتراضي)
   - **الحد الأدنى للطلب**: اختياري
   - **مدة التوريد**: اختياري (بالأيام)
   - **تاريخ السريان**: تاريخ بدء السعر
   - **نشط**: ✅ (افتراضي)

3. **ستظهر لك معلومات إضافية**:
   - 📦 **وحدة الشراء**: (مثل: متر مكعب)
   - 💰 **السعر الحالي**: (للمقارنة)

4. **اضغط "💾 حفظ"**

### النتيجة:
```
✅ تم إضافة السعر بنجاح: إسفنج كثافة 25 من شركة الإسفنج المصري
| تم تحديث 15 وحدة تعبئة تلقائياً
```

---

## ✏️ تعديل سعر موجود

### الخطوات:

1. **ابحث عن المورد والمنتج** في القائمة
2. **اضغط على زر "✏️ تعديل"** بجانب السعر
3. **عدّل السعر** أو أي معلومات أخرى
4. **اضغط "💾 حفظ"**

### النتيجة:
```
✅ تم تحديث السعر بنجاح: إسفنج كثافة 25 (من 4200 إلى 5000)
| تم تحديث 15 وحدة تعبئة تلقائياً
```

---

## 🔄 التحديث التلقائي

### ماذا يحدث عند إضافة أو تعديل سعر؟

1. ✅ **تحديث سعر المنتج الأساسي** (`Product.cost`)
2. ✅ **تحديث جميع وحدات التعبئة** (الألواح) تلقائياً
3. ✅ **تسجيل التغييرات** في الـ Logs
4. ✅ **عرض رسالة نجاح** مع عدد الوحدات المحدثة

### مثال:
عند تحديث سعر **إسفنج كثافة 25** من **4200** إلى **5000** جنيه/م³:

- ✅ تم تحديث سعر المادة الخام
- ✅ تم تحديث **15 لوح** تلقائياً:
  - لوح 200×90×10: من 756 إلى 900 جنيه
  - لوح 200×120×10: من 1008 إلى 1200 جنيه
  - لوح 200×140×10: من 1176 إلى 1400 جنيه
  - ... وهكذا

## 🔍 البحث والفلترة

### الفلاتر المتاحة:

1. **حسب المورد**: اختر مورد معين لعرض أسعاره فقط
2. **حسب الحالة**: نشط / غير نشط
3. **حسب المنتج**: ابحث عن منتج معين

---

## 💡 نصائح مهمة

### ✅ أفضل الممارسات:

1. **تحديث الأسعار بانتظام** للحفاظ على دقة التكاليف
2. **استخدام تاريخ السريان** لتتبع متى بدأ السعر الجديد
3. **إضافة الحد الأدنى للطلب** لتجنب الطلبات الصغيرة
4. **تحديد مدة التوريد** للتخطيط الأفضل
5. **مراجعة الرسائل** بعد الحفظ للتأكد من التحديثات

### ⚠️ تحذيرات:

1. **تأكد من السعر** قبل الحفظ (سيتم تحديث جميع الألواح!)
2. **راجع وحدة الشراء** للتأكد من إدخال السعر الصحيح
3. **لا تحذف الأسعار القديمة** - بدلاً من ذلك، اجعلها غير نشطة

---

## 📊 التقارير المتاحة

من نفس القسم (المشتريات → التقارير):

1. **أسعار المواد الخام لكل مورد** ← أنت هنا
2. **مقارنة الأسعار** - مقارنة أسعار نفس المنتج من موردين مختلفين
3. **أداء الموردين** - تقييم أداء الموردين
4. **تاريخ الأسعار** - تتبع تغييرات الأسعار عبر الزمن

---

## 🆘 المساعدة

### إذا واجهت مشكلة:

1. **تحقق من الصلاحيات**: هل لديك صلاحية "المشتريات"؟
2. **راجع الـ Logs**: للتأكد من التحديثات
3. **تواصل مع الدعم**: للمساعدة الفنية

---

## 📝 ملاحظات إضافية

- النظام يدعم **موردين متعددين** لنفس المنتج
- يمكنك تحديد **مورد مفضل** لكل منتج
- الأسعار تُحفظ بـ **العملة المحلية** (EGP) افتراضياً
- يمكنك **تصدير البيانات** للإكسل (قريباً)
