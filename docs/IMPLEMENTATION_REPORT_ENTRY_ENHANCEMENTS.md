## 🚀 خطوات النشر

### 1. تجميع الملفات الثابتة (Static Files)
```bash
cd /var/www/tony_erp
python manage.py collectstatic --noinput
```

### 2. إعادة تشغيل الخادم
```bash
# إذا كنت تستخدم Gunicorn
sudo systemctl restart gunicorn

# أو إذا كنت تستخدم Development Server
python manage.py runserver
```

### 3. مسح الكاش (اختياري)
```bash
python manage.py clear_cache
```

### 4. اختبار في المتصفح
1. افتح `/accounting/entries/revenue/create/`
2. اختبر كل ميزة واحدة تلو الأخرى
3. تحقق من وحدة تحكم المتصفح (F12) للأخطاء
