## 💾 قاعدة البيانات

### الجداول الجديدة:
```sql
hr_employeeloan:
├── id (PK)
├── loan_number (UNIQUE)
├── employee_id (FK)
├── amount, monthly_installment
├── paid_amount, remaining_amount
├── status, is_emergency
├── approved_by_id, approved_at
├── request_date, start_deduction_date
└── journal_entry_id (FK)

hr_loaninstallment:
├── id (PK)
├── loan_id (FK)
├── installment_number
├── amount, due_date
├── status
├── deduction_date
├── payroll_id (FK)
├── deferred_to_date
└── deferment_reason
```

### الفهارس:
```
✓ (employee_id, status)  - للبحث السريع
✓ loan_number             - للبحث بالرقم
✓ status                  - للفلترة
✓ (loan_id, status)       - للأقساط المعلقة
✓ due_date                - للأقساط المستحقة
```

## 🔄 سير العمل (Workflow)

### 1. طلب السلفة
```
الموظف يملأ النموذج
    ↓
النظام ينشئ السلفة (رقم فريد)
    ↓
يتم إنشاء الأقساط تلقائياً
    ↓
الحالة: pending (معلقة)
```

### 2. الموافقة
```
المدير يراجع الطلب
    ↓
يوافق أو يرفض
    ↓
إذا موافقة: الحالة = approved
    ↓
جاهزة للخصم من الراتب
```

### 3. الخصم الشهري
```
حساب راتب الموظف
    ↓
يبحث عن أقساط مستحقة
    ↓
يضيفها للخصومات
    ↓
يحدّث paid_amount
    ↓
إذا انتهت السلفة: الحالة = completed
```
