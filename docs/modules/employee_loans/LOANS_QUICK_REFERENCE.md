## 👤 للموظفين / For Employees

### تقديم طلب سلفة:
1. اذهب إلى: **الموارد البشرية → طلب سلفة جديدة**
2. املأ البيانات:
   - المبلغ المطلوب
   - عدد الأقساط (شهور)
   - السبب
   - تاريخ بدء الخصم
   - ☑️ سلفة طارئة (اختياري)
3. اضغط **تقديم الطلب**
4. انتظر الموافقة من الإدارة

### عرض سلفي:
- **الموارد البشرية → سلفي**
- ستجد:
  - إجمالي السلف
  - السلف النشطة
  - المبالغ المدفوعة والمتبقية
  - تفاصيل كل سلفة

### تأجيل قسط:
1. افتح تفاصيل السلفة
2. بجانب القسط المعلق، اضغط زر **التأجيل** (⏩)
3. اختر التاريخ الجديد
4. اكتب السبب
5. اضغط **تأجيل القسط**

---

## 👔 للمديرين / For Managers

### الموافقة على السلف:
1. **الموارد البشرية → إدارة السلف**
2. في قسم "سلف معلقة للموافقة"، اضغط **موافقة**
3. اختر:
   - ✅ **الموافقة** - يتم إنشاء الأقساط تلقائياً
   - ❌ **الرفض** - اكتب سبب الرفض
4. اضغط **حفظ القرار**

### عرض جميع السلف:
- **الموارد البشرية → قائمة السلف**
- يمكنك:
  - 🔍 البحث بالاسم أو رقم السلفة
  - 🎯 الفلترة بالحالة (معلقة، نشطة، مسددة)
  - 📂 الفلترة بالقسم
  - 👁️ عرض تفاصيل أي سلفة

### كشف الراتب الشامل:
1. **الموارد البشرية → كشف الراتب الشامل**
2. اختر:
   - تاريخ البداية والنهاية
   - القسم (اختياري)
   - ☑️ عرض التفاصيل الكاملة
3. اضغط **عرض الكشف** أو **تصدير PDF**
4. الكشف يشمل:
   - الراتب الأساسي
   - البدلات
   - الخصومات
   - **خصم السلف** (عمود منفصل)
   - الراتب الصافي

## 📊 الحالات / Status Flow

```
طلب جديد → معلقة (pending)
            ↓ موافقة
         معتمدة (approved)
            ↓ بدء الخصم
          نشطة (active)
            ↓ سداد كامل
         مسددة (completed)
         
         (يمكن الرفض في أي وقت → rejected)
```

---

## 🎯 حالات الأقساط / Installment Status

- **معلق (pending)** - لم يُخصم بعد
- **مخصوم (deducted)** - تم خصمه من الراتب
- **مؤجل (deferred)** - تم تأجيله لشهر آخر
- **معفي (waived)** - تم الإعفاء منه
- **متأخر** - معلق وتجاوز تاريخ الاستحقاق

## 🧮 الحسابات التلقائية / Auto Calculations

عند إنشاء سلفة بمبلغ **1000 ر.ع** و**10 أقساط**:

```
القسط الشهري = 1000 ÷ 10 = 100 ر.ع
```

عند الخصم:
```
المدفوع = مجموع الأقساط المخصومة
المتبقي = المبلغ الأصلي - المدفوع
النسبة = (المدفوع ÷ المبلغ الأصلي) × 100%
```
