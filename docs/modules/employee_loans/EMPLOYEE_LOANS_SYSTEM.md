# نظام إدارة سلف الموظفين 💰

## نظرة عامة
تم إضافة نظام متكامل لإدارة سلف الموظفين (Employee Loans) يتيح للموارد البشرية:
- تقديم وإدارة طلبات السلف من الموظفين
- تحديد خطة سداد بالأقساط الشهرية
- الخصم التلقائي من الرواتب الشهرية
- تأجيل الأقساط عند الحاجة
- طباعة كشف راتب شامل لجميع الموظفين مع كل التفاصيل

---

## المميزات الرئيسية

### 1️⃣ إدارة طلبات السلف
- **طلب سلفة جديدة**: يمكن للموظفين أو المدراء تقديم طلب سلفة
  - تحديد المبلغ المطلوب
  - توضيح السبب
  - اختيار عدد الأقساط (من 1 شهر إلى 12 شهر)
  - تحديد تاريخ بدء الخصم
  - وسم السلفة كطارئة إذا لزم الأمر

- **الموافقة/الرفض**: يمكن للمديرين أو الموارد البشرية:
  - الموافقة على السلفة
  - رفض السلفة مع توضيح السبب

### 2️⃣ إدارة الأقساط الشهرية
- **توليد الأقساط التلقائي**: عند الموافقة على السلفة، يتم:
  - حساب القسط الشهري (إجمالي المبلغ ÷ عدد الشهور)
  - إنشاء سجل لكل قسط مع تاريخ استحقاق محدد

- **الخصم من الراتب**: عند حساب راتب الموظف:
  - يتم البحث عن الأقساط المستحقة للشهر الحالي
  - الخصم التلقائي من الراتب الإجمالي
  - تسجيل القسط كمخصوم وربطه برقم الراتب

- **تأجيل الأقساط**: يمكن تأجيل قسط معين:
  - اختيار تاريخ جديد للاستحقاق
  - توضيح سبب التأجيل

### 3️⃣ تقارير ومتابعة
- **لوحة التحكم**:
  - إجمالي السلف النشطة
  - إجمالي المبالغ المدفوعة والمتبقية
  - قائمة بآخر السلف
  - السلف المعلقة للموافقة

- **سجل السلف**:
  - عرض جميع السلف بحالاتها المختلفة
  - فلترة حسب الحالة أو الموظف

- **كشف الراتب الشامل**:
  - طباعة تقرير شامل لجميع الموظفين
  - يتضمن: الراتب الأساسي، البدلات، الساعات الإضافية، المكافآت، الخصومات (بما فيها السلف)
  - يمكن تصفيته حسب الفترة والقسم
  - توفير خيارات PDF و HTML

## الجداول والنماذج

### نموذج EmployeeLoan (السلفة)
```
- loan_number: رقم السلفة (يتم توليده تلقائياً مثل: LOAN-202501-0001)
- employee: الموظف المستفيد
- amount: مبلغ السلفة
- reason: سبب طلب السلفة
- request_date: تاريخ التقديم (تلقائي)
- installments_count: عدد الأقساط (1-12 شهر)
- monthly_installment: مبلغ القسط الشهري (يحسب تلقائياً)
- start_deduction_date: تاريخ بدء الخصم
- paid_amount: المبلغ المدفوع
- remaining_amount: المبلغ المتبقي
- status: الحالة (pending, approved, rejected, active, completed, cancelled)
- approved_by: اسم المعتمد
- approved_at: تاريخ الاعتماد
- rejection_reason: سبب الرفض (إن وجد)
- journal_entry: ربط بالقيد المحاسبي
- is_emergency: هل هي سلفة طارئة
- notes: ملاحظات
```

### نموذج LoanInstallment (القسط)
```
- loan: السلفة المرتبطة
- installment_number: رقم القسط
- amount: مبلغ القسط
- due_date: تاريخ الاستحقاق
- status: الحالة (pending, deducted, deferred, waived)
- deduction_date: تاريخ الخصم من الراتب
- payroll: ربط بسجل الراتب
- deferred_to_date: التاريخ الجديد عند التأجيل
- deferment_reason: سبب التأجيل
- notes: ملاحظات
```

## التكامل مع نظام الرواتب

### الخصم التلقائي
عند حساب راتب الموظف شهرياً:
1. يتم البحث عن الأقساط المستحقة في شهر الراتب
2. يتم حساب مجموع الخصم من السلف
3. يضاف الخصم إلى `other_deductions` في سجل الراتب
4. يتم تحديث حالة القسط إلى `deducted`
5. يتم ربط القسط برقم الراتب

### الصيغة الحسابية
```
Net Salary = Gross Salary - (Late Penalties + Absence Deductions + Loan Installments)
```

## أمثلة عملية

### مثال 1: طلب وسداد سلفة

**خطوات:**
1. تقديم طلب سلفة:
   - الموظف: أحمد محمد
   - المبلغ: 3,000 ج.م
   - السبب: احتياجات طبية طارئة
   - عدد الأقساط: 3 شهور
   - تاريخ البدء: 2026-02-01

2. المدير يوافق على السلفة

3. النظام ينشئ 3 أقساط:
   - قسط 1: 1,000 ج.م - استحقاق 2026-02-28
   - قسط 2: 1,000 ج.م - استحقاق 2026-03-31
   - قسط 3: 1,000 ج.م - استحقاق 2026-04-30

4. عند حساب راتب فبراير:
   - يتم خصم 1,000 ج.م من الراتب تلقائياً
   - يتم تسجيل القسط كمخصوم

5. كل شهر يتم خصم القسط حتى تسديد كامل المبلغ

### مثال 2: تأجيل قسط

إذا لم يتمكن الموظف من السداد في الموعد المحدد:
1. يطلب تأجيل القسط
2. يحدد التاريخ الجديد للسداد (مثلاً: 2026-05-15)
3. النظام يحفظ التأجيل ويغير حالة القسط إلى `deferred`
4. في التاريخ الجديد سيتم الخصم
