# دليل الاستخدام السريع: نظام السلف 🚀

## البدء السريع

### للموظف: تقديم طلب سلفة

1. **الذهاب لصفحة الطلب**
   ```
   /hr/loans/request/
   ```

2. **ملء النموذج**
   - اختر اسمك (أو سيكون محدد مسبقاً إذا كنت موظفاً)
   - أدخل المبلغ المطلوب
   - اكتب سبب الطلب (مثل: احتياجات طبية، ضروريات شخصية)
   - حدد عدد الأقساط (كم شهر تريد تسديدها)
   - اختر تاريخ البدء (متى يبدأ الخصم)
   - ضع علامة "سلفة طارئة" إذا كانت حالة طوارئ

3. **اضغط "تقديم"**
   - سيتم إنشاء رقم سلفة فريد
   - سيتم إنشاء الأقساط تلقائياً
   - حالتك ستكون "معلقة" حتى الموافقة

---

### للمدير: الموافقة على السلفة

1. **الذهاب لقائمة السلف**
   ```
   /hr/loans/list/
   ```

2. **اختر السلفة المعلقة**
   - ابحث عن الحالة "معلقة"
   - اضغط على السلفة

3. **الموافقة أو الرفض**
   ```
   /hr/loans/<id>/approve/
   ```
   
   - إذا وافقت: اضغط "الموافقة"
   - إذا رفضت: اختر "الرفض" واكتب السبب

4. **التأكيد**
   - بعد الموافقة، ستصبح السلفة "نشطة"
   - ستكون جاهزة للخصم من راتب الشهر القادم

---

### للموارد البشرية: متابعة الرواتب

1. **الذهاب لكشف الراتب الشامل**
   ```
   /hr/payroll/comprehensive-report/
   ```

2. **اختر الفترة والقسم**
   - من تاريخ: (مثل: 2026-02-01)
   - إلى تاريخ: (مثل: 2026-02-28)
   - القسم: (اختياري - اختر قسماً معيناً أو "جميع الأقسام")

3. **اضغط "عرض" أو "طباعة PDF"**
   - ستظهر جميع الرواتب مع الخصومات
   - يمكنك رؤية خصم كل سلفة بالتفصيل
   - يمكنك طباعة التقرير أو تصديره

## حالات الاستخدام الشائعة

### 1️⃣ الموظف يريد سلفة 3000 لمدة 3 أشهر

```
✅ الخطوة 1: الموظف يدخل /hr/loans/request/
✅ الخطوة 2: يملأ:
   - المبلغ: 3000
   - السبب: نفقات طبية عاجلة
   - الأقساط: 3
   - بدء الخصم: 2026-02-01

✅ الخطوة 3: المدير يوافق في /hr/loans/<id>/approve/

✅ النتيجة:
   - فبراير: خصم 1000
   - مارس: خصم 1000
   - أبريل: خصم 1000
   - المتبقي: 0 ✓
```

### 2️⃣ الموظف يريد تأجيل القسط

```
❓ المشكلة: الموظف لا يستطيع الدفع هذا الشهر

✅ الحل:
1. الذهاب إلى صفحة السلفة /hr/loans/<id>/
2. اضغط "تأجيل القسط"
3. اختر تاريخ جديد (مثل: الشهر القادم)
4. اكتب السبب

✅ النتيجة:
   - القسط معلق الآن
   - سيتم خصمه في التاريخ الجديد
```

### 3️⃣ عرض كشف الراتب الشامل

```
📋 تقرير شامل يتضمن:
   - الراتب الأساسي لكل موظف
   - البدلات (سكن، مواصلات، إلخ)
   - الساعات الإضافية
   - المكافآت
   - الخصومات (تأخير، غياب، سلف)
   - الراتب الصافي

💾 يمكن:
   - عرضه على الشاشة
   - طباعته كـ PDF
   - تصفيته حسب القسم أو التاريخ
```

## نصائح مهمة ⚠️

1. **تحديد التاريخ بحذر**
   - تأكد من اختيار تاريخ بدء الخصم المناسب
   - يجب أن يكون التاريخ بعد تاريخ الموافقة

2. **عدد الأقساط**
   - كلما قل العدد، كبر مبلغ القسط الشهري
   - مثال: 3000 ÷ 1 = 3000 شهرياً
   - مثال: 3000 ÷ 6 = 500 شهرياً

3. **الخصومات التلقائية**
   - لا تحتاج لفعل شيء، النظام يخصم تلقائياً
   - سيظهر الخصم في كشف الراتب

4. **التأجيل**
   - استخدمه فقط عند الضرورة
   - يؤخر السداد لكن لا يلغيه

## مثال واقعي خطوة بخطوة

### السيناريو:
عامل يريد سلفة 1500 ج.م لأسباب طارئة، وسيسددها على 2 شهر

### الخطوات:

**Step 1: الموظف يدخل النظام**
```
URL: /hr/loans/request/
```

**Step 2: يملأ البيانات**
```
- الموظف: [محمد علي]
- المبلغ: 1500
- السبب: [حالة طوارئ عائلية]
- عدد الأقساط: 2
- تاريخ البدء: 2026-02-01
- سلفة طارئة: ✓ [منطقي]
```

**Step 3: النظام ينشئ:**
```
- رقم السلفة: LOAN-202602-0001
- القسط 1: 750 (استحقاق: 2026-02-28)
- القسط 2: 750 (استحقاق: 2026-03-31)
- الحالة: معلقة
```

**Step 4: المدير يوافق**
```
URL: /hr/loans/LOAN-202602-0001/approve/
- يختار: الموافقة
- ينقر: تأكيد
- الحالة تتغير: معتمدة ✓
```

**Step 5: الخصم التلقائي**
```
فبراير:
- راتب أساسي: 3000
- بدلات: 500
- خصومات (سلف): 750
- الصافي: 2750 ✓

مارس:
- راتب أساسي: 3000
- بدلات: 500
- خصومات (سلف): 750
- الصافي: 2750 ✓
```

**Step 6: النتيجة النهائية**
```
✓ تم سداد السلفة بالكامل
✓ المبلغ: 1500 (750 + 750)
✓ الحالة: مكتملة
```

## أسئلة متكررة

### س: هل يمكن تغيير مبلغ القسط؟
ج: بعد الموافقة، لا. يجب إلغاء السلفة وتقديم واحدة جديدة.

### س: هل يمكن سداد السلفة قبل الموعد؟
ج: نعم، يمكن تسجيل الدفع يدوياً (يتم إضافة هذه الميزة لاحقاً).

### س: ماذا لو لم أستطع الدفع في الموعد؟
ج: استخدم خاصية "تأجيل القسط" لتأجيل لشهر قادم.

### س: هل هناك فائدة على السلفة؟
ج: حالياً لا، لكن يمكن إضافتها لاحقاً.

### س: كم عدد السلف التي يمكن للموظف أن يأخذها؟
ج: حالياً بلا حد، لكن يمكن إضافة حد أقصى لاحقاً.
