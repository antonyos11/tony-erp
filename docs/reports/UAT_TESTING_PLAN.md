## 👥 الأدوار المختلفة والمتطلبات

### 1️⃣ المدير العام (Super Admin/CEO)

#### المسؤوليات الرئيسية:
- الإشراف العام على النظام
- المراجعة والموافقة على العمليات الكبرى
- الاطلاع على التقارير التنفيذية

#### المتطلبات الأساسية:
- لوحة معلومات (Dashboard) شاملة وفورية
- تقارير KPI والمؤشرات الرئيسية
- نظرة عامة على جميع الفروع والعمليات

#### السيناريوهات الاختبارية:

**السيناريو 1: مراجعة الأداء اليومي**
```
الخطوات:
1. تسجيل الدخول → لوحة المعلومات الرئيسية
2. عرض إجمالي المبيعات اليومية
3. عرض إجمالي المشتريات
4. عرض الرصيد النقدي
5. عرض المستحقات من العملاء

معايير النجاح:
✓ تحميل اللوحة في أقل من 3 ثوان
✓ البيانات محدثة فوراً
✓ الأرقام صحيحة (مطابقة للنظام)
✓ الرسوم البيانية واضحة وسهلة الفهم
```

**السيناريو 2: الموافقة على عمليات كبرى**
```
الخطوات:
1. الذهاب إلى قائمة الطلبات المعلقة
2. مراجعة طلب شراء كبير (50000+)
3. عرض الملفات المرفقة والتفاصيل
4. الموافقة أو الرفض مع التعليق
5. تلقي تأكيد العملية

معايير النجاح:
✓ سهولة الوصول للعمليات المعلقة
✓ واجهة الموافقة واضحة وسهلة
✓ إمكانية إضافة تعليقات وملاحظات
✓ إشعارات فورية للمعنيين
```

**السيناريو 3: استخراج تقرير تنفيذي شهري**
```
الخطوات:
1. الذهاب إلى التقارير التنفيذية
2. اختيار شهر معين
3. اختيار الفروع المطلوبة
4. تحديد المؤشرات (المبيعات، الأرباح، التكاليف)
5. تحميل وطباعة التقرير

معايير النجاح:
✓ التقرير يتضمن جميع البيانات المطلوبة
✓ الأرقام دقيقة وموثوقة
✓ التصميم احترافي وقابل للطباعة
✓ تصدير PDF يعمل بشكل سلس
```

### 2️⃣ مدير الفرع (Branch Manager)

#### المسؤوليات الرئيسية:
- إدارة عمليات الفرع
- الإشراف على الموظفين
- المراجعة والموافقة على العمليات الفرعية

#### المتطلبات الأساسية:
- لوحة معلومات خاصة بالفرع
- تقارير أداء الفرع
- إدارة الموظفين والمخزون الفرعي

#### السيناريوهات الاختبارية:

**السيناريو 1: بدء اليوم العملي**
```

✓ عرض بيانات الفرع فقط
✓ الإجمالي صحيح ومحدث
✓ تنبيهات واضحة للمشاكل
```

**السيناريو 2: إدارة المخزون الفرعي**
```
الخطوات:
1. الذهاب إلى مخزن الفرع
2. عرض المنتجات والكميات
3. تحديد المنتجات الناقصة

معايير النجاح:
✓ معلومات المخزون محدثة فوراً
✓ سهولة طلب التحويل
✓ تتبع الطلبات المعلقة
✓ إشعارات عند وصول البضائع
```

**السيناريو 3: الموافقة على مبيعات الفرع**
```
الخطوات:
1. عرض قائمة الفواتير المعلقة
2. مراجعة كل فاتورة
3. التحقق من العملاء والأسعار
4. الموافقة على الفواتير الصحيحة
5. رفع التقرير اليومي

معايير النجاح:
✓ واجهة واضحة وسهلة
✓ معلومات العميل كاملة ودقيقة
✓ سهولة الموافقة/الرفض
✓ تسجيل سبب الرفض عند الحاجة
```

**السيناريو 4: تقرير أداء الفرع**
```
الخطوات:
1. الذهاب إلى التقارير الفرعية
2. اختيار الفترة (يومي/أسبوعي/شهري)
3. عرض المبيعات والأرباح
4. عرض عدد الفواتير والمتوسط
5. عرض الموظفين الأفضل أداءً

معايير النجاح:
✓ التقرير شامل ودقيق
✓ المقارنة مع الأيام السابقة واضحة
```

### 3️⃣ المحاسب (Accountant)

#### المسؤوليات الرئيسية:
- إدخال القيود المحاسبية
- تسجيل الفواتير
- مراجعة المعاملات المالية

#### المتطلبات الأساسية:
- واجهة سريعة وسهلة لإدخال القيود
- حساب تلقائي للضرائب
- نظام بحث ذكي عن الحسابات

#### السيناريوهات الاختبارية:

**السيناريو 1: إنشاء قيد محاسبي سريع**
```
الخطوات:
1. الذهاب إلى نموذج إنشاء قيد جديد
2. اختيار نوع القيد (إيراد/مصروف/تحويل)
3. إدخال الحسابات والمبالغ
4. حساب الضريبة تلقائياً
5. إضافة ملفات مرفقة
6. الحفظ التلقائي

معايير النجاح:
✓ الحفظ التلقائي كل 10 ثواني
✓ عدم فقدان البيانات عند الانقطاع
✓ رسالة تحذير عند عدم التوازن
✓ سهولة التراجع عن التغييرات
```

**السيناريو 2: البحث عن حساب ذكي**
```
الخطوات:
1. البدء في إدخال قيد جديد
2. اختيار حقل الحساب
3. البحث برقم الحساب أو الاسم
4. عرض اقتراحات ذكية
5. اختيار الحساب المناسب

معايير النجاح:
✓ البحث سريع وسهل
✓ الاقتراحات دقيقة ومناسبة
✓ عرض اسم الحساب وفئته
✓ عرض الرصيد الحالي
```

**السيناريو 3: نسخ قيد من فاتورة سابقة**
```
الخطوات:
1. الذهاب إلى قائمة الفواتير السابقة
2. اختيار فاتورة معينة
3. النقر على "نسخ إلى قيد محاسبي"
4. مراجعة البيانات المنسوخة
5. التعديل إذا لزم الأمر
6. الحفظ

معايير النجاح:
✓ جميع البيانات تُنسخ صحيحاً
✓ سهولة التعديل
✓ حفظ سريع وآمن
```

**السيناريو 4: استخراج دفتر الأستاذ**
```
الخطوات:
1. الذهاب إلى التقارير المحاسبية
2. اختيار دفتر الأستاذ
3. اختيار الحساب والفترة
4. عرض جميع العمليات
5. عرض الرصيد آخر الفترة

معايير النجاح:
✓ البيانات دقيقة وكاملة
✓ عرض مفصل لكل عملية
✓ إمكانية التصدير والطباعة
```

**السيناريو 3: معالجة طرق الدفع**

**السيناريو 4: إدارة الوردية (Opening/Closing)**
