4. جرب في وضع التصفح الخفي (Incognito/Private):
   Ctrl + Shift + N

🔧 إذا استمرت المشكلة:
═════════════════════════

قم بتشغيل هذه الأوامر على الخادم:

cd /var/www/tony_erp

# تجميع الملفات الثابتة
python3 manage.py collectstatic --noinput

# إعادة تشغيل الخدمات
sudo systemctl restart nginx
sudo systemctl restart gunicorn

# إفراغ الكاش
python3 manage.py clear_cache
