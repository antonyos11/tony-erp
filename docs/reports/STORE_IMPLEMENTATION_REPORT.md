## 🔧 الصيانة والتشغيل

### الفحص اليومي
```bash
# 1. فحص حالة الخدمات
sudo systemctl status gunicorn
sudo systemctl status nginx

# 2. فحص اللوجات
tail -f /var/www/tony_erp/logs/error.log

# 3. فحص الطلبات الجديدة
python3 manage.py shell -c "from ecommerce.models import Order; print(f'طلبات اليوم: {Order.objects.filter(created_at__date=timezone.now().date()).count()}')"
```

### النسخ الاحتياطي
```bash
# نسخ احتياطي يومي
python3 manage.py dumpdata ecommerce > backup_store_$(date +%Y%m%d).json
```

### التحديثات
```bash
# إعادة تحميل Gunicorn بعد تغييرات الكود
sudo pkill -HUP gunicorn

# إعادة تحميل Nginx بعد تغييرات الإعدادات
sudo nginx -t && sudo systemctl reload nginx
```
