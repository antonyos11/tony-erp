# تفعيل القائمة الجانبية المنظمة
## Quick Activation Guide

---

## 🎯 الهدف

تفعيل النظام الجديد للقائمة الجانبية المنظمة مع دعم:
- تقسيم واضح (عمليات يومية، تعريفات، تقارير)
- صلاحيات تلقائية
- حفظ حالة الطي/الفتح
- تصميم عصري ومرن

---

## 📋 خطوات التفعيل

### 1. تسجيل Context Processor

افتح ملف `app/tony_erp/settings.py` وأضف:

```python
TEMPLATES = [
    {
        # ...
        'OPTIONS': {
            'context_processors': [
                # ... الموجودة ...
                'core.sidebar_processor.sidebar_menu',  # ← أضف هذا السطر
            ],
        },
    },
]
```

### 2. استبدال القالب

افتح ملف `app/templates/base_v2.html` وابحث عن:

```html
{% include 'partials/_sidebar.html' %}
```

واستبدله بـ:

```html
{% include 'partials/_sidebar_organized.html' %}
```

### 3. إعادة تشغيل السيرفر

```bash
# أوقف السيرفر (Ctrl+C)
# ثم شغّله من جديد:
python manage.py runserver
```

### 4. اختبار النظام

افتح المتصفح وتحقق من:
- ✅ ظهور الأقسام الرئيسية
- ✅ ظهور المجموعات الفرعية (يومية، تعريفات، تقارير)
- ✅ طي/فتح الأقسام يعمل
- ✅ حفظ الحالة عند تحديث الصفحة
- ✅ تمييز العنصر النشط
- ✅ الشارات (Badges) تظهر بشكل صحيح

## 🗂️ الملفات المضافة

```
app/

├── templates/
│   └── partials/
│       └── _sidebar_organized.html  ← القالب الجديد
└── docs/
    └── SIDEBAR_ORGANIZED_GUIDE.md   ← دليل الاستخدام الكامل
```

## 📚 التوثيق الكامل

للحصول على دليل شامل حول:
- إضافة عناصر جديدة
- إضافة أقسام رئيسية
- إضافة شارات (Badges)
- حل المشاكل

راجع: **`docs/SIDEBAR_ORGANIZED_GUIDE.md`**

---

## 🎨 المزايا الجديدة

### 1. التنظيم الواضح
```
📊 المبيعات
  ⚡ عمليات يومية
    - فاتورة جديدة
    - قائمة الفواتير
  ⚙️ تعريفات وإعدادات
    - العملاء
    - التسعير
  📈 تقارير واستعلامات
    - تقرير المبيعات
    - كشف حساب
```

### 2. حفظ الحالة تلقائيًا
- الأقسام المفتوحة تبقى مفتوحة
- الأقسام المطوية تبقى مطوية
- القسم النشط يُفتح تلقائيًا

### 3. صلاحيات ذكية
- العناصر التي لا يملك المستخدم صلاحيتها **تختفي تلقائيًا**
- لا حاجة لبرمجة يدوية للصلاحيات

### 4. سهولة الإضافة
إضافة عنصر جديد = **تعديل ملف واحد فقط** (`sidebar_config.py`)

## 🔄 العودة للنظام القديم (إذا لزم الأمر)

إذا أردت العودة للنظام القديم مؤقتًا:

### 1. استبدال القالب
في `base_v2.html`:
```html
{% include 'partials/_sidebar.html' %}  {# القديم #}
```

### 2. إعادة التشغيل
```bash
python manage.py runserver
```

**ملاحظة:** يمكنك الإبقاء على `context_processor` مفعّل حتى لو عدت للنظام القديم.

للمساعدة أو الاستفسارات:

2. افحص `core/sidebar_config.py` للأمثلة
3. راجع `core/sidebar_processor.py` لمنطق الصلاحيات
