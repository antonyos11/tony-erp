## 🔧 التثبيت

### خطوات بسيطة:

```bash
# 1. استنساخ المشروع
cd /var/www/tony_erp

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. تطبيق Migrations
python manage.py migrate

# 4. تحميل البيانات الأولية
python manage.py shell
>>> from accounting.entry_templates import create_predefined_templates
>>> create_predefined_templates()
>>> exit()

# 5. جمع الملفات الثابتة
python manage.py collectstatic

# 6. تشغيل Celery (3 terminals)
# Terminal 1:
celery -A tony_erp worker -l info

# Terminal 2:
celery -A tony_erp beat -l info

# Terminal 3:
python manage.py runserver
```
