## 🚀 الخطوات التالية للتشغيل

### 1️⃣ تشغيل Migrations
```bash
cd /var/www/tony_erp
python manage.py makemigrations
python manage.py migrate
```

### 2️⃣ تحديث خوادم البحث والفهرسة (اختياري)
```bash
python manage.py search_index --rebuild
```

### 3️⃣ إنشاء مستخدم إداري (اختياري)
```bash
python manage.py createsuperuser
```

### 4️⃣ تجميع الملفات الثابتة (للإنتاج)
```bash
python manage.py collectstatic
```

### 5️⃣ تشغيل الخادم
```bash
python manage.py runserver
```

## 🎓 أمثلة الاستخدام

### مثال 1: استخدام خدمة المطابقة البنكية
```python
from bank_integration.services import reconciliation_service

account = BankAccount.objects.get(account_number='123456')
result = reconciliation_service.auto_reconcile(account)
# النتيجة: تم مطابقة العمليات تلقائياً
```

### مثال 2: حساب درجة المخاطرة
```python
from risk_management.models import Risk

risk = Risk.objects.create(
    title='انقطاع الكهرباء',
    probability='high',
    impact='severe'
)
risk.calculate_risk_score()
# النتيجة: درجة عالية للمخاطرة
```

### مثال 3: إنشاء تنبيه ضريبي
```python
from tax_system.models import TaxReport

report = TaxReport.objects.create(
    report_type='vat_return',
    period_type='monthly'
)
report.calculate_tax_liability()
# النتيجة: تم حساب الضريبة تلقائياً
```
