## 🚀 الخطوات التالية

### 1️⃣ استعراض المواد الخام

افتح المتصفح واذهب إلى:
```
http://72.62.176.249/inventory/products/raw-material/create/
```

أو من القائمة:
```
المخزون > المنتجات > عرض الكل
```

ثم فلتر حسب "نوع المنتج" = "مادة خام"

### 2️⃣ إنشاء منتج نهائي (مرتبة)

1. اذهب إلى: **المخزون > المنتجات > إضافة منتج جديد**
2. املأ البيانات:
   ```
   SKU: MAT-SPR-120
   الاسم: مرتبة سوست بونيل 120×200 سم
   نوع المنتج: منتج تام
   الفئة: مراتب
   السعر: 2500 جنيه
   ```

### 3️⃣ إنشاء BOM (قائمة المواد)

1. اذهب إلى: **الإنتاج > قوائم المواد > إضافة قائمة جديدة**
2. اختر المنتج: "مرتبة سوست بونيل 120×200"
3. أضف المواد التالية:

| SKU | المادة | الكمية | الوحدة | الهدر % |
|-----|--------|--------|--------|---------|
| FRM-MTL-120 | إطار معدني 120×200 | 1 | وحدة | 0% |
| SPR-BNL-S100 | سوست بونيل 2.2 مم | 450 | وحدة | 2% |
| FOAM-HD30 | فوم HD كثافة 30 | 8 | كجم | 5% |
| FELT-STD-10 | لباد عادي 10 مم | 2.5 | متر | 3% |
| FAB-JAC-PRT | قماش جاكار مطبوع | 3 | متر | 5% |
| THR-POL-WHT | خيط بوليستر أبيض | 150 | متر | 2% |
| GLU-FOAM | غراء إسفنج | 0.5 | كجم | 5% |
| BAG-PVC-L | كيس PVC كبير | 1 | وحدة | 0% |
| LABEL-BRAND | ملصق العلامة | 1 | وحدة | 0% |

4. احفظ القائمة
5. النظام سيحسب التكلفة تلقائياً!

### 4️⃣ تشغيل سكريبت الأمثلة (اختياري)

لإنشاء منتجات جاهزة مع BOM:

```bash
python manage.py shell < setup_bom_examples.py
```

هذا سينشئ:
- ✅ مرتبة سوست بونيل 120×200 (مع BOM كامل)
- ✅ مرتبة ميموري فوم 160×200 (مع BOM كامل)
