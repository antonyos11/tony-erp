4. تسوية بنكية
5. الأرصدة النقدية

#### 🟢 دليل الحسابات (3 بنود):

2. حساب جديد
3. مراكز التكلفة

#### 🟢 الإعدادات (3 بنود):
1. تكوين الحسابات
2. إعدادات الضرائب
3. السنة المالية

#### 🟡 القوائم المالية (4 تقارير):

2. الميزانية العمومية
