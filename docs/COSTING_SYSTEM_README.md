# نظام تكاليف المنتجات (Product Costing System)

## نظرة عامة

تم إضافة نظام متكامل لتكاليف المنتجات يعمل كمحاسب تكاليف متخصص، يتيح لك تحديد التكلفة التفصيلية لكل منتج وتحليل هوامش الربح واتخاذ قرارات التسعير الصحيحة.

## المميزات الرئيسية

### 1. بطاقات التكلفة (Product Costing Cards)
- **إصدارات متعددة**: إمكانية إنشاء عدة إصدارات لبطاقة تكلفة المنتج الواحد
- **طرق تكلفة مختلفة**: 
  - تكلفة معيارية (Standard Cost)
  - تكلفة فعلية (Actual Cost)
  - متوسط متحرك (Moving Average)

### 2. مكونات التكلفة التفصيلية
يتم تقسيم تكلفة المنتج إلى:
- **المواد المباشرة** (Direct Materials)
- **العمالة المباشرة** (Direct Labor)
- **التكاليف الصناعية غير المباشرة** (Manufacturing Overhead)
- **تكاليف أخرى** (Other Costs)

### 3. مكونات التكلفة (Cost Components)
كل بطاقة تكلفة يمكن أن تحتوي على عدة مكونات تفصيلية:
- **مواد خام**: ربط بصنف من المخزون مع الكمية والسعر
- **عمالة**: تحديد ساعات العمل وتكلفة الساعة
- **تكاليف صناعية**: توزيع نسبي أو مبلغ ثابت
- **خدمات**: أي تكاليف خارجية
- ربط بـ:
  - حساب محاسبي
  - مركز تكلفة
  - صنف من المخزون

### 4. التحليلات والتقارير

#### لوحة تحكل محاسب التكاليف
- عدد المنتجات المُكلفة
- نسبة التغطية
- منتجات بحاجة للتكليف
- منتجات بهوامش ربح منخفضة
- تغييرات التكلفة الأخيرة

#### تحليل التكاليف
- المنتجات حسب نسبة المواد
- المنتجات حسب نسبة العمالة
- مقارنة التكلفة بسعر البيع
- تحليل هوامش الربح

### 5. السعر المقترح (Suggested Pricing)
- حساب آلي للسعر المقترح بناءً على:
  - إجمالي التكلفة
  - هامش الربح المستهدف
- مقارنة مع السعر الحالي
- حساب هامش الربح الفعلي

### 6. سجل التكاليف (Costing History)
- تسجيل تلقائي لجميع تغييرات التكلفة
- مقارنة التكلفة القديمة بالجديدة
- نسبة التغيير
- سبب التغيير
- من قام بالتغيير ومتى

### 7. التحديث الجماعي
- تحديث تكاليف عدة منتجات دفعة واحدة
- زيادة أو تخفيض بنسبة مئوية أو مبلغ ثابت
- تطبيق على نوع محدد من التكاليف (مواد، عمالة، إلخ)

### 8. التصدير إلى Excel
- تصدير جميع بطاقات التكلفة
- تفاصيل كاملة لكل بطاقة
- جاهز للطباعة والمراجعة

## كيفية الاستخدام

### 1. إنشاء بطاقة تكلفة جديدة

```
الخطوات:
1. اذهب إلى: تكاليف المنتجات → بطاقة تكلفة جديدة
2. اختر المنتج
3. حدد طريقة التكلفة (معيارية/فعلية/متوسط)
4. أدخل هامش الربح المستهدف
5. احفظ
```

### 2. إضافة مكونات التكلفة

```
بعد إنشاء البطاقة:
1. اضغط على "إضافة مكون"
2. اختر نوع المكون (مادة/عمالة/تكاليف صناعية)
3. أدخل التفاصيل:
   - الوصف
   - الكمية
   - تكلفة الوحدة
   - (اختياري) الصنف المرتبط
   - (اختياري) الحساب المحاسبي
   - (اختياري) مركز التكلفة
4. احفظ
```

### 3. تفعيل بطاقة التكلفة

```
عند الانتهاء من إدخال جميع المكونات:
1. راجع إجمالي التكلفة
2. راجع السعر المقترح
3. اضغط "تفعيل البطاقة"
4. سيتم تلقائياً:
   - تحديث تكلفة المنتج
   - إلغاء تفعيل البطاقات الأخرى
   - تسجيل التغيير في السجل التاريخي
```

### 4. مثال عملي: تكليف منتج "كرسي خشبي"

#### المواد المباشرة:
- خشب زان: 2 متر × 150 جنيه = 300 جنيه
- مسامير وغراء: 1 × 50 جنيه = 50 جنيه
- دهان: 0.5 لتر × 80 جنيه = 40 جنيه
**إجمالي المواد: 390 جنيه**

#### العمالة المباشرة:
- نجار: 3 ساعات × 30 جنيه = 90 جنيه
- دهان: 1 ساعة × 25 جنيه = 25 جنيه
**إجمالي العمالة: 115 جنيه**

#### التكاليف الصناعية:
- كهرباء وماكينات: 30 جنيه
- إشراف: 20 جنيه
**إجمالي التكاليف الصناعية: 50 جنيه**

**إجمالي التكلفة: 555 جنيه**

#### التسعير:
- هامش ربح مستهدف: 25%
- السعر المقترح: 555 / (1 - 0.25) = **740 جنيه**

## النماذج في قاعدة البيانات

### ProductCosting
```python
- product: ForeignKey للمنتج
- version: رقم الإصدار
- costing_method: طريقة التكلفة
- status: draft/active/archived
- direct_material_cost: تكلفة المواد
- direct_labor_cost: تكلفة العمالة
- overhead_cost: التكاليف الصناعية
- other_cost: تكاليف أخرى
- total_cost: إجمالي التكلفة (محسوبة)
- target_profit_margin: هامش الربح المستهدف
- suggested_price: السعر المقترح (محسوب)
```

### CostComponent
```python
- costing: ForeignKey لبطاقة التكلفة
- component_type: نوع المكون
- description: الوصف
- item: ForeignKey للصنف (اختياري)
- account: ForeignKey للحساب (اختياري)
- cost_center: ForeignKey لمركز التكلفة (اختياري)
- quantity: الكمية
- unit_cost: تكلفة الوحدة
- total_cost: إجمالي التكلفة (محسوبة)
```

### CostingHistory
```python
- product: ForeignKey للمنتج
- old_cost: التكلفة القديمة
- new_cost: التكلفة الجديدة
- change_reason: سبب التغيير
- costing: ForeignKey لبطاقة التكلفة
- changed_by: من قام بالتغيير
- changed_at: متى تم التغيير
```

## التكامل مع باقي النظام

### مع المخزون
- يتم تحديث حقل `cost` في جدول `Product` عند تفعيل بطاقة تكلفة
- يمكن ربط مكونات التكلفة بأصناف من المخزون

### مع المحاسبة
- يمكن ربط مكونات التكلفة بحسابات محاسبية
- يمكن ربط مكونات التكلفة بمراكز تكلفة
- جاهز للتكامل مع قيود تكاليف الإنتاج

### مع التقارير
- هوامش الربح تستخدم في تقارير الربحية
- التكاليف تستخدم في تحليل المبيعات

## التطويرات المستقبلية

1. **قيود محاسبية تلقائية**: إنشاء قيود تحميل التكاليف آلياً
2. **تكامل مع الإنتاج**: ربط مع أوامر الإنتاج والمراحل الإنتاجية
3. **تكلفة حسب الدفعات**: تتبع تكلفة كل دفعة إنتاج
4. **تحليل الانحرافات**: مقارنة التكلفة المعيارية بالفعلية
5. **تكامل مع المشتريات**: تحديث تلقائي لتكاليف المواد من فواتير الشراء
6. **تقارير متقدمة**: 
   - تحليل التكاليف حسب الفترة
   - مقارنة تكاليف المنتجات المتشابهة
   - تحليل ABC للمنتجات حسب التكلفة
