## 🧪 الاختبار السريع (5 دقائق)

### الخطوة 1: افتح صفحة تسجيل الإيراد
```
الرابط: http://your-domain/accounting/entries/revenue/create/
```

### الخطوة 2: اختبر الميزات واحدة تلو الأخرى

#### ✅ 1. زر "حفظ + جديد"
1. املأ النموذج كاملاً
2. انقر الزر **الأرجواني** "حفظ + جديد"
3. **المتوقع:** يتم الحفظ والانتقال لنموذج جديد

#### ✅ 2. استعادة المسودة
1. املأ بعض الحقول (لا تحفظ)
2. أغلق الصفحة أو انتقل لصفحة أخرى
3. ارجع لصفحة الإيراد
4. **المتوقع:** بانر أزرق في الأعلى يعرض "وجدنا مسودة..."
5. انقر "استعادة"
6. **المتوقع:** تعود البيانات

#### ✅ 3. تذكر آخر الاختيارات
1. سجّل قيد واحد باختيار حساب ومركز تكلفة
2. بعد الحفظ، افتح نموذج جديد
3. **المتوقع:** الحقول مملوءة بآخر اختياراتك
4. **لاحظ:** علامة "⏱️ آخر اختيار" بجانب التسمية

#### ✅ 4. تحذير الحسابات
1. في قيد **إيراد**، اختر حساب كوده يبدأ بـ4 أو 5
2. **المتوقع:** تحذير أصفر يظهر "هذا الحساب قد يكون للمصروفات"
3. التحذير يختفي بعد 5 ثوانٍ

#### ✅ 5. كشف التكرار
1. سجّل قيد (مثلاً: 100 ج.م في تاريخ اليوم)
2. حاول تسجيل نفس القيد مرة أخرى (نفس المبلغ، التاريخ، الحساب)
3. انقر "حفظ"
4. **المتوقع:** رسالة تحذير "يوجد قيد مشابه..."
5. **اختيارك:** موافق للحفظ أو إلغاء

#### ✅ 6. إدارة القوالب
1. في قسم "القوالب السريعة"، انقر "حفظ كقالب"
2. أدخل اسم القالب (مثل: "اختبار")
3. الصفحة تعيد التحميل
4. **المتوقع:** القالب الجديد يظهر في القائمة
5. **لاحظ:** أيقونة ❌ حمراء على القالب الجديد
6. انقر ❌ → تأكيد → **المتوقع:** القالب يُحذف

#### ✅ 7. آخر القيود
1. **ملاحظة:** يظهر فقط إذا سجلت قيودًا من قبل
2. تحت القوالب، ستجد قسم "آخر القيود المشابهة"
3. **المتوقع:** قائمة بآخر 5 قيود
4. انقر على أي قيد
5. **المتوقع:** البيانات تُنسخ للنموذج

#### ✅ 8. معاينة المرفقات
1. في قسم "المرفقات"، اختر ملف أو أكثر
2. **المتوقع:** بطاقة لكل ملف تعرض:
   - أيقونة حسب النوع
   - اسم الملف
   - حجم الملف
   - نوع الملف
3. جرّب رفع ملف أكبر من 10MB
4. **المتوقع:** رسالة تحذير حمراء "الحجم يتجاوز الحد..."
5. انقر ❌ على أي ملف
6. **المتوقع:** الملف يُحذف من القائمة

#### ✅ 9. الاختصارات
**في وحدة تحكم المتصفح (F12) → Console:**
```javascript
// اختبر الاختصارات
console.log('اضغط Ctrl+S للمسودة');
console.log('اضغط Ctrl+Enter للحفظ');
console.log('اضغط Enter للتنقل');
console.log('اضغط Esc للإلغاء');
```

1. املأ بعض الحقول
2. اضغط `Ctrl+S`
3. **المتوقع:** رسالة "تم حفظ المسودة"
4. في أي حقل، اضغط `Enter`
5. **المتوقع:** الانتقال للحقل التالي
6. اضغط `Ctrl+Enter`
7. **المتوقع:** حفظ القيد مباشرة
8. اضغط `Esc`
9. **المتوقع:** رسالة تأكيد الإلغاء

## 🐛 فحص الأخطاء

### افتح وحدة تحكم المتصفح (F12):
```
لا يجب أن ترى أي رسائل حمراء (errors)
```

### إذا ظهرت أخطاء:
1. **أخطاء 404 (ملف غير موجود):**
   ```bash
   cd /var/www/tony_erp
   python3 manage.py collectstatic --noinput
   ```

2. **أخطاء JavaScript:**
   - تحقق من `/static/accounting/js/entry_features.js`
   - انسخ الخطأ وابحث عن رقم السطر

3. **أخطاء CSS:**
   - امسح cache المتصفح (`Ctrl+Shift+Delete`)
   - حدّث الصفحة بقوة (`Ctrl+F5`)
