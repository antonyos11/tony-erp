# PRD — Tony ERP (نظام إدارة الأعمال الذكي والشامل)

## 1) الملخص التنفيذي
نظام **Tony ERP** هو منصة "الجيل القادم" لإدارة الموارد، مصممة خصيصاً لتدمج بين العمليات التقليدية (محاسبة، مخزون) وبين **الذكاء الاصطناعي والأتمتة المتقدمة**. يتميز النظام بتخصص عميق في **مجال تصنيع المراتب والمفروشات**، مع قدرات **Behaviors AI** للتسعير وخدمة العملاء.

## 2) القيمة المقترحة (Unique Value Proposition)
1.  **ذكاء اصطناعي حقيقي**: ليس مجرد شعار، بل محركات فعلية للتسعير (Smart Pricing) وخدمة العملاء (WhatsApp AI).
2.  **تخصص صناعي دقيق**: نظام مصمم خصيصاً لدورة حياة تصنيع المراتب (من القص إلى التغليف والضمان).
3.  **أتمتة كاملة**: من استلام طلب WhatsApp -> إنشاء عرض سعر AI -> أمر تصنيع -> صرف مواد آلي.
4.  **تجربة مستخدم عصرية**: واجهات POS متطورة وتصاميم تفاعلية حديثة.

---

## 3) الوحدات الأساسية (Core Modules)

### أ. الإدارة المالية والمحاسبة
*   دليل حسابات شجري ديناميكي.
*   قيود يومية ومراكز تكلفة متقدمة.
*   تقارير القوائم المالية (ميزانية، أرباح وخسائر) لحظية.
*   إدارة الأصول الثابتة وإهلاكها.

### ب. إدارة المخزون والمستودعات
*   إدارة متعددة للمخازن (خامات، تحت التشغيل، منتج تام، قطع غيار، معارض).
*   تتبع دقيق لحركات المخزون (وارد، منصرف، تحويل).
*   حدود إعادة الطلب والتنبيهات الذكية.
*   دعم FIFO/LIFO ومتوسط التكلفة.

### ج. المبيعات و CRM
*   إدارة العملاء والفرص البيعية (Leads & Opportunities).
*   دورة مبيعات كاملة (عرض سعر -> أمر بيع -> فاتورة -> سند قبض).
*   تحليلات أداء المبيعات لكل بائع/فرع.

## 4) الوحدات المتقدمة والمتخصصة (Advanced & Specialized Modules)

### 🏭 1. نظام مصنع المراتب (Mattress Factory System)
نظام تصنيع متكامل يغطي دورة حياة المنتج بالكامل:
*   **هيكل المنتج (BOM)**: تعريف دقيق لمكونات المرتبة (قماش، إسفنج، سوست، لباد، إطار).
*   **مراكز العمل (Work Centers)**: تتبع الإنتاج عبر المراحل (التقطيع، الخياطة، الحشو، التجميع، التشطيب، التعبئة).
*   **إدارة الجودة**: نقاط فحص ملزمة في كل مرحلة إنتاج.
*   **نظام الضمان الذكي**:
    *   توليد **QR Code** فريد لكل مرتبة منتجة.
    *   صفحة تسجيل ضمان للعميل النهائي عبر مسح الـ QR.
    *   ربط آلي بين الرقم التسلسلي وتاريخ الإنتاج والبيع.

### 🧠 2. التسعير الذكي (Smart Pricing AI)
محرك تسعير ديناميكي يعتمد على القواعد والذكاء الاصطناعي:
*   **PricingRule Engine**: تحديد قواعد تسعير مرنة (Cost+, Dynamic AI) بناءً على حجم العميل وتعقيد المنتج.
*   **SmartQuote**: حساب تكلفة فوري للمنتجات المخصصة (Custom Orders) يشمل المواد، العمالة، والتكاليف الإضافية.
*   **ProductionLineAI**: خوارزمية لترشيح خط الإنتاج الأمثل بناءً على التكلفة، الوقت، السعة المتاحة، وسجل الجودة التاريخي.
*   **AutoMaterialRelease**: صرف آلي للمواد عند اعتماد أمر الإنتاج بناءً على الـ BOM.

### 🤖 3. مساعد WhatsApp الذكي (WhatsApp AI)
نظام خدمة عملاء وأتمتة يعتمد على OpenAI و n8n:
*   **الرد الآلي الذكي**: فهم نية العميل (شراء، استفسار، شكوى) والرد الطبيعي.
*   **قاعدة معرفة المنتجات**: إجابة استفسارات العملاء حول مواصفات وأسعار المراتب (مثل "سليب كومفورت").
*   **Lead Generation**: استخلاص بيانات العميل وإنشاء "فرصة بيع" في الـ CRM تلقائياً عند اكتشاف نية الشراء (احتمالية > 50%).
*   **تحليل المشاعر**: تقييم رضا العميل في المحادثة.

### 🛒 4. نقطة البيع المتطورة (Enhanced POS)
واجهة بيع بالتجزئة مصممة للسرعة والكفاءة:
*   **Smart Cart**: سلة ذكية تدعم الخصومات السريعة، تعليق الطلبات، والبحث بالباركود.
*   **إشعارات تفاعلية**: تنبيهات فورية لحالة المخزون والعمليات الناجحة.
*   **Offline-Ready Architecture**: بنية مهيأة للعمل بدون إنترنت (مخطط مستقبلياً).
*   **اختصارات لوحة المفاتيح**: لسرعة الكاشير (F1-F12).

## 5) البنية التقنية (Technical Architecture)
*   **Backend**: Django (Python) - قوي وآمن وقابل للتوسع.
*   **Database**: PostgreSQL / SQLite (للتطوير).
*   **AI/ML**: OpenAI API (GPT-4), Scikit-learn (للتنبؤات البسيطة).
*   **Integration**: n8n (Workflow Automation) لربط WhatsApp والخدمات الخارجية.
*   **Frontend**: Bootstrap 5 + JavaScript (Vanilla/jQuery) لتجربة سريعة وتفاعلية.
