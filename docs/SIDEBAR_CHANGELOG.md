## CHANGELOG - Organized Sidebar

---

## [2.0.0] - 2025-12-06

### 🎉 إضافات رئيسية (Major Features)

#### ✨ نظام قائمة جانبية منظمة بالكامل
- **نموذج بيانات موحد** في ملف مركزي (`core/sidebar_config.py`)
- **تقسيم هرمي ثلاثي المستويات:**
  - المستوى 1: أقسام رئيسية (15 قسم)
  - المستوى 2: مجموعات فرعية (عمليات يومية، تعريفات، تقارير)
  - المستوى 3: عناصر القائمة (200+ عنصر)
- **context processor جديد** (`core/sidebar_processor.py`) لمعالجة البيانات والصلاحيات
- **قالب HTML جديد** (`templates/partials/_sidebar_organized.html`) مع تصميم عصري

#### 🎨 تحسينات تجربة المستخدم (UX Improvements)
- **حفظ حالة الطي/الفتح** في localStorage تلقائيًا
- **فتح ذكي** للقسم الذي يحتوي على الصفحة النشطة
- **تمرير تلقائي** للعنصر النشط إلى منتصف الشاشة
- **رسوم متحركة سلسة** للانتقالات والتحولات
- **دعم كامل للشاشات الصغيرة** والأجهزة المحمولة

#### 🔒 نظام صلاحيات متقدم
- **دمج تلقائي** مع نظام الصلاحيات الموجود
- **إخفاء ذكي** للعناصر غير المصرح بها
- دعم **3 أنواع من الصلاحيات:**
  - صلاحيات الوحدة (Module Permissions)
  - صلاحيات الموارد (Resource Permissions)
  - صلاحيات خاصة (Custom Permissions)

#### 📊 دعم الشارات (Badges)
- عرض **عدد أوامر الشراء المعلقة**
- عرض **عدد القيود غير المرحلة**
- عرض **عدد الموردين ذوي الأرصدة**
- عرض **عدد الإشعارات غير المقروءة**
- **قابل للتوسع** بسهولة لإضافة شارات جديدة

### 🔧 التغييرات المطلوبة للتفعيل

#### في `settings.py`:
```python
# إضافة context processor جديد
TEMPLATES = [
    {
        'OPTIONS': {
            'context_processors': [
                # ... الموجودة ...
                'core.sidebar_processor.sidebar_menu',  # ← جديد
            ],
        },
    },
]
```

#### في `templates/base_v2.html`:
```html
{# استبدال القالب القديم #}
{% include 'partials/_sidebar_organized.html' %}  {# ← جديد #}
```

### ⚠️ ملاحظات هامة

1. **لا تحذف الملفات القديمة:** القالب القديم (`_sidebar.html`) سيبقى للتوافق مع الإصدارات السابقة
2. **النسخ الاحتياطي:** يُنصح بأخذ نسخة احتياطية قبل التفعيل
3. **الاختبار:** اختبر النظام الجديد مع مستخدمين بصلاحيات مختلفة
4. **الأداء:** النظام الجديد محسّن ولا يؤثر على الأداء
