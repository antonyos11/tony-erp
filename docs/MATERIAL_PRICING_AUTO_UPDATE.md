# 🔄 نظام التحديث التلقائي لأسعار المواد الخام

## 📋 نظرة عامة

تم تطوير نظام ذكي لتحديث أسعار المواد الخام ووحدات التعبئة (الألواح) تلقائياً عند تغيير سعر المورد.

## ✨ الميزات

### 1. تحديث تلقائي لأسعار المنتجات
عند إضافة أو تعديل سعر مادة خام من مورد، يتم تلقائياً:
- ✅ تحديث سعر المنتج الأساسي (`Product.cost`)
- ✅ تحديث أسعار جميع وحدات التعبئة المرتبطة (`PackagingUnit`)
- ✅ تسجيل التغييرات في الـ Logs

### 2. واجهة محسّنة لإضافة الأسعار
- عرض وحدة الشراء للمادة الخام (متر مكعب، كيلو، إلخ)
- عرض السعر الحالي للمقارنة
- رسائل نجاح توضح عدد الوحدات المحدثة

## 🎯 كيفية الاستخدام

### إضافة سعر جديد

1. انتقل إلى: **المشتريات** → **أسعار المواد الخام** → **إضافة سعر جديد**
2. اختر **المادة الخام** (مثل: إسفنج كثافة 20)
3. اختر **المورد** (مثل: شركة الإسفنج المصري)
4. سيظهر لك:
   - وحدة الشراء (مثل: متر مكعب)
   - السعر الحالي
5. أدخل **السعر الجديد** (مثل: 4500 جنيه/م³)
6. اضغط **حفظ**

### النتيجة
سيتم تلقائياً:
- تحديث سعر المادة الخام
- تحديث أسعار جميع الألواح المرتبطة
- عرض رسالة نجاح مع عدد الوحدات المحدثة

## 📊 مثال عملي

### قبل التحديث
- **المادة**: إسفنج كثافة 20
- **السعر**: 3500 جنيه/م³
- **الألواح**:
  - لوح 200×100×5 سم = 350 جنيه
  - لوح 200×100×10 سم = 700 جنيه
  - لوح 180×200×8 سم = 1008 جنيه

### بعد تحديث السعر إلى 4500 جنيه/م³
- **المادة**: إسفنج كثافة 20
- **السعر**: 4500 جنيه/م³
- **الألواح** (محدثة تلقائياً):
  - لوح 200×100×5 سم = 450 جنيه ✅
  - لوح 200×100×10 سم = 900 جنيه ✅
  - لوح 180×200×8 سم = 1296 جنيه ✅

## 📝 ملاحظات مهمة

### متى يتم تحديث السعر؟
يتم تحديث سعر المنتج الأساسي في الحالات التالية:
1. إذا كان المورد هو المورد المفضل
2. إذا لم يكن هناك سعر حالي (0 أو فارغ)
3. إذا كان هذا هو المورد الوحيد للمنتج

### حساب سعر اللوح
يتم حساب سعر اللوح بناءً على:
- **للألواح (متر مكعب)**: `السعر = الحجم × سعر المتر المكعب`
- **للوزن (كيلو)**: `السعر = الوزن × سعر الكيلو`
- **للكمية العادية**: `السعر = الكمية × سعر الوحدة`
