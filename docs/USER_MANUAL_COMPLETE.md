# 1. مقدمة عن النظام

## ما هو Tony ERP؟
Tony ERP هو نظام متكامل لإدارة موارد المؤسسات مصمم خصيصاً للشركات
العربية ومصانع المراتب والمفروشات. يشمل النظام 44 وحدة متكاملة تغطي
جميع احتياجات العمل اليومي.

## المتطلبات الأساسية للاستخدام
- متصفح حديث (Chrome / Firefox / Edge)
- اتصال بالإنترنت أو شبكة داخلية
- اسم مستخدم وكلمة مرور صالحة

## عنوان النظام
```
https://your-domain.com
```

# 2. تسجيل الدخول والخروج

## 2.1 تسجيل الدخول

### الخطوات:
```
1. افتح المتصفح
2. اكتب عنوان النظام
3. أدخل اسم المستخدم
4. أدخل كلمة المرور
5. اضغط "تسجيل الدخول"
```

### صلاحيات الدخول حسب الدور:
| الدور | المستوى | الوصول |
|-------|---------|--------|
| مدير عام | 5 | جميع الوحدات بلا قيود |
| مدير محاسبة | 4 | المحاسبة + التقارير + المبيعات |
| مدير قسم | 3 | وحدة قسمه + التقارير |
| موظف | 2 | وحدة واحدة + الإضافة والتعديل |
| مشاهد | 1 | قراءة فقط بلا تعديل |

## 2.2 نسيت كلمة المرور
```
1. في صفحة الدخول اضغط "نسيت كلمة المرور"
2. أدخل بريدك الإلكتروني المسجل
3. ستصلك رسالة بالكود
4. أدخل الكود وأنشئ كلمة مرور جديدة
```

## 2.3 تسجيل الخروج
```
1. اضغط على اسمك في أعلى يمين الشاشة
2. اختر "تسجيل الخروج"
```

> ⚠️ **تنبيه:** النظام يسجل خروجك تلقائياً بعد 24 ساعة من عدم النشاط.

# 4. إعدادات الشركة

## 4.1 الوصول للإعدادات
```
القائمة الجانبية ← الإعدادات ← إعدادات الشركة
```

## 4.2 البيانات الأساسية للشركة

### معلومات يجب إدخالها أولاً:
```
✅ اسم الشركة (بالعربي والإنجليزي)
✅ العنوان الكامل
✅ رقم الهاتف
✅ البريد الإلكتروني
✅ الموقع الإلكتروني (اختياري)
✅ الرقم الضريبي (VAT Number)
✅ رقم السجل التجاري
✅ العملة الأساسية (ريال / دولار / جنيه...)
✅ نسبة ضريبة القيمة المضافة (15% في السعودية)
✅ شعار الشركة (صورة JPG/PNG)
```

## 4.3 إعدادات الفاتورة
```
✅ بادئة رقم الفاتورة (مثال: INV-2026-)
✅ شروط الدفع الافتراضية (30 يوم / فوري...)
✅ ملاحظات افتراضية للفاتورة
✅ هل تظهر الضريبة منفصلة؟
✅ العدد الافتراضي لنسخ الطباعة
```

## 4.4 إعدادات السنة المالية
```
1. اذهب: الإعدادات ← السنة المالية
2. حدد تاريخ بداية السنة المالية
3. حدد تاريخ نهاية السنة المالية
4. اضغط حفظ
```

> السنة المالية الحالية المفعّلة: **FY2026** (01/01/2026 → 31/12/2026)

# 5. إدارة المستخدمين والصلاحيات

## 5.1 إضافة مستخدم جديد
```
المسار: الإعدادات ← المستخدمون ← إضافة مستخدم
```

### البيانات المطلوبة:
```
✅ الاسم الكامل
✅ اسم المستخدم (بالإنجليزي بلا مسافات)
✅ كلمة المرور (يجب أن لا تكون كلمة مرور شائعة)
✅ البريد الإلكتروني
✅ رقم الهاتف
✅ القسم
✅ الدور (مدير / موظف / مشاهد)
✅ الوحدات المسموح بها
```

> ⚠️ **مهم:** لا تستخدم كلمات مرور مثل: admin123، password، 123456
> النظام يرفض هذه الكلمات لأسباب أمنية ويطلب تغييرها فوراً.

## 5.2 تعديل صلاحيات مستخدم
```
1. اذهب لقائمة المستخدمين
2. اضغط على اسم المستخدم
3. اختر "تعديل الصلاحيات"
4. فعّل أو ألغِ تفعيل الوحدات
5. اضغط حفظ
```

## 5.3 تعطيل حساب مستخدم
```
1. اذهب لقائمة المستخدمين
2. اضغط على المستخدم
3. اضغط "تعطيل الحساب"
```

> ⚠️ لا تحذف المستخدم نهائياً — عطّله فقط للحفاظ على سجل عملياته.

# 6. الدفتر المحاسبي

## 6.1 شجرة الحسابات

### الوصول:
```
القائمة ← المحاسبة ← شجرة الحسابات
```

### هيكل الحسابات:
```
1000 - الأصول
  1100 - الأصول المتداولة
    1110 - الصندوق النقدي
    1120 - البنك
    1130 - العملاء (المدينون)
    1140 - المخزون
  1200 - الأصول الثابتة
    1210 - المعدات والآلات
    1220 - السيارات

2000 - الخصوم
  2100 - الخصوم المتداولة
    2110 - الموردون (الدائنون)
    2120 - الرواتب المستحقة
  2200 - الخصوم طويلة الأجل

3000 - حقوق الملكية
  3100 - رأس المال
  3200 - الأرباح المبقاة

4000 - الإيرادات
  4100 - إيرادات المبيعات
  4200 - إيرادات أخرى

5000 - المصروفات
  5100 - تكلفة البضاعة المباعة
  5200 - مصروفات التشغيل
  5300 - مصروفات الرواتب
```

### إضافة حساب جديد:
```
1. اضغط "إضافة حساب"
2. أدخل كود الحساب (يجب أن يكون فريداً)
3. أدخل اسم الحساب بالعربي
4. أدخل اسم الحساب بالإنجليزي
5. اختر نوع الحساب (أصول/خصوم/إيرادات/مصروفات)
6. اختر الحساب الأب (Parent Account)
7. اضغط حفظ
```

## 6.2 القيود المحاسبية

### إنشاء قيد يدوي:
```
المحاسبة ← قيود يومية ← قيد جديد
```

### خطوات إنشاء القيد:
```
1. أدخل تاريخ القيد
2. أدخل رقم المرجع (اختياري)
3. أدخل الوصف
4. أضف سطور القيد:
   - السطر الأول:  الحساب المدين  → أدخل المبلغ في خانة "مدين"
   - السطر الثاني: الحساب الدائن → أدخل المبلغ في خانة "دائن"
5. تأكد أن: مجموع المدين = مجموع الدائن
6. اضغط "حفظ القيد"
7. اضغط "ترحيل" لاعتماد القيد نهائياً
```

> ⚠️ القيد المرحّل **لا يمكن تعديله** — راجع الأرقام جيداً قبل الترحيل.

### مثال على قيد شراء نقدي:
```
تاريخ: 15/01/2026
المرجع: PUR-001
الوصف: شراء مواد خام

السطر 1: 1140 - المخزون           مدين: 5,000
السطر 2: 1110 - الصندوق النقدي    دائن: 5,000

المجموع: مدين 5,000 = دائن 5,000 ✅
```

## 6.3 الأرصدة الافتتاحية
```
المحاسبة ← الأرصدة الافتتاحية
```

يجب إدخال الأرصدة الافتتاحية قبل البدء بأي عملية:
```
1. حدد تاريخ بداية العمل (مثال: 01/01/2026)
2. أدخل رصيد كل حساب من الكشف المحاسبي السابق
3. تأكد من توازن الميزانية (أصول = خصوم + حقوق ملكية)
4. اضغط "تأكيد الأرصدة الافتتاحية"
```

## 6.4 التقارير المحاسبية

| التقرير | الوصف |
|---------|-------|
| ميزان المراجعة | مجموع المدين والدائن لكل حساب |
| قائمة الدخل | الإيرادات والمصروفات والربح الصافي |
| الميزانية العمومية | الأصول والخصوم وحقوق الملكية |
| التدفق النقدي | حركة الأموال الداخلة والخارجة |
| كشف حساب | كشف مفصل لأي حساب في أي فترة |

# 7. المبيعات والفواتير

## 7.1 إنشاء فاتورة مبيعات جديدة

### المسار:
```
القائمة ← المبيعات ← فاتورة جديدة
```

### الخطوة 1: بيانات العميل
```
1. اضغط على حقل "العميل"
2. ابدأ بكتابة اسم العميل
3. اختر العميل من القائمة المنسدلة
4. إذا كان عميل جديد اضغط "+" لإضافته فوراً
```

### الخطوة 2: بيانات الفاتورة
```
• تاريخ الفاتورة   → يتعبأ تلقائياً بتاريخ اليوم
• تاريخ الاستحقاق → موعد الدفع المتفق عليه
• رقم المرجع      → رقم طلب العميل (اختياري)
• المستودع        → المستودع الذي ستنزل منه البضاعة
```

### الخطوة 3: إضافة المنتجات
```
1. اضغط "إضافة منتج"
2. ابحث عن المنتج بالاسم أو الباركود
3. أدخل الكمية
4. تحقق من السعر (يتعبأ تلقائياً)
5. عدّل السعر إذا لزم (بحسب صلاحيتك)
6. أضف الخصم (نسبة مئوية أو مبلغ ثابت)
7. كرر لكل منتج
```

### الخطوة 4: الملخص المالي
```
المجموع قبل الضريبة : xxxx
الخصم               : xxxx
ضريبة القيمة المضافة: xxxx (15%)
الإجمالي النهائي    : xxxx
```

### الخطوة 5: الحفظ
```
"حفظ كمسودة"     → للحفظ المؤقت (لا يخصم المخزون)
"تأكيد الفاتورة" → للاعتماد النهائي (يخصم المخزون ويُنشئ قيداً)
```

## 7.2 حالات الفاتورة
```
مسودة          → لم تُؤكد بعد
مؤكدة          → معتمدة وخصمت المخزون
مدفوعة جزئياً  → دُفع جزء منها
مدفوعة         → تم التحصيل الكامل
ملغية          → تم إلغاؤها
```

## 7.3 تسجيل دفعة على فاتورة
```
1. افتح الفاتورة
2. اضغط "تسجيل دفعة"
3. أدخل المبلغ المدفوع
4. اختر طريقة الدفع:
   • نقدي
   • تحويل بنكي
   • شيك
   • بطاقة ائتمان
5. أدخل رقم المرجع (رقم الشيك / التحويل)
6. اضغط حفظ
```

## 7.4 إدارة العملاء

### إضافة عميل جديد:
```
المبيعات ← العملاء ← عميل جديد
```

**البيانات المطلوبة:**
```
✅ الاسم الكامل (أو اسم الشركة)
✅ نوع العميل (فرد / شركة)
✅ رقم الهاتف
✅ البريد الإلكتروني
✅ العنوان
✅ الرقم الضريبي (للشركات)
✅ حد الائتمان (الحد الأقصى للمديونية)
✅ شروط الدفع الافتراضية
✅ مستوى السعر (A / B / C)
```

## 7.5 الفواتير المتكررة
```
للعملاء الذين لهم فواتير شهرية ثابتة:
1. أنشئ الفاتورة الأولى
2. اضغط "جعلها متكررة"
3. حدد التكرار (أسبوعي / شهري / ربع سنوي)
4. حدد تاريخ البداية والنهاية
→ النظام يُنشئ الفواتير تلقائياً
```

# 8. المشتريات

## 8.1 طلب الشراء (Purchase Order)

```
القائمة ← المشتريات ← طلب شراء جديد
```

**الخطوات:**
```
1. اختر المورد
2. حدد تاريخ الطلب
3. حدد التاريخ المتوقع للاستلام
4. أضف المنتجات المطلوبة والكميات
5. اضغط "حفظ الطلب"
6. أرسله للمورد: اضغط "إرسال للمورد"
```

**حالات طلب الشراء:**
```
معلق   → انتظار الموافقة
معتمد  → تمت الموافقة الداخلية
مُرسَل → أُرسل للمورد
مستلم  → استُلمت البضاعة فعلياً
ملغى   → تم الإلغاء
```

## 8.2 استلام البضاعة
```
عند وصول البضاعة:
1. افتح طلب الشراء المرتبط
2. اضغط "تسجيل استلام"
3. أدخل الكميات المستلمة فعلياً
4. أدخل رقم الفاتورة من المورد
5. تحقق من الأسعار
6. اضغط "تأكيد الاستلام"
```

> البضاعة تُضاف للمخزون تلقائياً عند التأكيد.

## 8.3 إضافة مورد جديد
```
المشتريات ← الموردون ← مورد جديد
```

**البيانات المطلوبة:**
```
✅ اسم المورد / الشركة
✅ اسم مندوب المبيعات
✅ رقم الهاتف
✅ رقم الجوال
✅ البريد الإلكتروني
✅ العنوان
✅ الرقم الضريبي
✅ رقم الحساب البنكي (للدفع)
✅ شروط الدفع المتفق عليها
✅ فئة المورد (مواد خام / قطع غيار / خدمات...)
```

# 9. المخزون والمستودعات

## 9.1 إضافة مستودع
```
المخزون ← المستودعات ← مستودع جديد

✅ اسم المستودع
✅ الموقع / العنوان
✅ المسؤول عن المستودع
✅ الطاقة الاستيعابية (اختياري)
✅ النوع: إنتاج / معارض / تخزين عام
```

## 9.2 إضافة منتج جديد
```
المخزون ← المنتجات ← منتج جديد
```

### البيانات الأساسية:
```
✅ اسم المنتج (عربي)
✅ اسم المنتج (إنجليزي)
✅ كود المنتج / SKU
✅ الباركود (أو اتركه فارغاً للتوليد التلقائي)
✅ الفئة (الرئيسية والفرعية)
✅ وحدة القياس (قطعة / كيلو / متر / صندوق...)
✅ سعر الشراء
✅ سعر البيع A (التجزئة)
✅ سعر البيع B (الجملة)
✅ سعر البيع C (العملاء الخاص)
✅ الحد الأدنى للمخزون (للتنبيه)
✅ الحد الأقصى للمخزون
✅ هل خاضع للضريبة؟
✅ صورة المنتج (اختياري)
```

### بيانات الإنتاج (للمصنع):
```
✅ المواد الخام المكوّنة (BOM)
✅ وقت التصنيع بالدقائق
✅ الخط الإنتاجي
✅ المواصفات الفنية
```

## 9.3 تسوية الجرد
```
المخزون ← الجرد ← جرد جديد

1. حدد المستودع
2. حدد تاريخ الجرد
3. اضغط "بدء الجرد"
4. النظام يعرض الكميات الدفترية
5. أدخل الكميات الفعلية
6. النظام يحسب الفرق تلقائياً
7. إذا كان هناك فرق أدخل السبب
8. اضغط "تأكيد الجرد"
```

## 9.4 تحويل بضاعة بين مستودعات
```
المخزون ← التحويلات ← تحويل جديد

1. اختر المستودع المصدر
2. اختر المستودع الوجهة
3. أضف المنتجات والكميات
4. أدخل سبب التحويل
5. اضغط "تأكيد التحويل"
```

# 10. الموارد البشرية

## 10.1 إضافة موظف جديد

# 11. الرواتب والسلف

## 11.1 مسير الرواتب الشهري
```
HR ← الرواتب ← مسير راتب جديد

الخطوة 1: اختر الشهر والسنة
الخطوة 2: اضغط "توليد الرواتب"
الخطوة 3: راجع الأرقام وعدّل إذا لزم
الخطوة 4: اضغط "اعتماد المسير"
الخطوة 5: طباعة كشوف الرواتب
```

### مكونات الراتب:
```
المستحقات (+):
  + الراتب الأساسي
  + بدل السكن
  + بدل النقل
  + بدل الهاتف
  + العمل الإضافي
  + الحوافز والمكافآت
  = إجمالي المستحقات

الاستقطاعات (-):
  - خصم الغياب
  - خصم التأخير
  - أقساط السلف
  - أقساط القروض
  - الغرامات
  = إجمالي الاستقطاعات

صافي الراتب = المستحقات - الاستقطاعات
```

## 11.2 إدارة السلف
```
HR ← السلف ← طلب سلفة جديد

1. اختر الموظف
2. أدخل مبلغ السلفة
3. سبب السلفة
4. طريقة السداد:
   • خصم من راتب شهر واحد
   • تقسيط على عدة أشهر
5. عدد الأقساط وتاريخ بداية الخصم
6. اضغط "تقديم الطلب"
```

> النظام يخصم القسط تلقائياً من الراتب كل شهر حتى السداد الكامل.

# 12. الإنتاج

## 12.1 قائمة المواد BOM
```
الإنتاج ← قوائم المواد ← BOM جديد

1. اختر المنتج النهائي
2. أضف المواد الخام (لكل مادة: الكمية + الوحدة)
3. أضف مراحل التصنيع
4. أضف وقت التصنيع المتوقع
5. اضغط حفظ
```

### مثال BOM لسرير 200×200:
```
المنتج: سرير 200×200

المواد:
• قماش الغطاء الخارجي : 5 متر
• اسفنج كثافة 40      : 10 كيلو
• سلك نابض            : 8 كيلو
• إطار خشبي           : 1 قطعة
• خيط تخييط           : 200 متر
• أشرطة تثبيت         : 4 قطع

وقت التصنيع: 45 دقيقة
```

## 12.2 أوامر الإنتاج
```
الإنتاج ← أوامر الإنتاج ← أمر جديد

1. اختر المنتج
2. أدخل الكمية المطلوبة
3. تاريخ البداية والإنجاز المتوقع
4. اختر خط الإنتاج والمشرف
5. اضغط "إنشاء الأمر"
```

### حالات أمر الإنتاج:
```
مخطط         → لم يبدأ بعد
قيد التنفيذ  → يعمل حالياً
متوقف        → توقف مؤقت (نقص مواد / عطل)
مكتمل        → انتهى الإنتاج
ملغى         → تم الإلغاء
```

### تسجيل إنجاز الإنتاج:
```
1. افتح أمر الإنتاج
2. اضغط "تسجيل الإنجاز"
3. أدخل الكمية المنتجة فعلياً
4. أدخل الكمية المُتلفة وسببها
5. اضغط "إغلاق الأمر"
```

# 13. نقطة البيع POS

## 13.1 فتح جلسة البيع
```
POS ← فتح جلسة

1. أدخل رصيد الصندوق الافتتاحي
   (المبلغ النقدي الموجود في الدرج)
2. اضغط "فتح الجلسة"
```

## 13.2 إجراء عملية بيع
```
1. ابحث عن المنتج بالاسم أو امسح الباركود
2. اضغط على المنتج لإضافته
3. عدّل الكمية إذا لزم
4. كرر لكل منتج
5. أضف الخصم (إذا كان مسموحاً)
6. اضغط "الدفع"
7. اختر طريقة الدفع:
   • نقدي  → أدخل المبلغ المستلم
   • بطاقة → المبلغ يُدخل مباشرة
   • تقسيط → أدخل الدفعة الأولى
8. اضغط "إتمام البيع"
9. اطبع الإيصال
```

## 13.3 طلب معلق (Layaway)
```
للعملاء الذين يريدون حجز البضاعة ودفع لاحقاً:
1. أضف المنتجات
2. اضغط "تعليق الطلب"
3. أدخل اسم العميل ورقم الاتصال
4. اضغط حفظ

لاسترجاعه: اضغط "الطلبات المعلقة" واختر الطلب
```

## 13.4 مرتجع مبيعات من POS
```
POS ← مرتجعات

1. أدخل رقم الفاتورة الأصلية
2. اختر المنتجات المرتجعة
3. أدخل سبب الإرجاع
4. اختر طريقة الاسترداد:
   • استرداد نقدي
   • استبدال بمنتج آخر
   • رصيد دائن للعميل
5. اضغط تأكيد
```

## 13.5 إغلاق جلسة البيع
```
POS ← إغلاق الجلسة

1. عد النقود في الدرج
2. أدخل المبلغ الفعلي
3. النظام يعرض الفرق مع المتوقع
4. إذا كان هناك فرق أدخل السبب
5. اضغط "إغلاق الجلسة"
6. اطبع تقرير اليوم
```

# 21. الأخطاء الشائعة وحلولها

## 21.1 مشاكل تسجيل الدخول

| المشكلة | الحل |
|---------|------|
| "كلمة مرور خاطئة" | تأكد من Caps Lock، جرب "نسيت كلمة المرور" |
| "الحساب معطل" | تواصل مع مدير النظام |
| "جلسة منتهية" | سجّل دخولك مرة أخرى |
| يُطلب منك تغيير كلمة المرور | كلمة مرورك من الكلمات المحظورة — غيّرها فوراً |
| الصفحة لا تفتح | تحقق من الاتصال بالإنترنت أو تواصل مع IT |

## 21.2 مشاكل الفواتير

| المشكلة | الحل |
|---------|------|
| "المنتج غير موجود بالمخزون" | تحقق من رصيد المخزون أو غير المستودع |
| "العميل تجاوز حد الائتمان" | خفف المبلغ أو اطلب تأذيناً من المدير |
| "الفاتورة لا تُحفظ" | تأكد من ملء جميع الحقول الإلزامية (*) |
| "لا يمكن تعديل الفاتورة" | الفاتورة المؤكدة لا تُعدل — أنشئ مرتجعاً بدلاً منها |

## 21.3 مشاكل الطباعة

| المشكلة | الحل |
|---------|------|
| الطابعة لا تظهر | تأكد من تثبيت Print Agent وتشغيله |
| الطباعة بطيئة | استخدم تصدير PDF ثم اطبع |
| الأحرف العربية غير واضحة | تأكد من دعم الطابعة للغة العربية |

## 21.4 مشاكل المخزون

| المشكلة | الحل |
|---------|------|
| "الكمية سالبة" | راجع حركات المخزون وأجرِ تسوية جرد |
| "المنتج غير موجود" | تأكد من الكود الصحيح أو أضف المنتج |
| لا تتطابق الكمية الفعلية مع الدفترية | أجرِ جرد وسوّ الفرق مع ذكر السبب |
