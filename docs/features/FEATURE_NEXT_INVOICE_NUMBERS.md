# ✅ تم إضافة ميزة معاينة أرقام الفواتير التالية

## 📋 الملخص

تم إضافة ميزة جديدة تسمح لك برؤية أرقام الفواتير التي سيتم توليدها تلقائياً قبل إنشاء الفواتير الفعلية. هذا مفيد جداً للتخطيط المحاسبي واستخدام الأرقام في معاملات أخرى.

## 🎯 الميزات المضافة

### 1. صفحة ويب تفاعلية
- عرض جميع أرقام الفواتير التالية في صفحة واحدة
- تصميم جميل وسهل الاستخدام
- إمكانية نسخ الأرقام بضغطة زر

**الرابط**: `/sales/next-numbers/`

### 2. API للمطورين
- استرجاع الأرقام بصيغة JSON
- سهل التكامل مع أنظمة أخرى

**الرابط**: `/sales/api/next-numbers/`

### 3. أمر سطر الأوامر
```bash
python3 manage.py show_next_invoice_numbers
```

### 4. Widget للوحة التحكم
يمكن إضافته في أي صفحة:
```django
{% include 'widgets/next_invoice_number_widget.html' %}
```

## 🚀 كيفية الاستخدام

### من المتصفح
1. افتح: `http://your-domain.com/sales/next-numbers/`
2. شاهد جميع الأرقام
3. انسخ الرقم الذي تحتاجه

### من Python
```python
from sales.next_invoice_number import preview_invoice_numbers

numbers = preview_invoice_numbers()
print(numbers['sales_invoice'])        # INV-202601-000123
print(numbers['tax_sales'])            # TAX-S-202601-00045
```

### من JavaScript
```javascript
fetch('/sales/api/next-numbers/')
    .then(response => response.json())
    .then(data => {
        console.log(data.next_numbers);
    });
```

### من Terminal
```bash
cd /var/www/tony_erp
python3 manage.py show_next_invoice_numbers
```

## ⚠️ ملاحظات مهمة

1. **الأرقام تقديرية**: قد تتغير إذا تم إنشاء فاتورة جديدة من نفس النوع
2. **الأرقام الفعلية مضمونة**: عند إنشاء الفاتورة، يتم توليد رقم فريد ومضمون
3. **التسلسل شهري**: يبدأ الترقيم من جديد كل شهر
4. **لا تكرار**: النظام يضمن عدم تكرار الأرقام
