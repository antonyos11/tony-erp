## 🎯 نظرة عامة

نظام شامل لإدارة مصنع المراتب والمفروشات يشمل:

### ✅ المميزات الرئيسية
- **إدارة المواد الخام**: تتبع أكثر من 100+ مادة خام مختلفة
- **قوائم المواد (BOM)**: حساب تلقائي للتكاليف والكميات المطلوبة
- **وحدات قياس متعددة**: دعم التحويل بين وحدات الشراء والاستخدام
- **تتبع الهدر**: احتساب نسبة الهدر لكل مادة
- **إدارة المخزون**: تنبيهات تلقائية عند نقص المواد
- **تقارير شاملة**: تقارير التكلفة والاستهلاك والإنتاج

## 🧱 إدارة المواد الخام

### التصنيفات الرئيسية

```
📂 مواد خام
   ├─ سوست ونوابض
   │  ├─ سوست بونيل
   │  ├─ سوست متصلة
   │  ├─ سوست منفصلة (Pocket Spring)
   │  └─ أسلاك فولاذية
   │
   ├─ إطارات
   │  ├─ إطارات معدنية
   │  └─ إطارات خشبية
   │
   ├─ إسفنج وفوم
   │  ├─ فوم عادي
   │  ├─ فوم عالي الكثافة
   │  ├─ فوم ميموري
   │  ├─ فوم لاتكس
   │  └─ فوم جل
   │
   ├─ حشوات
   │  ├─ لباد
   │  ├─ فيبر
   │  ├─ قطن
   │  ├─ صوف
   │  └─ ريش
   │
   ├─ أقمشة
   │  ├─ أقمشة تنجيد
   │  ├─ أقمشة مفروشات
   │  └─ أقمشة خاصة (مضادة للبكتيريا، تبريد، إلخ)
   │
   └─ مستهلكات
      ├─ خيوط
      ├─ لواصق
      ├─ إكسسوارات
      └─ تغليف
```

### إضافة مادة خام جديدة

1. اذهب إلى: **المخزون > المنتجات > إضافة منتج جديد**
2. املأ البيانات:
   - **SKU**: كود فريد (مثل: `FOAM-D25`)
   - **الاسم**: اسم واضح (مثل: `فوم عادي كثافة 25`)
   - **نوع المنتج**: اختر `مادة خام`
   - **الفئة**: اختر الفئة المناسبة
   - **وحدة الشراء**: كيف تشتريها (كجم، متر، وحدة، لفة)
   - **وحدة الاستخدام**: كيف تستخدمها في الإنتاج
   - **معامل التحويل**: إذا كانت الوحدات مختلفة
   - **التكلفة**: سعر الشراء
   - **الحد الأدنى**: للتنبيه عند النقص

### مثال: إضافة خيط خياطة

```
SKU: THR-POL-001
الاسم: خيط بوليستر أبيض
نوع المنتج: مادة خام
الفئة: مستهلكات > خيوط
وحدة الشراء: لفة (roll)
وحدة الاستخدام: متر (m)
معامل التحويل: 5000 (كل لفة = 5000 متر)
التكلفة: 45.00 جنيه
الحد الأدنى: 200 لفة
```

## 📊 قوائم المواد (BOM)

### ما هي قائمة المواد؟

قائمة المواد (Bill of Materials) هي وصفة الإنتاج التي تحدد:
- المواد الخام المطلوبة لإنتاج منتج واحد
- كمية كل مادة
- نسبة الهدر المتوقعة
- التكلفة الإجمالية

### إنشاء BOM جديد

1. اذهب إلى: **الإنتاج > قوائم المواد > إضافة قائمة جديدة**
2. اختر المنتج النهائي
3. أضف المواد الخام واحدة تلو الأخرى
4. لكل مادة حدد:
   - الكمية المطلوبة
   - نسبة الهدر (%)
   - نوع العنصر (مادة خام / مكون / مستهلكات)

### حساب التكلفة التلقائي

النظام يحسب تلقائياً:
```
تكلفة المادة = (الكمية × (1 + نسبة الهدر/100)) × سعر الوحدة
التكلفة الإجمالية = مجموع تكاليف جميع المواد
```

## 🎯 نصائح وأفضل الممارسات

### 1. تنظيم المواد الخام

✅ **افعل:**
- استخدم أكواد SKU واضحة ومنطقية (مثل: `FOAM-D25`, `SPR-BNL-100`)
- صنف المواد في الفئات المناسبة
- حدّث الأسعار بانتظام
- اربط كل مادة بالمورد المفضل

❌ **لا تفعل:**
- لا تستخدم أكواد عشوائية
- لا تترك مواد بدون فئة
- لا تهمل تحديث الأسعار

### 2. إدارة قوائم المواد (BOM)

✅ **افعل:**
- راجع قوائم المواد دورياً
- احسب نسبة الهدر بدقة من الواقع
- اجعل لكل منتج BOM افتراضي واحد
- وثّق أي تغييرات في الإصدارات

❌ **لا تفعل:**
- لا تبالغ في نسبة الهدر (تزيد التكلفة)
- لا تقلل نسبة الهدر (قد تسبب نقص)
- لا تنسى تحديث BOM عند تغيير المواد

### 3. إدارة المخزون

✅ **افعل:**
- حدد الحد الأدنى لكل مادة بناءً على:
  - معدل الاستهلاك الشهري
  - مدة التوريد من المورد
  - المساحة التخزينية المتاحة
- راجع تقارير المخزون أسبوعياً
- استخدم الباركود لتسريع العمليات

❌ **لا تفعل:**
- لا تخزن كميات زائدة (تكلفة تخزين)
- لا تنتظر حتى نفاد المخزون
- لا تهمل الجرد الدوري

### 4. وحدات القياس

✅ **افعل:**
- استخدم وحدة الشراء الفعلية (كما تشتري من المورد)
- استخدم وحدة الاستخدام الفعلية (كما تستخدم في الإنتاج)
- حدد معامل التحويل بدقة

**أمثلة:**
```
خيط خياطة:
  وحدة الشراء: لفة (roll)
  وحدة الاستخدام: متر (m)
  معامل التحويل: 5000 (كل لفة = 5000 متر)

إسفنج:
  وحدة الشراء: كجم (kg)
  وحدة الاستخدام: كجم (kg)
  معامل التحويل: 1 (نفس الوحدة)

قماش:
  وحدة الشراء: متر (m)
  وحدة الاستخدام: متر (m)
  معامل التحويل: 1 (نفس الوحدة)
```

### 5. التكاليف والتسعير

✅ **افعل:**
- احسب التكلفة الفعلية من BOM
- أضف تكلفة العمالة والتشغيل
- أضف هامش ربح مناسب
- راجع الأسعار مع المنافسين

**معادلة التسعير:**
```
سعر البيع = تكلفة المواد + تكلفة العمالة + تكلفة التشغيل + هامش الربح

مثال:
تكلفة المواد: 1,485 جنيه
تكلفة العمالة: 200 جنيه
تكلفة التشغيل: 150 جنيه
هامش الربح (30%): 550 جنيه
─────────────────────────────
سعر البيع: 2,385 جنيه
```

## 📈 التقارير المفيدة

### 1. تقرير استهلاك المواد الخام
- يوضح كمية كل مادة مستخدمة في فترة معينة
- يساعد في التخطيط للشراء

### 2. تقرير تكلفة الإنتاج
- يحسب التكلفة الفعلية لكل منتج
- يقارن مع التكلفة المخططة

### 3. تقرير المواد الناقصة
- يعرض المواد التي وصلت للحد الأدنى
- يقترح كميات الشراء المطلوبة

### 4. تقرير الموردين والأسعار
- يقارن أسعار نفس المادة من موردين مختلفين
- يساعد في اختيار أفضل مورد

## 🔧 استكشاف الأخطاء

### مشكلة: المادة الخام لا تظهر في BOM

**الحل:**
1. تأكد أن نوع المنتج = "مادة خام"
2. تأكد أن المنتج نشط (is_active = True)
3. تأكد من وجود كمية في المخزون

### مشكلة: التكلفة المحسوبة خاطئة

**الحل:**
1. راجع أسعار المواد الخام
2. تأكد من نسبة الهدر
3. تأكد من معامل التحويل بين الوحدات

### مشكلة: تنبيه نقص مخزون مستمر

**الحل:**
1. راجع الحد الأدنى للمخزون
2. زد كمية الشراء
3. قلل الحد الأدنى إذا كان مبالغاً فيه
