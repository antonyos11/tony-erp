## 🎯 كيفية الاستخدام

### البدء السريع

1. **افتح جلسة POS جديدة**
   - اضغط F1 للذهاب للوحة التحكم
   - اختر "فتح جلسة"

2. **ابدأ البيع**
   - ابحث عن منتج (F2)
   - انقر على المنتج لإضافته
   - أو اكتب الباركود واضغط Enter

3. **إدارة السلة**
   - استخدم +/- لتعديل الكمية
   - انقر على أيقونة القلم لتعديل السعر
   - انقر على % للخصم السريع

4. **إتمام البيع**
   - اضغط F8 أو زر "الدفع"
   - اختر طريقة الدفع
   - أكمل العملية

### الاختصارات الأساسية

| المفتاح | الوظيفة |
|---------|---------|
| F2 | بحث عن منتج |
| F8 | الدفع |
| F9 | تعليق الطلب |
| F11 | آلة حاسبة |
| Ctrl+D | خصم |
