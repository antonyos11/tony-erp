# 🏭 نظام إدارة المواد الخام لمصنع المراتب
## دليل الاستخدام الشامل

تم تطوير نظام متكامل لإدارة المواد الخام مع دعم كامل للباركود اليدوي والتلقائي، ووحدات القياس المتعددة.

---

## ✨ الميزات الجديدة

### 1. **نظام المواد الخام المتقدم**

#### أنواع المنتجات المدعومة:
- ✅ **مادة خام** (Raw Material) - مثل الإسفنج، المنجر، القماش
- ✅ **نصف مصنع** (Semi-Finished) - منتجات في مراحل الإنتاج
- ✅ **منتج تام** (Finished Product) - المراتب الجاهزة
- ✅ **قطع غيار** (Spare Parts)
- ✅ **خدمات** (Services)

---

### 2. **وحدات القياس المتعددة**

النظام يدعم الآن **10 وحدات قياس مختلفة**:

| الوحدة | الرمز | الاستخدام |
|--------|------|-----------|
| وحدة/قطعة | unit | العد بالقطع |
| كيلوجرام | kg | الوزن - الإسفنج، القماش |
| جرام | g | المواد الصغيرة |
| طن | ton | الكميات الكبيرة |
| متر | m | القماش، الخشب |
| **متر مكعب** | **m3** | **الإسفنج بالحجم** |
| لتر | liter | السوائل، الغراء |
| صندوق | box | التعبئة |
| لفة | roll | القماش الملفوف |

#### ميزة التحويل بين الوحدات:
- **وحدة الشراء**: الوحدة التي تشتري بها من المورد (مثل: متر مكعب)
- **وحدة الاستخدام**: الوحدة في الإنتاج (مثل: كيلوجرام)
- **معامل التحويل**: كم وحدة استخدام = 1 وحدة شراء

**مثال عملي:**
```
إسفنج عالي الكثافة:
- وحدة الشراء: 1 متر مكعب (m³)
- وحدة الاستخدام: كيلوجرام (kg)
- معامل التحويل: 35 (أي 1 م³ = 35 كجم)

المنجر:
- وحدة الشراء: متر (m)
- وحدة الاستخدام: سنتيمتر (cm)
- معامل التحويل: 100
```

---

### 3. **نظام الباركود الذكي**

#### الباركود اليدوي:
- ✅ إدخال باركود موجود على المنتج من المورد
- ✅ التحقق من عدم التكرار
- ✅ إمكانية المسح الضوئي

#### الباركود التلقائي:
- ✅ توليد باركود فريد تلقائياً عند الحفظ
- ✅ استخدام معيار Code-128
- ✅ ضمان عدم التكرار

#### طباعة الباركود:
- ✅ طباعة ملصقات بأحجام مختلفة (صغير/متوسط/كبير)
- ✅ طباعة عدة نسخ (حتى 100 نسخة)
- ✅ إظهار/إخفاء اسم المنتج والسعر
- ✅ دعم أنواع باركود متعددة (Code-128, Code-39, EAN-13)
- ✅ معاينة قبل الطباعة

---

### 4. **إدارة الموردين المتعددة**

- ✅ **مورد رئيسي/مفضل**: المورد الأساسي للمادة
- ✅ **موردين بديلين**: قائمة بالموردين الاحتياطيين
- ✅ ربط سريع بصفحة إضافة مورد جديد
- ✅ عرض معلومات الاتصال بكل مورد

## 📋 كيفية الاستخدام

### 1. إنشاء مخزن للمواد الخام

```
1. اذهب إلى: المخزون → المخازن → إضافة مخزن
2. اختر النوع: "خامات" (Raw Materials)
3. أدخل الاسم والكود (مثال: RAW-MAIN)
4. احفظ المخزن
```

**رابط مباشر:**
```
http://your-server/inventory/locations/add/?type=raw
```

---

### 2. إضافة مادة خام جديدة

#### الطريقة الأولى: عبر الصفحة المخصصة

```
1. اذهب إلى: المخزون → المنتجات → إضافة مادة خام
   الرابط: /inventory/products/raw-material/create/

2. املأ البيانات الأساسية:
   - اسم المادة: "إسفنج عالي الكثافة 35"
   - رمز المنتج (SKU): RAW-FOAM-001 (أو اضغط توليد تلقائي)
   - الفئة: اختر أو أضف فئة "إسفنج"

3. نظام الباركود:
   أ) باركود يدوي:
      - فعّل "باركود يدوي"
      - أدخل الباركود الموجود على المنتج
   
   ب) باركود تلقائي:
      - اترك الخيار معطلاً
      - سيتم التوليد تلقائياً

4. وحدات القياس:
   - وحدة الشراء: متر مكعب (m³)
   - وحدة الاستخدام: كيلوجرام (kg)
   - معامل التحويل: 35.0000
   
   → المعاينة: 1 م³ = 35 كجم

5. التسعير:
   - تكلفة الوحدة: 1500 ج.م / م³
   - الحد الأدنى للمخزون: 5 م³

6. الموردين:
   - اختر المورد الرئيسي
   - حدد موردين بديلين (اختياري)

7. المخزن:
   - اختر مخزن المواد الخام

8. احفظ
```

---

### 3. طباعة الباركود

بعد إضافة المادة، يمكنك طباعة باركودات:

```
1. من صفحة المنتج، اضغط "طباعة باركود"
   أو: /inventory/products/{id}/print-barcode/

2. اختر الإعدادات:
   - عدد النسخ: 10 (مثلاً)
   - حجم الملصق: متوسط
   - إظهار اسم المنتج: ✓
   - إظهار السعر: ✓
   - نوع الباركود: Code 128

3. معاينة الملصقات

4. اضغط "طباعة الملصقات"
```

---

### 4. إضافة منجر من مورد مختلف

**مثال: منجر خشب زان من 3 موردين**

```
المادة: منجر خشب زان 5×10 سم
SKU: RAW-WOOD-001

وحدة الشراء: متر (m)
وحدة الاستخدام: سنتيمتر (cm)
معامل التحويل: 100

المورد الرئيسي: شركة الأخشاب المصرية
الموردين البديلين:
  - مورد الخشب الفاخر
  - الشركة العالمية للأخشاب

الباركود: يدوي (إذا كان مطبوع على المنتج)
         أو تلقائي
```

## 🎯 أمثلة عملية لمصنع المراتب

### مثال 1: إسفنج

```yaml
اسم المادة: إسفنج كثافة 35 - أبيض
SKU: RAW-FOAM-35-W
الفئة: إسفنج

وحدة الشراء: متر مكعب (m³)
وحدة الاستخدام: كيلوجرام (kg)
معامل التحويل: 35

تكلفة الوحدة: 1500 ج.م / م³
الحد الأدنى: 5 م³

المورد الرئيسي: شركة الإسفنج الفاخر
باركود: تلقائي
```

### مثال 2: منجر

```yaml
اسم المادة: منجر خشب زان 5×10
SKU: RAW-WOOD-BEECH-510
الفئة: أخشاب

وحدة الشراء: متر (m)
وحدة الاستخدام: سنتيمتر (cm)
معامل التحويل: 100

تكلفة الوحدة: 180 ج.م / متر
الحد الأدنى: 50 م

الموردين:
  - مورد أساسي: الأخشاب المصرية
  - بديل 1: شركة الخشب الفاخر
  - بديل 2: مورد الخشب العالمي

باركود: يدوي (إذا موجود) أو تلقائي
```

### مثال 3: قماش

```yaml
اسم المادة: قماش دمسكو - أزرق
SKU: RAW-FABRIC-DAMASK-B
الفئة: أقمشة

وحدة الشراء: لفة (roll)
وحدة الاستخدام: متر (m)
معامل التحويل: 50 (50 متر/لفة)

تكلفة الوحدة: 1200 ج.م / لفة
الحد الأدنى: 3 لفات

باركود: تلقائي
```

## 🔍 البحث والفلترة

يمكنك البحث عن المواد الخام:

```
1. قائمة المنتجات → فلتر حسب النوع: "مادة خام"
2. البحث بالباركود: استخدم قارئ الباركود
3. الفلترة حسب:
   - المورد
   - الفئة
   - وحدة القياس
   - المخزن
```


## 💡 نصائح مهمة

### 1. تنظيم الفئات
```
إنشاء فئات منظمة:
- إسفنج
  - إسفنج كثافة 25
  - إسفنج كثافة 35
  - إسفنج كثافة 40
- أخشاب
  - خشب زان
  - خشب سويدي
- أقمشة
  - قماش دمسكو
  - قماش قطني
```

### 2. معايير التسمية
```
استخدم نظام واضح:
RAW-{النوع}-{المواصفات}-{رقم}

أمثلة:
- RAW-FOAM-35-001
- RAW-WOOD-BEECH-001
- RAW-FABRIC-DAMASK-001
```

### 3. الباركود
```
- استخدم الباركود اليدوي إذا كان موجوداً على المنتج
- اطبع باركودات فوراً بعد الإضافة
- احتفظ بنسخ احتياطية من الباركودات
```

### 4. الموردين
```
- حدد مورد رئيسي دائماً
- أضف موردين بديلين للمواد المهمة
- حدّث بيانات الاتصال بالموردين دورياً
```

## 🔧 الصيانة والدعم

### مشاكل شائعة وحلولها:

#### 1. لا يظهر الباركود في الطباعة
```
الحل:
- تأكد من وجود رقم باركود للمنتج
- تحقق من اتصال الإنترنت (لتحميل مكتبة JsBarcode)
- جرب نوع باركود مختلف
```

#### 2. خطأ في معامل التحويل
```
الحل:
- تأكد من إدخال رقم صحيح
- استخدم 4 منازل عشرية للدقة
- مثال: 35.0000 وليس 35
```

#### 3. تكرار الباركود
```
الحل:
- في الوضع اليدوي: أدخل باركود مختلف
- في الوضع التلقائي: سيتم التوليد تلقائياً بدون تكرار
```
