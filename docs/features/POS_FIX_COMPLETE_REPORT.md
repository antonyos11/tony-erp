## 🚀 طريقة الاستخدام

### فتح جلسة
1. اذهب إلى `/pos/`
2. إذا لم تكن هناك جلسة نشطة، اضغط "فتح جلسة"
3. أدخل الرصيد الافتتاحي
4. اضغط "فتح"

### إنشاء طلب
1. اضغط "طلب جديد" أو `F3`
2. ابحث عن المنتجات بالاسم أو الباركود
3. اضغط على المنتج لإضافته للسلة
4. عدّل الكميات والأسعار حسب الحاجة

### إتمام الدفع
1. راجع العناصر في السلة
2. اضغط زر "الدفع" أو `F8`
3. اختر طريقة الدفع
4. أدخل المبلغ المدفوع
5. اضغط "تأكيد الدفع"
6. سيتم تحويلك لصفحة الإيصال تلقائياً

### تعليق الطلب
1. اضغط أيقونة التعليق ⏸️ أو `F9`
2. أدخل ملاحظة واسم العميل (اختياري)
3. الطلب محفوظ، يمكن استعادته لاحقاً

### استعادة طلب معلق
1. اضغط زر "معلقة" أو `F10`
2. اختر الطلب من القائمة
3. اضغط "استعادة"
4. يتم تحميل الطلب في السلة
