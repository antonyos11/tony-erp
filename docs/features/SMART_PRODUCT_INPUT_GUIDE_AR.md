## 🎯 الميزة الأولى: نسخ المنتج (Duplicate Product)

### الوصف
تمكن هذه الميزة من نسخ منتج موجود لإنشاء منتج جديد بنفس المواصفات مع تعديل البيانات الفريدة تلقائياً.

### المميزات
✅ نسخ جميع البيانات الأساسية (الفئة، الوحدات، الأسعار، الأبعاد)
✅ توليد SKU جديد تلقائياً  
✅ توليد باركود جديد تلقائياً
✅ نسخ جميع أسعار الموردين
✅ نسخ وحدات التعبئة
✅ إضافة "(نسخة)" في اسم المنتج الجديد

### كيفية الاستخدام

#### من قائمة المنتجات:
1. اذهب إلى **المخزون → المنتجات**
2. ابحث عن المنتج المراد نسخه
3. انقر على زر **نسخ** (أيقونة الملفات) في عمود الإجراءات
4. ستفتح صفحة إضافة منتج جديد مع جميع البيانات
5. عدّل البيانات حسب الحاجة
6. انقر **حفظ**

#### من صفحة تفاصيل المنتج:
1. افتح تفاصيل المنتج
2. انقر على زر **نسخ المنتج** (زر أزرق)
3. ستُملأ جميع البيانات تلقائياً
4. عدّل ما تشاء وانقر **حفظ**

### المسارات (URLs)
```
/inventory/products/<product_id>/duplicate/  GET
/inventory/products/<product_id>/duplicate/  POST
```

### الكود المرتبط
- **View:** `views.product_duplicate()`
- **URL:** `path('products/<int:pk>/duplicate/', views.product_duplicate, name='product_duplicate')`

## 🎯 الميزة الثانية: استيراد من Excel/CSV (Bulk Import)

### الوصف
استيراد مئات أو آلاف المنتجات دفعة واحدة من ملف Excel أو CSV مع التحقق الآلي من البيانات.

### المميزات
✅ دعم ملفات Excel (.xlsx) و CSV
✅ قالب Excel جاهز للتحميل
✅ معالجة سريعة للبيانات
✅ التحقق الآلي من البيانات
✅ معاينة النتائج قبل الحفظ
✅ تقرير مفصل للأخطاء والنجاحات
✅ توليد SKU والباركود تلقائياً
✅ ربط المنتجات بالموردين تلقائياً

### الأعمدة المدعومة

| العمود | مطلوب | الوصف |
|--------|-------|-------|
| **اسم المنتج** | ✅ | اسم المنتج أو المادة الخام |
| **SKU** | ❌ | رمز المنتج (سيُولد تلقائياً) |
| **نوع المنتج** | ❌ | raw_material, finished, semi_finished, accessory |
| **نوع المادة الخام** | ❌ | foam, fabric, spring, wood, metal, chemical, packaging, other |
| **الفئة** | ❌ | اسم الفئة (يجب أن تكون موجودة) |
| **وحدة الشراء** | ❌ | unit, kg, m, m2, m3, roll, sheet, box |
| **وحدة الاستخدام** | ❌ | unit, kg, m, m2, m3, piece |
| **معامل التحويل** | ❌ | عدد وحدات الاستخدام في وحدة الشراء |
| **سعر الشراء** | ❌ | السعر بالعملة الأساسية |
| **الحد الأدنى للمخزون** | ❌ | رقم صحيح |
| **المورد** | ❌ | اسم المورد (يجب أن يكون موجوداً) |
| **الباركود** | ❌ | رقم الباركود (اختياري) |
| **الوصف** | ❌ | وصف المنتج |

### كيفية الاستخدام

#### الخطوة 1: تحميل القالب
1. اذهب إلى **المخزون → المنتجات**
2. انقر على زر **استيراد Excel**
3. انقر على **تحميل القالب**
4. سيتم تحميل ملف Excel فارغ جاهز للملء

#### الخطوة 2: ملء البيانات
1. افتح الملف في Excel أو LibreOffice Calc
2. ابدأ من الصف الثاني (الصف الأول يحتوي على مثال)
3. أضف بيانات المنتجات:
   - **مثال:**
     ```
     إسفنج مضغوط 20 كثافة | | raw_material | foam | إسفنج | roll | m2 | 60 | 150.50 | 10 | صفا فوم | | إسفنج عالي الجودة
     قماش عادي | | raw_material | fabric | أقمشة | m | m | 1 | 50 | 5 | شركة الخياطة | | قماش قطن
     ```

#### الخطوة 3: حذف المثال
1. احذف الصف الثاني (صف المثال)
2. تحقق من الأعمدة والبيانات

#### الخطوة 4: الرفع والاستيراد
1. احفظ الملف
2. عد إلى صفحة الاستيراد
3. اسحب الملف أو انقر لاختياره
4. انقر **رفع واستيراد**

#### الخطوة 5: مراجعة النتائج
1. ستُعرض نتائج الاستيراد مباشرة
2. عدد المنتجات المستوردة بنجاح ✅
3. عدد الأخطاء ⚠️
4. يمكنك عرض تفاصيل كل منتج

### المسارات (URLs)
```
/inventory/products/bulk-import/              GET/POST  - صفحة الاستيراد
/inventory/products/download-template/        GET      - تحميل القالب
```

### الكود المرتبط
- **Views:**
  - `views.bulk_import_products()` - صفحة الاستيراد
  - `views.process_excel_import()` - معالجة الملف
  - `views.download_import_template()` - إنشاء القالب
- **URLs:**
  ```python
  path('products/bulk-import/', views.bulk_import_products, name='bulk_import_products'),
  path('products/download-template/', views.download_import_template, name='download_import_template'),
  ```

### الأخطاء الشائعة وحلولها

| الخطأ | السبب | الحل |
|-------|-------|------|
| "اسم المنتج مطلوب" | خلية فارغة | تأكد من وجود اسم لكل منتج |
| "SKU مستخدم بالفعل" | نفس SKU موجود | غيّر SKU أو اتركه فارغاً |
| "الفئة غير موجودة" | الفئة غير موجودة في النظام | أضف الفئة أولاً من إدارة الفئات |
| "المورد غير موجود" | المورد غير موجود | أضف المورد أولاً من إدارة الموردين |

## 🎯 الميزة الثالثة: قوالب جاهزة (Product Templates)

### الوصف
حفظ وإدارة قوالب جاهزة للمنتجات المتكررة لتسريع الإدخال.

### المميزات
✅ إنشاء وتعديل وحذف القوالب
✅ حفظ أي منتج موجود كقالب
✅ استخدام القالب لإنشاء منتجات جديدة
✅ نسخ جميع المواصفات من القالب
✅ تتبع من أنشأ القالب والتاريخ

### كيفية الاستخدام

#### إنشاء قالب جديد:
1. اذهب إلى **المخزون → القوالب**
2. انقر على **قالب جديد**
3. أدخل البيانات:
   - اسم القالب (مثال: "قالب إسفنج 20 كثافة")
   - نوع المنتج
   - نوع المادة الخام (إن وُجد)
   - الفئة
   - وحدات القياس
   - معامل التحويل
   - السعر الافتراضي
   - الحد الأدنى للمخزون
   - ملاحظات
4. انقر **حفظ القالب**

#### حفظ منتج موجود كقالب:
1. افتح تفاصيل المنتج
2. انقر على زر **حفظ كقالب** (زر أخضر)
3. ادخل اسماً للقالب
4. انقر **حفظ**

#### استخدام قالب لإضافة منتج جديد:
1. اذهب إلى **المخزون → القوالب**
2. ابحث عن القالب المطلوب
3. انقر على زر **استخدام القالب**
4. ستُملأ البيانات تلقائياً من القالب
5. أدخل اسم المنتج الجديد وأي بيانات إضافية
6. انقر **حفظ**

#### إدارة القوالب:
- **عرض جميع القوالب:** اذهب إلى المخزون → القوالب
- **تعديل قالب:** انقر على أيقونة التعديل (قلم)
- **حذف قالب:** انقر على أيقونة السلة (حذف)
- **عرض تفاصيل:** كل قالب يعرض بيانات ملخصة

### المسارات (URLs)
```
/inventory/templates/                             GET      - قائمة القوالب
/inventory/templates/create/                      GET/POST - إنشاء قالب جديد
/inventory/templates/<template_id>/edit/          GET/POST - تعديل قالب
/inventory/templates/<template_id>/delete/        GET/POST - حذف قالب
/inventory/templates/<template_id>/use/           GET/POST - استخدام قالب
/inventory/products/<product_id>/save-as-template GET/POST - حفظ منتج كقالب
```

### الموديل (Model)
```python
class ProductTemplate(models.Model):
    name                         # اسم القالب
    product_type                 # نوع المنتج
    raw_material_type           # نوع المادة الخام
    category                     # الفئة
    purchase_uom                # وحدة الشراء
    usage_uom                   # وحدة الاستخدام
    conversion_factor           # معامل التحويل
    purchase_price              # السعر الافتراضي
    min_stock                   # الحد الأدنى للمخزون
    auto_calculate_conversion   # حساب تلقائي من الأبعاد
    length, width, height       # الأبعاد
    notes                       # ملاحظات
    created_by                  # المستخدم الذي أنشأها
    created_at                  # تاريخ الإنشاء
```

## 🐛 استكشاف الأخطاء

### المشكلة: لا يظهر زر النسخ
**الحل:**
1. تأكد من أن المنتج محفوظ (له ID)
2. نعّش الصفحة (Ctrl+Shift+R)
3. تحقق من الـ permissions

### المشكلة: الاستيراد لا يعمل
**الحل:**
1. تحقق من صيغة الملف (.xlsx أو .csv)
2. تأكد من تثبيت المكتبات:
   ```bash
   pip3 install openpyxl pandas --break-system-packages
   ```
3. تحقق من أسماء الأعمدة تماماً

### المشكلة: خطأ "Product type choices"
**الحل:**
تأكد من أن نوع المنتج يكون واحداً من:
- `raw_material`
- `finished`
- `semi_finished`
- `accessory`
