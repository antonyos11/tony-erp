### 2. وظائف التفاعل

#### اختيار مورد
- [ ] عند اختيار مورد، يتم تحميل المواد
- [ ] رسالة "جاري التحميل..." تظهر
- [ ] المواد تظهر في بطاقات جميلة
- [ ] كل بطاقة مادة تحتوي على:
  - [ ] اسم المادة بخط كبير
  - [ ] السعر بلون أخضر كبير
  - [ ] Badge الوحدة بتدرج بنفسجي
  - [ ] معامل التحويل أسفل البطاقة
  - [ ] أيقونة يد للإشارة للنقر

#### النقر على مادة
- [ ] عند التمرير، البطاقة:
  - [ ] تنزلق لليسار 8px
  - [ ] الخلفية تتحول لأزرق فاتح
  - [ ] الظل يزداد
- [ ] عند النقر:
  - [ ] تتغير حالة البطاقة إلى "selected"
  - [ ] الخلفية تصبح خضراء
  - [ ] الحدود تصبح خضراء
- [ ] البيانات تُطبق على الحقول:
  - [ ] سعر الشراء
  - [ ] وحدة الشراء
  - [ ] معامل التحويل
- [ ] قسم "المادة المختارة" يظهر
- [ ] البطاقة الخضراء تحتوي على:
  - [ ] اسم المادة
  - [ ] السعر
  - [ ] الوحدة
  - [ ] معامل التحويل
  - [ ] زر إلغاء الاختيار

#### الباركود
- [ ] مفتاح التبديل كبير (50px)
- [ ] الخلفية بتدرج بنفسجي
- [ ] حقل الإدخال كبير
- [ ] زر "توليد" يعمل
- [ ] زر "طباعة" موجود
- [ ] منطقة المعاينة تعمل

#### التسعير
- [ ] الخلفية بتدرج أصفر
- [ ] حقل سعر الشراء:
  - [ ] Badge أخضر "ج.م"
  - [ ] حجم الحقل كبير
- [ ] حقل معامل التحويل:
  - [ ] Badge أزرق
  - [ ] حجم الحقل كبير
- [ ] حقل تكلفة الاستخدام:
  - [ ] حدود خضراء سميكة (3px)
  - [ ] خط كبير جداً (1.5rem)
  - [ ] لون أخضر
  - [ ] محاذاة وسط
  - [ ] حقل للقراءة فقط
- [ ] الحاسبة البصرية:
  - [ ] خلفية سماوية
  - [ ] بطاقتان واضحتان
  - [ ] سهم في الوسط
  - [ ] مثال عملي أسفل

### 3. الحسابات التلقائية

#### حساب تكلفة الاستخدام
- [ ] عند إدخال سعر الشراء، يتم الحساب

- [ ] الصيغة: تكلفة الاستخدام = سعر الشراء ÷ معامل التحويل
- [ ] النتيجة تظهر بشكل فوري
