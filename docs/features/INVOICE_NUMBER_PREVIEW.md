# معاينة أرقام الفواتير التالية 🔢

## نظرة عامة
ميزة جديدة تتيح لك معرفة أرقام الفواتير التي سيتم توليدها تلقائياً قبل إنشاء الفواتير الفعلية. هذا مفيد جداً للتخطيط المسبق وللمعاملات المحاسبية.

## المزايا الرئيسية

### 1. معاينة جميع أنواع الفواتير
يمكنك رؤية الأرقام التالية لـ:
- ✅ فواتير المبيعات العادية
- ✅ الفواتير الضريبية - مبيعات
- ✅ الفواتير الضريبية - مرتجع مبيعات
- ✅ الفواتير الضريبية - مشتريات
- ✅ الفواتير الضريبية - مرتجع مشتريات

### 2. تنسيق موحد وواضح
كل رقم فاتورة يتبع التنسيق التالي:
```
نوع-الفاتورة-سنة-شهر-رقم-تسلسلي
مثال: INV-202601-000123
مثال: TAX-S-202601-00045
```

### 3. واجهة سهلة الاستخدام
- عرض جميع الأرقام في صفحة واحدة منظمة
- إمكانية نسخ أي رقم بضغطة زر واحدة
- تحديث تلقائي للأرقام

## كيفية الوصول

### الطريقة الأولى: من خلال القائمة
1. افتح قائمة المبيعات
2. اختر "أرقام الفواتير التالية"
3. ستظهر لك جميع الأرقام المتاحة

### الطريقة الثانية: الرابط المباشر
```
/sales/next-numbers/
```

### الطريقة الثالثة: Widget في لوحة التحكم
يمكن إضافة widget صغير في أي صفحة لعرض أهم الأرقام:
```django
{% include 'widgets/next_invoice_number_widget.html' %}
```

## استخدام API

### للحصول على البيانات بصيغة JSON
```javascript
fetch('/sales/api/next-numbers/')
    .then(response => response.json())
    .then(data => {
        console.log(data.next_numbers);
        // {
        //   "sales_invoice": "INV-202601-000123",
        //   "tax_sales": "TAX-S-202601-00045",
        //   "tax_sales_return": "TAX-SR-202601-00012",
        //   "tax_purchase": "TAX-P-202601-00067",
        //   "tax_purchase_return": "TAX-PR-202601-00003"
        // }
    });
```

### استخدام Python
```python
from sales.next_invoice_number import preview_invoice_numbers

# الحصول على جميع الأرقام
numbers = preview_invoice_numbers()
print(numbers['sales_invoice'])  # INV-202601-000123

# أو الحصول على رقم محدد
from sales.next_invoice_number import get_next_invoice_number
next_invoice = get_next_invoice_number()
print(next_invoice)  # INV-202601-000123
```

## تفاصيل تقنية

### نظام الترقيم

#### فواتير المبيعات العادية
- البادئة: `INV-{السنة}{الشهر}`
- مثال: `INV-202601-000123`
- الترقيم: متسلسل شهرياً (يبدأ من جديد كل شهر)

#### الفواتير الضريبية

| النوع | البادئة | مثال |
|-------|---------|-------|
| مبيعات | TAX-S | TAX-S-202601-00045 |
| مرتجع مبيعات | TAX-SR | TAX-SR-202601-00012 |
| مشتريات | TAX-P | TAX-P-202601-00067 |
| مرتجع مشتريات | TAX-PR | TAX-PR-202601-00003 |

### كيف يعمل النظام؟

1. **البحث عن آخر فاتورة**: يبحث النظام عن آخر فاتورة من نفس النوع في الشهر الحالي
2. **استخراج الرقم التسلسلي**: يستخرج الرقم ويضيف 1
3. **التنسيق**: يطبق التنسيق المناسب مع الأصفار البادئة
4. **التحقق**: يتأكد من عدم وجود تكرار

## حالات الاستخدام

### 1. التخطيط المحاسبي
عندما تحتاج لتسجيل معاملة محاسبية قبل إصدار الفاتورة، يمكنك استخدام الرقم المتوقع.

### 2. الحجز المسبق
في حالة حجز رقم فاتورة لعملية معينة قبل اكتمالها.

### 3. التكامل مع أنظمة خارجية
عند الحاجة لمشاركة رقم الفاتورة المتوقع مع نظام آخر.

### 4. التدقيق والمراجعة
للتحقق من تسلسل الأرقام والتأكد من عدم وجود فجوات.

## ملاحظات هامة

⚠️ **الأرقام المعروضة هي تقديرية**
- الأرقام المعروضة قد تتغير إذا تم إنشاء فاتورة جديدة من نفس النوع
- لا تعتمد على هذه الأرقام كأرقام نهائية حتى يتم إنشاء الفاتورة فعلياً

✅ **الأرقام الفعلية مضمونة**
- عند إنشاء الفاتورة فعلياً، سيتم توليد رقم فريد مضمون
- النظام يتعامل مع حالات التزامن (concurrent requests)
- الأرقام لن تتكرر أبداً
