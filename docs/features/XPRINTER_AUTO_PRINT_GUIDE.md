# 🖨️ دليل الطباعة التلقائية على XPrinter

## نظرة عامة
تم إضافة ميزة الطباعة التلقائية على طابعة XPrinter الحرارية عند إتمام عملية الدفع في نظام نقطة البيع (POS).

## الميزات الجديدة

### 1. ✅ الطباعة التلقائية عند التأكيد
- عند الضغط على زر "تأكيد الدفع" في نافذة الدفع
- يتم طباعة الإيصال تلقائياً على طابعة XPrinter الحرارية
- الطباعة تتم في الخلفية ولا تعطل سير العمل

### 2. 🎛️ خيارات الطباعة في نافذة الدفع
في نافذة الدفع، يوجد الآن قسم "خيارات الطباعة" يحتوي على:

#### ✓ طباعة تلقائية على XPrinter (مفعّل افتراضياً)
- يمكن إلغاء تفعيلها إذا لم ترغب بالطباعة التلقائية
- مفيد في حالات التدريب أو التجربة

#### ✓ فتح درج النقود (معطّل افتراضياً)
- تفعيل هذا الخيار يفتح درج النقود تلقائياً عند الطباعة
- مفيد للدفع النقدي

### 3. 📄 أزرار إضافية في صفحة الإيصال
بعد إتمام الدفع، في صفحة الإيصال يوجد:

- **🖨️ طباعة حرارية XPrinter**: طباعة يدوية على الطابعة الحرارية
- **📄 طباعة عادية**: طباعة عادية على طابعة عادية أو PDF
- **🔄 طلب جديد**: العودة لفتح طلب جديد مباشرة
- **✕ إغلاق**: إغلاق النافذة

## كيفية الاستخدام

### الاستخدام الأساسي (الطريقة الافتراضية)
1. في شاشة POS، أضف المنتجات للسلة
2. اضغط على زر "الدفع" 
3. اختر طريقة الدفع والمبلغ
4. تأكد من تفعيل خيار "طباعة تلقائية على XPrinter" ✓
5. اختياري: فعّل "فتح درج النقود" إذا كنت تريد فتحه
6. اضغط على "تأكيد الدفع"
7. ✅ سيتم:
   - إتمام عملية الدفع
   - طباعة الإيصال تلقائياً على XPrinter
   - فتح درج النقود (إذا كان مفعّلاً)
   - الانتقال لصفحة الإيصال

### إعادة الطباعة من صفحة الإيصال
إذا كنت في صفحة الإيصال وتريد طباعته مرة أخرى:
1. اضغط على زر "🖨️ طباعة حرارية XPrinter"
2. سيتم إعادة طباعة الإيصال

## الإعدادات المطلوبة

### 1. تثبيت الطابعة
- تأكد من تثبيت طابعة XPrinter في النظام
- يُفضل تعيينها كطابعة افتراضية
- يمكن استخدام أي طابعة حرارية متوافقة مع ESC/POS

### 2. المكتبات المطلوبة (مثبتة مسبقاً)
```bash
pip install Pillow
pip install arabic-reshaper
pip install python-bidi
pip install pywin32  # في Windows
```

### 3. اختبار الطابعة
للتأكد من أن الطابعة تعمل، استخدم API الاختبار:
```
GET /pos/printer/test/?printer=XPrinter
```

## حل المشاكل

### المشكلة: الطباعة لا تعمل
**الحلول:**
1. تأكد من أن الطابعة متصلة ومشغلة
2. تحقق من أن برنامج تشغيل الطابعة مثبت
3. تحقق من الكونسول (F12) لرؤية رسائل الخطأ
4. جرب الطباعة العادية للتأكد من الطابعة
5. تحقق من أن المنفذ USB أو الشبكة متصل

### المشكلة: النص العربي لا يظهر صحيحاً
**الحل:**
- النظام يستخدم طباعة كصورة لضمان ظهور العربية صحيحاً
- تأكد من تثبيت مكتبات `arabic-reshaper` و `python-bidi`

### المشكلة: درج النقود لا يُفتح
**الحلول:**
1. تأكد من أن درج النقود متصل بالطابعة
2. تحقق من كابل RJ11/RJ12 بين الطابعة والدرج
3. بعض الطابعات تحتاج إعدادات خاصة لتفعيل فتح الدرج

### المشكلة: الطباعة بطيئة
**الحل:**
- الطباعة كصورة قد تأخذ وقتاً أطول من الطباعة النصية
- يمكن تقليل دقة الصورة في الإعدادات (غير موصى به)

## API المستخدم

### طباعة إيصال
```http
POST /pos/order/{order_id}/direct-print/
Content-Type: application/json

{
    "printer_name": null,  // null = الطابعة الافتراضية
    "open_drawer": false   // true لفتح الدرج
}
```

**استجابة ناجحة:**
```json
{
    "success": true,
    "message": "تم طباعة الفاتورة XXX بنجاح",
    "printer": "XPrinter XP-58IIH"
}
```

**استجابة فاشلة:**
```json
{
    "success": false,
    "error": "فشل الاتصال بالطابعة"
}
```
