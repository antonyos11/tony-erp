## 🚀 البدء السريع

### 1. افتح نظام POS
```
الرابط: http://[your-server-ip]/pos/
أو: http://[your-server-ip]/pos/order/new/
```

### 2. تأكد من وجود جلسة نشطة
```
إذا لم تكن هناك جلسة: /pos/session/open/
```

### 3. ابدأ البيع!
- 💵 **الدفع النقدي**: اضغط الزر الأخضر "الدفع"
- 📅 **التقسيط**: اضغط أيقونة التقويم
- 💾 **حفظ مؤقت**: اضغط F9
