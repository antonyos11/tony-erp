# البدء السريع - نظام مخازن المصنع المتعددة 🚀

## خطوات سريعة للبدء

### 1️⃣ الوصول إلى نظام المخازن

افتح المتصفح واذهب إلى:
```
http://72.62.176.249/inventory/locations/types/
```

أو من لوحة التحكم:
```
المخزون → المواقع → عرض حسب النوع
```

---

### 2️⃣ إنشاء أول مخزن

**اختر نوع المخزن الذي تريده:**

#### 🏭 مخزن منتجات تامة
اضغط على **"إضافة مخزن منتج تام"** واملأ:
- الكود: `FINISHED-01`
- الاسم: `مخزن المنتجات الجاهزة`
- العنوان: `المبنى الرئيسي - الطابق الثاني`

#### ⚙️ مخزن نصف مصنعة
اضغط على **"إضافة مخزن نصف مصنع"** واملأ:
- الكود: `WIP-01`
- الاسم: `خط الإنتاج 1`
- العنوان: `ورشة التصنيع`

#### 💧 مخزن خامات
اضغط على **"إضافة مخزن خامات"** واملأ:
- الكود: `RAW-01`
- الاسم: `مخزن المواد الخام`
- العنوان: `المستودع الرئيسي`

---

### 3️⃣ عرض المخازن

**عرض حسب النوع:**
```
/inventory/locations/types/
```
يعرض لك بطاقات ملونة لكل نوع مع الإحصائيات

**عرض قائمة كاملة:**
```
/inventory/locations/
```
يعرض لك جدول بجميع المخازن

---

### 4️⃣ إضافة منتجات للمخازن

بعد إنشاء المخازن، يمكنك:

1. **إضافة منتج جديد:**
   ```
   المخزون → المنتجات → إضافة منتج جديد
   ```

2. **اختر المخزن:**
   عند الإضافة، اختر المخزن المناسب من القائمة

3. **إضافة كمية:**
   ```
   المخزون → إدارة المخزون → إضافة كمية
   ```

---

### 5️⃣ نقل البضائع بين المخازن

**مثال: نقل خامات للتصنيع**

1. اذهب إلى **التحويلات المخزنية**
   ```
   المخزون → التحويلات → إنشاء تحويل جديد
   ```

2. اختر:
   - **من:** مخزن الخامات (`RAW-01`)
   - **إلى:** مخزن نصف المصنعة (`WIP-01`)
   - **المنتج:** اختر الخامات
   - **الكمية:** أدخل الكمية

3. **احفظ وأكمل التحويل**

**مثال: نقل منتجات تامة للمعرض**

1. نفس الخطوات
2. اختر:
   - **من:** مخزن المنتجات التامة (`FINISHED-01`)
   - **إلى:** مخزن المعرض (`STORE-01`)

## نصيحة سريعة 💡

**ابدأ بهذه المخازن الأساسية:**

```
1. RAW-01: مخزن المواد الخام
2. WIP-01: خط الإنتاج
3. FINISHED-01: المنتجات الجاهزة
4. STORE-01: المعرض الرئيسي
```

**الحل:** راجع سجل التحويلات والعمليات
