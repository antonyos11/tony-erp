## ⚙️ المنتجات نصف المصنعة - السوست

تم إنشاء 8 أنواع من السوست كمنتجات **نصف مصنعة**:

### 1️⃣ سوست بونيل (Bonnell Springs)

| SKU | الوصف | السلك المستخدم | وزن السلك | تكلفة العمالة | التكلفة الإجمالية |
|-----|-------|----------------|-----------|---------------|-------------------|
| SPR-BNL-S90 | سوست بونيل 2.0 مم | WIRE-2.0 | 0.015 كجم | 0.30 ج | 0.60 ج |
| SPR-BNL-S100 | سوست بونيل 2.2 مم | WIRE-2.2 | 0.018 كجم | 0.35 ج | 0.73 ج |
| SPR-BNL-S120 | سوست بونيل 2.4 مم (Heavy) | WIRE-2.4 | 0.022 كجم | 0.40 ج | 0.88 ج |

**الحساب:**
```
تكلفة السوست = (وزن السلك × سعر السلك) + تكلفة العمالة

مثال: SPR-BNL-S90
= (0.015 كجم × 20 ج/كجم) + 0.30 ج
= 0.30 ج + 0.30 ج
= 0.60 ج
```

## 🏭 سير العمل

### المرحلة 1: شراء السلك الحديد
```
1. استلام السلك من المورد
2. تسجيل في المخزون (مادة خام)
3. تخزين في مخزن المواد الخام
```

### المرحلة 2: تصنيع السوست
```
1. صرف السلك من المخزون
2. تصنيع السوست على الماكينة
3. تسجيل السوست المنتجة (نصف مصنع)
4. تخزين في مخزن نصف المصنع
```

### المرحلة 3: تجميع المرتبة
```
1. صرف السوست من مخزن نصف المصنع
2. صرف باقي المواد (إسفنج، قماش، إلخ)
3. تجميع المرتبة
4. تسجيل المرتبة (منتج نهائي)
5. تخزين في مخزن المنتج التام
```

## 📈 تقارير مفيدة

### 1. تقرير استهلاك السلك الحديد
- كم كيلو سلك استخدمت في الشهر؟
- أي نوع سلك الأكثر استهلاكاً؟

### 2. تقرير إنتاج السوست
- كم سوست أنتجت اليوم/الأسبوع/الشهر؟
- ما هي الأنواع الأكثر إنتاجاً؟

### 3. تقرير كفاءة التصنيع
- نسبة الهدر الفعلية vs المخططة
- تكلفة العمالة الفعلية vs المخططة

## 🎯 نصائح مهمة

### ✅ افعل
1. **سجل الإنتاج يومياً**: لا تنتظر نهاية الأسبوع
2. **راقب نسبة الهدر**: 3% هدر طبيعي، أكثر من ذلك يحتاج مراجعة
3. **حدّث تكلفة العمالة**: حسب الإنتاجية الفعلية
4. **احسب وزن السلك بدقة**: استخدم ميزان دقيق

### ❌ لا تفعل
1. **لا تخلط السوست المصنعة مع المشتراة**: إذا كنت تشتري بعض السوست جاهزة
2. **لا تهمل تسجيل الإنتاج**: حتى لو كميات صغيرة
3. **لا تنسى احتساب الهدر**: في السلك والقماش
