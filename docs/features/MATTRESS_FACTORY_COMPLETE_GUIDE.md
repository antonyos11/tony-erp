# 🏭 الدليل الشامل لنظام مصنع المراتب والمفروشات

## 📊 نظرة عامة على الدورة المستندية

هذا النظام مصمم خصيصاً لمصنع المراتب والمفروشات ويشمل:
- إدارة المخزون بكل أنواعه (خامات، نصف مصنع، تام)
- دورة الإنتاج الكاملة
- تتبع التكاليف
- نظام الجودة
- نظام الضمان

---

## 📦 أنواع المخازن

| النوع | الكود | الوصف | الاستخدام |
|-------|-------|-------|-----------|
| خامات | `raw` | مخزن المواد الخام | القماش، الإسفنج، السوست، الخشب |
| نصف مصنع | `wip` | منتجات تحت التشغيل | إطارات، أغطية مقطعة، حشوات جاهزة |
| منتج تام | `finished` | المنتجات النهائية | مراتب، مفروشات، وسائد |
| قطع غيار | `spare` | قطع الغيار | سوست بديلة، أقمشة للصيانة |
| معرض | `store` | صالة العرض والبيع | المنتجات المعروضة للبيع |

## 🔄 الدورة المستندية خطوة بخطوة

### 1️⃣ مرحلة الشراء والاستلام

```
المورد ──► أمر شراء (PO) ──► استلام (GRN) ──► مخزن الخامات
```

**المستندات:**
- **أمر الشراء** (`purchases:create_order`)
  - تحديد المواد المطلوبة
  - تحديد الكميات والأسعار
  - تحديد المورد
  
- **مستند الاستلام** (`inventory:receiving_create`)
  - فحص الجودة عند الاستلام
  - تسجيل الكميات الفعلية
  - تحديد رقم الدفعة (Lot Number)
  - تحديد تاريخ الصلاحية (إن وجد)

### 2️⃣ مرحلة طلب الخامات للإنتاج

```
قسم الإنتاج ──► طلب خامات (Requisition) ──► موافقة ──► إذن صرف
```

**المستندات:**
- **طلب الخامات** (`inventory:requisition_create`)
  - تحديد المواد المطلوبة من قائمة المواد (BOM)
  - ربط بأمر الإنتاج
  - تحديد المرحلة

- **إذن الصرف** (`inventory:issue_create`)
  - صرف المواد للإنتاج
  - خصم من المخزون (FIFO/LIFO)
  - تسجيل المستلم

### 3️⃣ مرحلة الإنتاج

```
أمر إنتاج ──► مراحل الإنتاج ──► منتج نهائي
```

**المستندات:**
- **أمر الإنتاج** (`production:create_order`)
  - تحديد المنتج المطلوب
  - تحديد الكمية
  - اختيار قائمة المواد (BOM)
  - جدولة التواريخ

- **مراحل الإنتاج:**
  | المرحلة | الوصف | الأقسام |
  |---------|-------|---------|
  | تقطيع | تقطيع الأقمشة والإسفنج | قسم التقطيع |
  | خياطة | خياطة الأغطية | قسم الخياطة |
  | حشو | حشو المراتب | قسم الحشو |
  | تجميع | تجميع المكونات | قسم التجميع |
  | تشطيب | اللمسات النهائية | قسم التشطيب |
  | فحص جودة | فحص المنتج النهائي | قسم الجودة |
  | تعبئة | تغليف المنتج | قسم التعبئة |

### 4️⃣ مرحلة المنتج النهائي

```
اكتمال الإنتاج ──► توليد باركود ──► مخزن المنتج التام
```

**المستندات:**
- **وحدة المنتج النهائي** (`production:unit_list`)
  - رقم تسلسلي فريد
  - باركود فريد
  - QR Code للضمان
  - معلومات الصلاحية والمقاس

### 5️⃣ مرحلة التحويل للمعرض

```
مخزن المنتج التام ──► تحويل مخزني ──► المعرض
```

**المستندات:**
- **التحويل المخزني** (`inventory:transfer_create`)
  - تحديد المصدر (مخزن المنتج التام)
  - تحديد الوجهة (المعرض)
  - تحديد المنتجات والكميات

### 6️⃣ مرحلة البيع

```
المعرض ──► فاتورة بيع ──► العميل ──► تسجيل الضمان
```

**المستندات:**
- **فاتورة البيع** (`sales:invoice_create`)
  - اختيار المنتجات
  - تحديد العميل
  - تسجيل معلومات الضمان

- **تسجيل الضمان** (`production:warranty_register`)
  - مسح QR Code
  - تسجيل بيانات العميل
  - تفعيل الضمان

## 📋 قائمة المواد (Bill of Materials - BOM)

### مثال: مرتبة 200×200 سم

```
📦 المنتج: مرتبة سوبر ديلوكس 200×200
   │
   ├── 🧵 القماش الخارجي (10 متر)
   │   └── تكلفة: 500 ج.م
   │
   ├── 🧽 الإسفنج (25 كجم)
   │   └── تكلفة: 1000 ج.م
   │
   ├── 🔩 السوست (200 قطعة)
   │   └── تكلفة: 300 ج.م
   │
   ├── 🪵 الإطار الخشبي (1 وحدة)
   │   └── تكلفة: 200 ج.م
   │
   ├── 🧶 اللباد (8 متر)
   │   └── تكلفة: 150 ج.م
   │
   └── 📦 التغليف (1 وحدة)
       └── تكلفة: 50 ج.م

   ═══════════════════════════════
   💰 إجمالي تكلفة المواد: 2,200 ج.م
   👷 تكلفة العمالة: 300 ج.م
   🏭 التكاليف الإضافية: 200 ج.م
   ═══════════════════════════════
   📊 إجمالي تكلفة الوحدة: 2,700 ج.م
```

## 💡 نصائح للاستخدام الأمثل

### عند إنشاء أمر إنتاج:
1. ✅ تأكد من وجود قائمة مواد (BOM) للمنتج
2. ✅ راجع توفر المواد الخام في المخزن
3. ✅ حدد تاريخ البدء والانتهاء المخطط
4. ✅ اختر المشرف المسؤول

### عند صرف المواد:
1. ✅ أنشئ طلب خامات أولاً (للتوثيق والموافقة)
2. ✅ بعد الموافقة، حوّله لإذن صرف
3. ✅ سجّل اسم المستلم
4. ✅ اطبع إذن الصرف للتوقيع

### عند إنهاء الإنتاج:
1. ✅ سجّل الكميات المنتجة والتالفة
2. ✅ ولّد الباركود لكل وحدة
3. ✅ اطبع ملصقات المنتج
4. ✅ انقل للمخزن التام

## 📱 رموز QR والباركود

كل منتج نهائي يحصل على:
- **باركود فريد**: للمسح عند البيع والجرد
- **QR Code**: يحتوي على رابط تسجيل الضمان

عند مسح QR Code من العميل:
1. ينتقل لصفحة تسجيل الضمان
2. يُدخل بياناته (الاسم، الهاتف، العنوان)
3. يُفعّل الضمان تلقائياً
