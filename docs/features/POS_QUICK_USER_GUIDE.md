# 🎮 دليل المستخدم السريع - نقطة البيع

## 🚀 البدء السريع (3 خطوات)

### الخطوة 1: افتح جلسة
1. اضغط على زر **"فتح جلسة"** 
2. أدخل رصيد الافتتاح
3. اضغط **حفظ**

### الخطوة 2: أضف منتجات
- **طريقة 1**: انقر على المنتج من الشبكة
- **طريقة 2**: اكتب اسم المنتج في البحث واضغط على المنتج
- **طريقة 3**: امسح الباركود بالماسح أو اكتبه واضغط Enter

### الخطوة 3: أتمم البيع
1. تأكد من المنتجات في السلة
2. اضغط زر **"الدفع"** (أو F8)
3. اختر طريقة الدفع
4. أكمل العملية

## ⌨️ الاختصارات الأساسية

### للمبتدئين (احفظ هذه فقط!)

| المفتاح | ماذا يفعل |
|---------|-----------|
| **F2** | ابحث عن منتج |
| **F8** | ادفع الآن |
| **F9** | علّق الطلب |
| **Esc** | إلغاء |

### للمحترفين

| المفتاح | الوظيفة |
|---------|---------|
| F1 | لوحة التحكم |
| F3 | طلب جديد |
| F4 | اختر عميل |
| F10 | الطلبات المعلقة |
| F11 | آلة حاسبة |
| Ctrl+D | خصم |
| + / - | زيادة/تقليل الكمية |
