## 🎯 كيفية الوصول للميزات الجديدة

### من الواجهة الرئيسية:

1. **إضافة حساب إلكتروني:**
   ```
   /admin/accounting/electronicaccount/add/
   ```

2. **إضافة خزينة:**
   ```
   /admin/accounting/treasury/add/
   ```

3. **تسجيل إيراد:**
   ```
   /accounting/entries/revenue/create/
   ```

4. **تسجيل منصرف:**
   ```
   /accounting/entries/expense/create/
   ```

5. **التقارير:**
   ```
   /accounting/reports/ledger-account/
   /accounting/reports/financial-analysis-1/
   /accounting/reports/financial-analysis-2/
   /accounting/reports/cost-center/
   /accounting/reports/owner/
   ```
