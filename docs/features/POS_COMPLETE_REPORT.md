## 📋 دليل الاستخدام السريع

### 1️⃣ البيع النقدي
```
1. أضف منتجات للسلة
2. اضغط زر "الدفع" 💵
3. اختر "نقدي"
4. أدخل المبلغ أو "المبلغ بالضبط"
5. اضغط "تأكيد الدفع" ✅
6. ستفتح صفحة الإيصال 🧾
```

### 2️⃣ البيع بالتقسيط
```
1. أضف منتجات للسلة
2. اضغط زر التقسيط 📅
3. أدخل بيانات العميل
4. حدد خطة التقسيط:
   - الدفعة المقدمة
   - عدد الأقساط
   - نسبة الفائدة
   - تاريخ البداية
5. اضغط "تأكيد التقسيط" ✅
6. ستفتح صفحة العقد 📝
```

### 3️⃣ الطلبات المعلقة
```
حفظ: F9
استعادة: F10
```
