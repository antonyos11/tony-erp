# 🏭 نظام إدارة المخازن المتعددة للمصنع

## نظرة سريعة

تم تطوير نظام شامل لإدارة أنواع مختلفة من المخازن في المصنع:

- 🏭 **مخازن المنتجات التامة** - للمنتجات الجاهزة للبيع
- ⚙️ **مخازن نصف المصنعة** - للمنتجات قيد التصنيع
- 💧 **مخازن المواد الخام** - للخامات الأولية
- 🔧 **مخازن قطع الغيار** - لقطع الغيار والأدوات
- 🏪 **مخازن المعارض** - لمخازن المعارض والمحلات
- 📦 **مخازن أخرى** - للمخازن العامة

---

## 🚀 البدء السريع

### 1. الوصول إلى النظام

```
http://your-domain/inventory/locations/types/
```

أو من لوحة التحكم:
```
المخزون → المخازن حسب النوع
```

### 2. إنشاء مخازن تجريبية (اختياري)

```bash
cd /var/www/tony_erp
python3 manage.py shell < create_sample_warehouses.py
```

سيتم إنشاء 13 مخزن تجريبي من جميع الأنواع تلقائياً.

### 3. إضافة مخزن يدوياً

1. افتح صفحة المخازن حسب النوع
2. اختر نوع المخزن
3. اضغط "إضافة مخزن [نوع المخزن]"
4. املأ البيانات:
   - الكود (مثل: `FINISHED-01`)
   - الاسم (مثل: `مخزن المنتجات الجاهزة`)
   - العنوان (اختياري)
5. احفظ

## 📊 أمثلة الاستخدام

### مصنع أثاث:

```
RAW-WOOD      → مخزن الخشب (خامات)
WIP-CUT       → قسم القطع (نصف مصنع)
WIP-ASSEMBLY  → قسم التجميع (نصف مصنع)
FINISHED-01   → مخزن الأثاث الجاهز (منتج تام)
STORE-MAIN    → المعرض الرئيسي (معرض)
```

### مصنع إلكترونيات:

```
RAW-COMP      → مخزن المكونات (خامات)
WIP-PCB       → خط تجميع اللوحات (نصف مصنع)
WIP-TEST      → قسم الاختبار (نصف مصنع)
FINISHED-01   → الأجهزة الجاهزة (منتج تام)
SPARE-WARR    → قطع الضمان (قطع غيار)
```

## 🎯 الحالات الاستخدام الشائعة

### 1. إضافة مخزن جديد:
```
الطريقة 1: من صفحة الأنواع → اختر النوع → "إضافة مخزن"
الطريقة 2: من قائمة المخازن → "إضافة موقع جديد"
```

### 2. نقل بضائع بين المخازن:
```
المخزون → التحويلات → إنشاء تحويل
اختر: من (مخزن خامات) → إلى (مخزن نصف مصنع)
```

### 3. عرض المخزون لمخزن محدد:
```
من بطاقة المخزن → "عرض المخزون"
أو: المخزون → إدارة المخزون → اختر الموقع
```

## 🔧 الصيانة

### إضافة نوع مخزن جديد:

1. عدّل `Location.WAREHOUSE_TYPES` في `inventory/models.py`:
```python
WAREHOUSE_TYPES = [
    # ... existing types
    ('new_type', _('نوع جديد')),
]
```

2. أضف الألوان والأيقونات في القوالب
3. أضف إحصائيات في `warehouse_types_view`

### تخصيص الألوان:

عدّل ملف CSS في القالب أو أضف ملف CSS منفصل.
