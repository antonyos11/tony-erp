## 🛠️ التثبيت والإعداد

### الخطوة 1: تشغيل Migrations

```bash
cd /var/www/tony_erp
python manage.py migrate sales
```

### الخطوة 2: تسجيل النماذج في Admin

أضف في `sales/admin.py`:

```python
from .invoice_admin import (
    InvoiceTemplateAdmin,
    InvoiceAutosaveAdmin,
    InvoiceAttachmentAdmin,
    InvoiceHistoryAdmin,
    CustomerCreditLimitAdmin
)
```

### الخطوة 3: تحديث القوالب

أضف في `invoice_form.html` أو `invoice_form_enhanced.html`:

```html
<!-- في head -->
<link rel="stylesheet" href="{% static 'css/invoice_features_advanced.css' %}">

<!-- قبل إغلاق body -->
<script src="{% static 'js/invoice_features_advanced.js' %}"></script>
```

### الخطوة 4: إعادة تشغيل السيرفر

```bash
sudo systemctl restart tony_erp
# أو
python manage.py runserver
```

## 🎯 الميزات المتاحة

### 1️⃣ الحفظ التلقائي (Auto-Save)

**الوصف:** حفظ تلقائي لبيانات الفاتورة كل 30 ثانية.

**الفوائد:**
- ✅ لا تفقد عملك أبداً
- ✅ استرجاع تلقائي عند العودة للصفحة
- ✅ إشعارات بسيطة غير مزعجة

**كيفية الاستخدام:**
1. ابدأ في إدخال بيانات الفاتورة
2. سيتم الحفظ تلقائياً كل 30 ثانية
3. ستظهر رسالة: "تم الحفظ تلقائياً ✓"
4. عند العودة للصفحة، ستجد بياناتك محفوظة

**API:**
```javascript
// الحفظ يدوياً
autoSaveForm();

// تحميل آخر حفظ
$.get('/sales/api/autosave/load/', function(data) {
    if (data.success) {
        // استعادة البيانات
    }
});
```

### 2️⃣ نماذج الفواتير الجاهزة (Templates)

**الوصف:** حفظ فواتير متكررة كقوالب لإعادة استخدامها.

**الفوائد:**
- ✅ سرعة في إنشاء فواتير مشابهة
- ✅ تقليل الأخطاء
- ✅ توحيد العمل

**كيفية الاستخدام:**

#### إنشاء نموذج جديد:
1. أنشئ فاتورة عادية
2. اضغط على "حفظ كنموذج"
3. أدخل اسم النموذج (مثل: "فاتورة شركة ABC الشهرية")
4. سيُحفظ النموذج مع جميع الأصناف

#### استخدام نموذج موجود:
1. في أعلى الصفحة، ستجد قائمة "استخدام نموذج جاهز"
2. اختر النموذج المطلوب
3. ستُملأ جميع البيانات تلقائياً
4. عدّل ما تريد ثم احفظ

**إدارة النماذج:**
- افتح Admin Panel → Invoice Templates
- شاهد عدد مرات الاستخدام لكل نموذج
- عطّل أو احذف النماذج القديمة

### 3️⃣ الحساب التلقائي للضريبة

**الوصف:** احتساب ضريبة القيمة المضافة (15%) تلقائياً.

**الفوائد:**
- ✅ دقة في الحسابات
- ✅ عرض تفصيلي للمبالغ
- ✅ لا حاجة للحاسبة

**العرض:**
```

└─────────────────────────────────────┘
```

### 4️⃣ البحث الذكي للعملاء

**الوصف:** بحث متقدم مع عرض معلومات إضافية.

**الميزات:**
- 🔍 بحث في الاسم، الهاتف، والبريد
- 💰 عرض الرصيد الحالي
- 📅 آخر فاتورة للعميل
- 📊 آخر 3 معاملات

**كيفية الاستخدام:**
1. انقر في حقل "العميل"
2. ابدأ بالكتابة
3. ستظهر نتائج البحث مباشرة
4. اختر العميل، وستظهر معلوماته:
   - الرصيد الحالي
   - تاريخ آخر فاتورة
   - عدد الفواتير الإجمالي
   - آخر 3 معاملات

**اختصار:**
اضغط `F3` للوصول السريع لبحث العملاء

### 5️⃣ اختصارات لوحة المفاتيح

**القائمة الكاملة:**

| الاختصار | الوظيفة |
|----------|---------|
| `Ctrl + S` | حفظ الفاتورة |
| `Ctrl + Enter` | حفظ وإضافة فاتورة جديدة |
| `F2` | إضافة صنف جديد |
| `F3` | بحث عن عميل |
| `Esc` | إلغاء / الرجوع |

**كيفية العرض:**
- اضغط على أيقونة ⌨️ "اختصارات المفاتيح" في الأعلى
- ستظهر قائمة منبثقة بجميع الاختصارات

### 6️⃣ نسخ من فاتورة سابقة

**الوصف:** نسخ بيانات فاتورة قديمة لإنشاء فاتورة جديدة.

**كيفية الاستخدام:**
1. اضغط على "نسخ من فاتورة"
2. أدخل رقم الفاتورة المراد نسخها (مثل: INV-000123)
3. سيتم تحميل:
   - العميل
   - طريقة الدفع
   - الخصم
   - جميع الأصناف
4. عدّل التاريخ أو أي بيانات أخرى
5. احفظ كفاتورة جديدة

**حالات الاستخدام:**
- ✅ فواتير شهرية متكررة
- ✅ طلبات إضافية لنفس العميل
- ✅ استبدال فاتورة ملغاة

---

### 7️⃣ حسابات سريعة في الحقول

**الوصف:** إجراء عمليات حسابية مباشرة في الحقول.

**كيفية الاستخدام:**
1. في أي حقل رقمي (السعر، الكمية، الخصم)
2. اكتب عملية حسابية مثل:
   - `1000+500` → 1500
   - `2000-150` → 1850
   - `500*2` → 1000
   - `1200/4` → 300
3. عند الخروج من الحقل، سيُحسب تلقائياً
4. ستظهر رسالة: "النتيجة: 1500"

**أمثلة عملية:**
```
حقل السعر:    100*12        → 1,200
حقل الخصم:    1000-50       → 950
حقل الكمية:   24/2          → 12
```

### 8️⃣ تذكيرات ذكية

**الوصف:** تنبيهات تلقائية للحقول المهمة والنصائح.

**التنبيهات المتاحة:**

#### ⚠️ تنبيه: لم تختر عميلاً
- يظهر: عند عدم اختيار عميل
- الحل: زر "إصلاح" للوصول المباشر

#### ⚠️ تنبيه: لا توجد أصناف
- يظهر: عندما تكون الفاتورة فارغة
- الحل: زر للإضافة السريعة

#### 💡 نصيحة: حدد طريقة الدفع
- يظهر: عند عدم تحديد طريقة الدفع
- اختياري لكن مُوصى به

**التوقيت:**
- تظهر بعد 3 ثوانٍ من فتح الصفحة
- تُحدث عند أي تغيير

---

### 9️⃣ مرفقات سريعة (السحب والإفلات)

**الوصف:** رفع مستندات وصور بسهولة.

**طرق الرفع:**

#### الطريقة 1: السحب والإفلات
1. اسحب الملف من سطح المكتب
2. أفلته في المنطقة المحددة
3. سيُرفع تلقائياً

#### الطريقة 2: النقر والاختيار
1. انقر على منطقة الرفع
2. اختر الملف من جهازك
3. سيُرفع تلقائياً

**المواصفات المدعومة:**
- ✅ الحد الأقصى: 5 MB لكل ملف
- ✅ الأنواع المدعومة:
  - صور: JPG, PNG, GIF, WebP
  - مستندات: PDF, DOC, DOCX
  - جداول: XLS, XLSX
  - أخرى: ZIP, RAR

**عرض المرفقات:**
- أيقونة حسب نوع الملف
- اسم الملف وحجمه
- زر الحذف

## ⌨️ اختصارات لوحة المفاتيح - المرجع الكامل

### الاختصارات الأساسية

| الاختصار | الوظيفة | الوصف |
|----------|---------|--------|
| `Ctrl + S` | حفظ | حفظ الفاتورة الحالية |
| `Ctrl + Enter` | حفظ وجديد | حفظ وفتح فاتورة جديدة |

| `F3` | بحث عميل | فتح بحث العملاء |

### نصائح للاستخدام الفعّال

1. **استخدم Tab للتنقل** بين الحقول بدلاً من الماوس
2. **اضغط Enter** في حقل البحث للانتقال للنتيجة الأولى
3. **استخدم الأسهم** للتنقل في القوائم المنسدلة

## ❓ الأسئلة الشائعة

### س: هل الحفظ التلقائي يحفظ في قاعدة البيانات؟
**ج:** نعم، يُحفظ في جدول منفصل ويُحذف بعد 7 أيام تلقائياً.

### س: ماذا يحدث إذا فقدت الاتصال بالإنترنت؟
**ج:** سيتوقف الحفظ التلقائي، لكن البيانات ستبقى في المتصفح حتى تعود.

### س: هل يمكن تعطيل ميزة معينة؟
**ج:** نعم، يمكنك تعليق استدعاء الدالة في JavaScript.

### س: كيف أحذف نموذج قديم؟
**ج:** من Admin Panel → Invoice Templates → حدد النموذج → احذف.

### س: هل يمكن تعديل مدة الحفظ التلقائي؟
**ج:** نعم، غيّر قيمة `setInterval(autoSaveForm, 30000)` في الكود.

### س: كيف أحدد حد ائتمان لعميل؟
**ج:** Admin Panel → Customer Credit Limits → Add.
