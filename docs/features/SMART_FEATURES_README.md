## 🎯 الميزة 1: نسخ المنتج

### كيفية الاستخدام:
```
المخزون → المنتجات → انقر "نسخ" (أيقونة الملفات)
↓
سيتم فتح صفحة الإضافة مع جميع البيانات
↓
عدّل البيانات وانقر "حفظ"
↓
تم! المنتج الجديد محفوظ
```

### ما يُنسخ:
- ✅ البيانات الأساسية (الاسم، الوصف، الفئة)
- ✅ وحدات القياس والتحويل
- ✅ الأسعار والأبعاد
- ✅ أسعار الموردين
- ✅ وحدات التعبئة

### ما يُولّد تلقائياً:
- 🔄 SKU جديد
- 🔄 باركود جديد
- 🔄 إضافة "(نسخة)" في الاسم

## 🎯 الميزة 2: الاستيراج من Excel

### الخطوات:
```
1. اذهب: المخزون → استيراج Excel
2. انقر: تحميل القالب
3. ملء البيانات في الملف
4. حفظ الملف
5. رفع الملف
6. مراجعة النتائج
```

### الأعمدة المدعومة:
```
✅ اسم المنتج (مطلوب)
✅ SKU (تلقائي إذا كان فارغاً)
✅ الفئة
✅ نوع المنتج
✅ نوع المادة الخام
✅ وحدات القياس
✅ معامل التحويل
✅ سعر الشراء
✅ الحد الأدنى للمخزون
✅ المورد
✅ الباركود
✅ الوصف
```

### حجم الملف:
- 📄 ملفات Excel (.xlsx)
- 📄 ملفات CSV

### السرعة:
- ⚡ آلاف المنتجات دفعة واحدة
- ⚡ معالجة سريعة وموثوقة

## 🎯 الميزة 3: قوالس المنتجات

### كيفية الاستخدام:

#### إنشاء قالب:
```
المخزون → القوالب → قالب جديد
↓
أدخل البيانات (اسم، وحدات، أسعار، إلخ)
↓
انقر "حفظ القالب"
```

#### استخدام قالب:
```
المخزون → القوالب → اختر قالب
↓
انقر "استخدام القالب"
↓
ستُملأ البيانات تلقائياً
↓
أدخل البيانات الإضافية وانقر "حفظ"
```

#### حفظ منتج كقالب:
```
المخزون → تفاصيل المنتج
↓
انقر "حفظ كقالب"
↓
أدخل اسم القالب
↓
تم! يمكن الآن استخدام هذا القالب
```
