# 📋 خطوات الاستخدام المفصلة - نظام الإدخال الذكي

---

## 🎯 الميزة 1: نسخ المنتج - الخطوات المفصلة

### الطريقة الأولى: من قائمة المنتجات

**الخطوة 1:** افتح قائمة المنتجات
```
المخزون → المنتجات
```

**الخطوة 2:** ابحث عن المنتج المراد نسخه
```
- استخدم حقل البحث
- أو تصفح القائمة
```

**الخطوة 3:** انقر على زر "نسخ" (أيقونة الملفات)
```
في عمود الإجراءات (Actions)
```

**الخطوة 4:** ستُفتح صفحة إضافة المنتج
```
✅ جميع البيانات ممتلأة من المنتج الأصلي
✅ الاسم يحتوي على "(نسخة)"
✅ SKU والباركود جديد وفريد
```

**الخطوة 5:** عدّل البيانات حسب الحاجة
```
- غيّر الاسم
- عدّل الأسعار
- غيّر الفئة إن احتجت
- اضبط وحدات القياس
```

**الخطوة 6:** انقر "حفظ المنتج"
```
✅ تم إنشاء المنتج الجديد
✅ يمكنك عرض التفاصيل أو العودة للقائمة
```

### الطريقة الثانية: من صفحة تفاصيل المنتج

**الخطوة 1:** افتح تفاصيل المنتج
```
المخزون → المنتجات → انقر على اسم المنتج
```

**الخطوة 2:** انقر على زر "نسخ المنتج" (زر أزرق)
```
في أعلى الصفحة بين الأزرار
```

**الخطوات 3-6:** نفس الخطوات السابقة

## 🎯 الميزة 2: الاستيراج من Excel - الخطوات المفصلة

### الخطوة 1: الوصول لصفحة الاستيراج

```
المخزون → المنتجات → استيراج Excel
```

سترى صفحة بها:
- 📥 منطقة رفع الملفات
- 📥 خيار اختيار الملف
- ℹ️ معلومات وتعليمات

### الخطوة 2: تحميل قالب Excel

انقر على زر **"تحميل القالب"** (أخضر)

```
✅ سيتم تحميل ملف Excel
✅ به جميع الأعمدة المطلوبة
✅ صف مثال لفهم الصيغة
✅ ورقة تعليمات شاملة
```

### الخطوة 3: فتح الملف

```
1. افتح الملف في Excel أو LibreOffice Calc
2. سترى:
   - الصف الأول: عناوين الأعمدة
   - الصف الثاني: مثال للبيانات
   - الصفوف 3+: فارغة للإدخال
```

### الخطوة 4: ملء البيانات

```
📝 ابدأ من الصف الثالث
📝 أدخل بيانات كل منتج في صف

الأعمدة المهمة:
1. ✅ اسم المنتج (مطلوب)
   - مثال: إسفنج مضغوط 20 كثافة
   
2. SKU (اختياري - سيُولد تلقائياً)
   - مثال: PRD-0001
   
3. ✅ نوع المنتج
   - اختر من: raw_material, finished, semi_finished, accessory
   
4. نوع المادة الخام
   - اختر من: foam, fabric, spring, wood, metal, chemical, packaging, other
   
5. ✅ الفئة (اختياري لكن مهم)
   - مثال: إسفنج
   - (يجب أن تكون موجودة في النظام)
   
6. ✅ وحدة الشراء
   - مثال: roll, kg, m, m2, m3, sheet, box
   
7. ✅ وحدة الاستخدام
   - مثال: m2, kg, unit, piece
   
8. ✅ معامل التحويل
   - مثال: 60 (معنى: 1 رولة = 60 متر مربع)
   
9. ✅ سعر الشراء
   - مثال: 150.50
   
10. الحد الأدنى للمخزون
    - مثال: 10
    
11. ✅ المورد (اختياري)
    - مثال: شركة صفا فوم
    - (يجب أن يكون موجوداً في النظام)
    
12. الباركود (اختياري)
    - مثال: 1234567890123
```

### مثال عملي لملء البيانات:

```
اسم المنتج | SKU | نوع المنتج | نوع المادة | الفئة | وحدة الشراء | وحدة الاستخدام | معامل التحويل | السعر | الحد الأدنى | المورد
إسفنج 20 كثافة | | raw_material | foam | إسفنج | roll | m2 | 60 | 150.50 | 10 | صفا فوم
قماش قطن أبيض | | raw_material | fabric | أقمشة | m | m | 1 | 50 | 5 | المتحدة للنسيج
سوست عالي | | raw_material | spring | مواد | unit | unit | 1 | 25 | 100 | الرواد للصناعة
```

### الخطوة 5: حذف صف المثال

```
1. حدد الصف الثاني (صف المثال)
2. انقر زر اليمين واختر: Delete Row
3. أو احذف المحتوى فقط
```

### الخطوة 6: حفظ الملف

```
1. File → Save As
2. اختر اسم مناسب (مثل: products_import_jan2026.xlsx)
3. تأكد من الصيغة: Excel (.xlsx)
```

### الخطوة 7: العودة لصفحة الاستيراج

```
المخزون → المنتجات → استيراج Excel
```

### الخطوة 8: رفع الملف

**الطريقة الأولى: السحب والإفلات**
```
1. اسحب الملف من المستكشف
2. أفلته على منطقة الرفع (الزرقاء)
```

**الطريقة الثانية: النقر**
```
1. انقر على المنطقة الزرقاء
2. اختر الملف من جهازك
```

### الخطوة 9: مراجعة البيانات

```
بعد الرفع مباشرة:
✅ يتم التحقق من الملف
✅ يتم معالجة البيانات
✅ يتم عرض النتائج
```

### الخطوة 10: عرض النتائج

ستُعرض صفحة بـ:

**المنتجات المستوردة بنجاح:**
```
✅ عدد المنتجات
✅ قائمة بأسماء المنتجات
✅ أزرار لعرض التفاصيل
```

**الأخطاء (إن وُجدت):**
```
❌ الصف الذي به خطأ
❌ وصف المشكلة
❌ الحل المقترح
```

### الخطوة 11: البدء بتصحيح الأخطاء (إن وُجدت)

```
إذا كان هناك أخطاء:
1. قم بتصحيح البيانات في الملف
2. حفظ الملف
3. أعد رفع الملف
4. (المنتجات الناجحة السابقة لن تُنسخ مجدداً)
```

## 🎯 الميزة 3: القوالس - الخطوات المفصلة

### إنشاء قالب جديد

**الخطوة 1:** اذهب لصفحة القوالس
```
المخزون → القوالب
```

**الخطوة 2:** انقر على "قالب جديد" (زر أزرق)
```
في أعلى يمين الصفحة
```

**الخطوة 3:** أدخل بيانات القالب

في القسم الأول (معلومات القالب):
```
1. اسم القالب (مطلوب)
   - مثال: "قالب إسفنج 20 كثافة"
   
2. نوع المنتج
   - اختر من القائمة المنسدلة
   
3. نوع المادة الخام (إن كان المنتج مادة خام)
   - اختر من القائمة
   
4. الفئة
   - اختر من المنتجات الموجودة
```

في القسم الثاني (وحدات القياس):
```
1. وحدة الشراء
   - مثال: roll
   
2. وحدة الاستخدام
   - مثال: m2
   
3. معامل التحويل
   - مثال: 60
   
4. حساب تلقائي (اختياري)
   - إذا أردت إدخال الأبعاد بدلاً من معامل التحويل
```

في القسم الثالث (التسعير):
```
1. سعر الشراء
   - مثال: 150.50
   
2. الحد الأدنى للمخزون
   - مثال: 10
```

في القسم الرابع (الملاحظات):
```
أي ملاحظات إضافية عن هذا القالب
- مثال: "لا ننسَ إضافة الباركود يدوياً"
```

**الخطوة 4:** انقر "حفظ القالب" (زر أخضر)
```
✅ تم إنشاء القالب
✅ يمكنك استخدامه الآن
```

### حفظ منتج موجود كقالب

**الخطوة 1:** افتح المنتج المراد حفظه كقالب
```
المخزون → المنتجات → اختر المنتج
```

**الخطوة 2:** انقر على "حفظ كقالب" (زر أخضر)
```
في أعلى الصفحة
```

**الخطوة 3:** ستفتح نافذة تطلب اسم القالب
```
اسم مقترح: "قالب [اسم المنتج]"
يمكنك تعديله
```

**الخطوة 4:** انقر "حفظ القالب"
```
✅ تم حفظ المنتج كقالب
```

### استخدام قالب لإضافة منتج جديد

**الطريقة الأولى: من صفحة القوالس**

**الخطوة 1:** اذهب لقائمة القوالس
```
المخزون → القوالب
```

**الخطوة 2:** اختر القالب المطلوب
```
ابحث عن القالب بالاسم
```

**الخطوة 3:** انقر على "استخدام القالب" (زر أخضر)
```
يمين بطاقة القالب
```

**الخطوة 4:** ستفتح صفحة إضافة المنتج
```
✅ جميع البيانات من القالب ممتلأة
```

**الخطوة 5:** أدخل اسم المنتج الجديد
```
- غيّر الاسم
- أو أبقِ على الاسم من القالب
```

**الخطوة 6:** عدّل أي بيانات أخرى إن احتجت
```
- الأسعار
- الفئة
- الأبعاد
```

**الخطوة 7:** انقر "حفظ المنتج"
```
✅ تم إنشاء المنتج الجديد من القالب
```

### الطريقة الثانية: من صفحة إضافة منتج

**الخطوة 1:** اذهب لإضافة منتج جديد
```
المخزون → منتج جديد
```

**الخطوة 2:** ستجد قائمة منسدلة "استخدام قالب"
```
في أعلى النموذج
```

**الخطوة 3:** اختر القالب من القائمة
```
القائمة تحتوي على جميع القوالب المتاحة
```

**الخطوات 4-7:** نفس الخطوات السابقة

### تعديل قالب موجود

**الخطوة 1:** اذهب لقائمة القوالس
```
المخزون → القوالب
```

**الخطوة 2:** انقر على أيقونة التعديل (قلم)
```
في بطاقة القالب
```

**الخطوة 3:** عدّل البيانات
```
- الاسم
- الوحدات
- الأسعار
- الملاحظات
```

**الخطوة 4:** انقر "حفظ القالب"
```
✅ تم تحديث القالب
✅ التعديلات لن تؤثر على المنتجات الموجودة
```

### حذف قالب

**الخطوة 1:** اذهب لقائمة القوالس
```
المخزون → القوالب
```

**الخطوة 2:** انقر على أيقونة الحذف (سلة)
```
في بطاقة القالب
```

**الخطوة 3:** ستظهر نافذة تأكيد
```
⚠️ هل أنت متأكد من حذف القالب؟
```

**الخطوة 4:** انقر "حذف"
```
✅ تم حذف القالب
✅ المنتجات المنشأة من هذا القالب تبقى
```

## ⚠️ نصائح مهمة

### قبل الاستيراج:
```
✅ تأكد من وجود الفئات في النظام
✅ تأكد من وجود الموردين في النظام
✅ أخذ نسخة احتياطية من قاعدة البيانات
✅ فحص الملف قبل الرفع
```

### عند الاستيراج:
```
✅ ابدأ باستيراج عدد قليل من المنتجات أولاً
✅ راجع النتائج والأخطاء
✅ صحح الأخطاء وأعد المحاولة
```

### بعد الاستيراج:
```
✅ فحص المنتجات المستوردة
✅ التحقق من الأسعار والوحدات
✅ إضافة الباركود إن لزم
```

## 🆘 الأخطاء الشائعة وحلولها

### "اسم المنتج مطلوب"
```
❌ السبب: ترك خانة الاسم فارغة
✅ الحل: تأكد من كتابة اسم لكل منتج
```

### "SKU مستخدم بالفعل"
```
❌ السبب: نفس SKU موجود في النظام
✅ الحل: اتركه فارغاً ليتم التوليد التلقائي
```

### "الفئة غير موجودة"
```
❌ السبب: اسم الفئة غير موجود في النظام
✅ الحل: أضف الفئة أولاً من المخزون → الفئات
```

### "الباركود مستخدم بالفعل"
```
❌ السبب: نفس الباركود موجود لمنتج آخر
✅ الحل: استخدم باركود فريد أو اتركه فارغاً
```
