# ⚡ البدء السريع - الميزات المحسنة للفواتير

## 🚀 التثبيت في 3 خطوات

### 1️⃣ تشغيل Migration
```bash
cd /var/www/tony_erp
python manage.py migrate sales
```

### 2️⃣ إضافة النماذج للـ Admin
في `sales/admin.py`:
```python
# في آخر الملف
from .invoice_admin import *
```

### 3️⃣ إضافة الملفات الثابتة للقالب
في `templates/sales/invoice_form_enhanced.html` (أو أي قالب):

```html
<!-- في head -->
<link rel="stylesheet" href="{% static 'css/invoice_features_advanced.css' %}">

<!-- قبل إغلاق body -->
<script src="{% static 'js/invoice_features_advanced.js' %}"></script>
```

**✅ انتهى! أعد تشغيل السيرفر**

```bash
sudo systemctl restart tony_erp
```

## ⚡ 5 أشياء يجب تجربتها الآن

### 1. جرّب الحفظ التلقائي
```
1. افتح صفحة فاتورة جديدة
2. ابدأ بالكتابة
3. انتظر 30 ثانية
4. ستظهر رسالة "تم الحفظ تلقائياً ✓"
```

### 2. استخدم اختصار Ctrl+S
```
1. املأ بيانات الفاتورة
2. اضغط Ctrl+S
3. ستُحفظ مباشرة بدون النقر على زر!
```

### 3. جرّب البحث الذكي
```
1. انقر في حقل العميل (أو اضغط F3)
2. ابدأ الكتابة
3. لاحظ عرض الرصيد والمعاملات
```

### 4. اختبر الحاسبة المدمجة
```
1. في حقل السعر، اكتب: 1000+500
2. اضغط Tab للخروج من الحقل
3. ستجد النتيجة: 1500
```

### 5. اسحب وأفلت مرفق
```
1. اسحب أي صورة من سطح المكتب
2. أفلتها في منطقة المرفقات
3. ستُرفع تلقائياً!
```

## 🎓 الدرس الأول: إنشاء نموذج فاتورة

### الهدف: حفظ فاتورة متكررة كنموذج

**الخطوات:**
1. أنشئ فاتورة جديدة عادية
2. أضف العميل
3. أضف الأصناف المعتادة
4. اضغط زر "حفظ كنموذج" 📋
5. أدخل اسم: "فاتورة ABC الشهرية"
6. في المرات القادمة، اختره من القائمة!

**النتيجة:** 
- ⏱️ من 3 دقائق إلى 10 ثوانٍ
- ✅ صفر أخطاء

---

## 🎓 الدرس الثاني: نسخ فاتورة قديمة

### الهدف: إنشاء فاتورة مشابهة بسرعة

**الخطوات:**
1. افتح صفحة فاتورة جديدة
2. اضغط "نسخ من فاتورة" 📄
3. أدخل الرقم: `INV-202401-001`
4. تأكيد
5. عدّل التاريخ فقط
6. احفظ!

---

## 🎓 الدرس الثالث: استخدام اختصارات المفاتيح

### التحدي: أنشئ فاتورة بدون استخدام الماوس!

```
F3        → ابحث عن عميل
↓ ↑       → اختر من القائمة
Enter     → تأكيد
Tab       → انتقل للحقل التالي
F2        → أضف صنف
Tab Tab   → املأ الكمية والسعر
Enter     → أضف الصنف
Ctrl+S    → احفظ
```

**⏱️ الوقت المستهدف:** أقل من دقيقة!
