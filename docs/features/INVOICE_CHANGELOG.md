## كيفية الترقية

### من v1.0 إلى v2.0:

1. **نسخ الملفات الجديدة:**
```bash
cp templates/sales/invoice_form_enhanced.html /path/to/templates/
cp static/js/invoice_enhanced.js /path/to/static/js/
```

2. **تحديث URLs:**
```python
# في sales/urls.py
path('new/enhanced/', views.invoice_create, {'template': 'enhanced'})
```

3. **تحديث Views:**
```python
# في sales/views.py
if template == 'enhanced':
    return render(request, 'sales/invoice_form_enhanced.html', context)
```

4. **اختبار:**
```bash
python manage.py runserver
# زيارة: http://localhost:8000/sales/new/enhanced/
```
