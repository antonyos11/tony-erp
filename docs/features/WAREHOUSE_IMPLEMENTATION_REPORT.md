4. **إضافة مخزن بنوع محدد:**
   ```
   http://your-domain/inventory/locations/add/?type=finished

   http://your-domain/inventory/locations/add/?type=raw
   ```

### سيناريو عملي:

#### إنشاء مخازن لمصنع جديد:

**1. مخزن الخامات:**
- اذهب إلى صفحة المخازن حسب النوع
- اضغط على "إضافة مخزن خامات" في بطاقة الخامات
- املأ البيانات:
  - الكود: `RAW-MAIN`
  - الاسم: `مخزن المواد الخام الرئيسي`
  - النوع: خامات (محدد مسبقاً)
  - العنوان: `المبنى A - الطابق الأرضي`

**2. مخزن نصف المصنعة:**
- اضغط على "إضافة مخزن نصف مصنع"
- البيانات:
  - الكود: `WIP-LINE1`
  - الاسم: `خط إنتاج 1 - قيد التصنيع`
  - النوع: نصف مصنع
  - العنوان: `المبنى B - الطابق الأول`

**3. مخزن المنتجات التامة:**
- اضغط على "إضافة مخزن منتج تام"
- البيانات:
  - الكود: `FINISHED-01`
  - الاسم: `مخزن المنتجات الجاهزة`
  - النوع: منتج تام
  - العنوان: `المبنى C - الطابق الثاني`
  - ✅ تعيين كافتراضي

**4. مخزن قطع الغيار:**
- البيانات:
  - الكود: `SPARE-MAINT`
  - الاسم: `مخزن الصيانة وقطع الغيار`
  - النوع: قطع غيار

**5. مخزن المعرض:**
- البيانات:
  - الكود: `STORE-MAIN`
  - الاسم: `معرض البيع الرئيسي`
  - النوع: معرض/متجر
