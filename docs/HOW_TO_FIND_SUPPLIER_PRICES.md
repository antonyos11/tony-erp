# 🔍 كيفية الوصول لصفحة أسعار الموردين

## ✅ تم إضافة الرابط للقائمة!

تم إضافة **"💰 أسعار المواد الخام"** إلى قائمة المشتريات.

---

## 📍 الطريقة الأولى: من القائمة الجانبية (الأسهل) ⭐

### الخطوات:

1. **افتح القائمة الجانبية** (إذا كانت مغلقة)
   - اضغط على أيقونة القائمة ☰ في أعلى اليسار

2. **ابحث عن "المشتريات"** 📦
   - اضغط على **"المشتريات"**

3. **ستظهر قائمة منسدلة**، ابحث عن قسم:
   ```
   التقارير والتحليلات
   ```

4. **اضغط على**:
   ```
   💰 أسعار المواد الخام
   ```

---

## 📍 الطريقة الثانية: الرابط المباشر (الأسرع) 🚀

اكتب في شريط العنوان:

```
/purchases/material-prices/
```

أو انسخ الرابط الكامل:

```
http://localhost:8000/purchases/material-prices/
```

*(استبدل `localhost:8000` بالدومين الخاص بك)*

---

## 📋 ماذا ستجد في الصفحة؟

### 1. قائمة الموردين
- عرض جميع الموردين
- عدد المنتجات لكل مورد
- معلومات الاتصال

### 2. أسعار المواد لكل مورد
جدول يحتوي على:
- المنتج (المادة الخام)
- الفئة
- التكلفة (السعر)
- وحدة الشراء
- الحد الأدنى للطلب
- مدة التوريد
- الحالة (نشط/غير نشط)
- تاريخ السريان
- إجراءات (تعديل)

### 3. زر الإضافة
```
➕ إضافة سعر جديد
```

---

## 🔄 بعد التحديث

**مهم**: بعد إضافة الرابط للقائمة، قد تحتاج إلى:

1. **تحديث الصفحة** (F5 أو Ctrl+R)
2. **تسجيل الخروج والدخول مرة أخرى** (إذا لم يظهر الرابط)
3. **مسح الكاش** (Ctrl+Shift+Delete)

## 📸 كيف تبدو القائمة الآن؟

بعد التحديث، ستجد في قائمة **المشتريات**:

```
📦 المشتريات
├── 🎫 خصم مكتسب
├── 📋 سجل خصومات الموردين
├── ─────────────────────
├── طلبات الشراء (PR)
│   ├── طلبات الشراء
│   ├── طلب شراء جديد
│   └── طلبات من المخازن
├── ─────────────────────
├── عروض الأسعار (RFQ)
│   ├── طلبات عروض الأسعار
│   ├── طلب عروض جديد
│   ├── عروض الموردين
│   └── مقارنة الأسعار
├── ─────────────────────
├── أوامر الشراء (PO)
│   ├── أوامر الشراء
│   └── أمر شراء جديد
├── ─────────────────────
├── الشحنات والاستلام
│   ├── الشحنات
│   └── سندات الاستلام
├── ─────────────────────
├── فواتير الشراء
│   ├── قائمة المشتريات
│   └── مشتريات جديدة
├── ─────────────────────
├── الموردين
│   ├── قائمة الموردين
│   └── إضافة مورد جديد
├── ─────────────────────
└── التقارير والتحليلات
    ├── 💰 أسعار المواد الخام  ← جديد! ⭐
    ├── أداء الموردين
    ├── تحليلات المشتريات
    └── أرصدة الموردين
```
