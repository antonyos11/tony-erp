### عرض الإحصائيات فقط
```python
from smart_pricing.models_price_list import PriceList, ProductVariantPrice
from django.db.models import Min, Max, Avg

pl = PriceList.objects.get(id=6)
prices = ProductVariantPrice.objects.filter(price_list=pl)

print(f'عدد الأسعار: {prices.count()}')
stats = prices.aggregate(
    min_price=Min('final_price'),
    max_price=Max('final_price'),
    avg_price=Avg('final_price'),
)
print(f'الحد الأدنى: {stats["min_price"]:.2f}')
print(f'الحد الأقصى: {stats["max_price"]:.2f}')
print(f'المتوسط: {stats["avg_price"]:.2f}')
```

## 🎯 المميزات الإضافية

### 1. حساب تلقائي للتكلفة وهامش الربح
النظام يحسب تلقائياً:
- التكلفة لكل مقاس (بناءً على معامل التكلفة)
- هامش الربح بالمبلغ والنسبة المئوية
- السعر النهائي شامل/غير شامل الضريبة

### 2. مرونة في التسعير
- **أسعار تلقائية**: تُحسب من السعر الأساسي × معامل المقاس
- **أسعار مخصصة**: يمكن تعيين سعر يدوي لأي مقاس
- **خصومات**: تطبيق نسبة خصم على مستوى القائمة
- **ضريبة**: شامل أو غير شامل ضريبة القيمة المضافة

### 3. تصدير متعدد الصيغ
- **PDF**: للطباعة والعروض
- **Excel**: للتحليل والتعديل
- **CSV**: لاستيراد البيانات لبرامج أخرى

## 🔧 التخصيص

### تغيير اسم القائمة أو الإعدادات
```python
from smart_pricing.models_price_list import PriceList

pl = PriceList.objects.get(id=6)
pl.name = "قائمة أسعار RITA 2025"
pl.discount_percentage = 5  # خصم 5%
pl.includes_tax = True      # شامل الضريبة
pl.save()
```

### إضافة شعار مخصص
```python
# من لوحة الإدارة: /admin/smart_pricing/pricelist/6/change/
# أو برمجياً:
from django.core.files import File

pl = PriceList.objects.get(id=6)
with open('path/to/logo.png', 'rb') as f:
    pl.logo.save('rita_logo.png', File(f))
pl.save()
```

### إضافة نص ترويسي أو تذييلي
```python
pl = PriceList.objects.get(id=6)

pl.footer_text = "جميع الأسعار قابلة للتفاوض عند الطلبيات الكبيرة"
pl.save()
```
