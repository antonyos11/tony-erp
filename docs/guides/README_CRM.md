# نظام إدارة علاقات العملاء (CRM) - الدليل الشامل

## نظرة عامة
تم إنشاء نظام CRM متكامل وشامل يتضمن جميع الوحدات المطلوبة لإدارة العلاقات مع العملاء بشكل احترافي. النظام مصمم ليكون جزءاً لا يتجزأ من منظومة "المحاسب الشامل" مع تكامل كامل مع أنظمة المبيعات والمخزون والمحاسبة.

## الميزات الرئيسية

### إدارة العملاء الشاملة
- **قاعدة بيانات متقدمة** للعملاء مع 25+ حقل
- **تصنيفات ذكية** (تجزئة، جملة، VIP، موزع، شريك تجاري)
- **مصادر العملاء** المتنوعة (8 مصادر مختلفة)
- **جهات اتصال متعددة** لكل عميل
- **ترميز تلقائي** للعملاء (C000001, C000002, إلخ)
- **معلومات مالية كاملة** (حد الائتمان، شروط الدفع)

### إدارة الفرص التجارية
- **8 مراحل متدرجة** للبيع مع احتماليات دقيقة
- **تتبع القيم المالية** المتوقعة لكل فرصة
- **نظام أولوية متقدم** (منخفض، متوسط، عالي، عاجل)
- **واجهة Kanban تفاعلية** لإدارة الفرص
- **تنبيهات للفرص المتأخرة**
- **ربط كامل** مع العملاء والأنشطة

### إدارة الأنشطة والمهام
- **8 أنواع مختلفة** من الأنشطة
- **جدولة زمنية دقيقة** مع تحديد المدة

- **نظام متابعة وتذكير**
- **تسجيل النتائج** والمخرجات
- **ربط الأنشطة** بالفرص والعملاء

### نظام عروض الأسعار المتقدم
- **إنشاء عروض مفصلة** مع أصناف متعددة
- **حساب تلقائي شامل** (خصومات، ضرائب، مجاميع)
- **ترقيم تلقائي** للعروض (Q000001)
- **5 حالات مختلفة** للعروض
- **تحويل مباشر** لفواتير
- **تواريخ انتهاء صلاحية**

### نظام الدعم الفني

- **إسناد للموظفين المختصين**

### الحملات التسويقية

## واجهة برمجة التطبيقات (API)

### REST API شامل
```
العملاء:           /api/crm/customers/
الفرص التجارية:    /api/crm/opportunities/ 
الأنشطة:          /api/crm/activities/
عروض الأسعار:     /api/crm/quotations/
تذاكر الدعم:      /api/crm/tickets/
الحملات التسويقية: /api/crm/campaigns/
لوحة التحكم:      /api/crm/dashboard/
```
