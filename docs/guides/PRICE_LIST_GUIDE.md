# 📋 دليل نظام قوائم الأسعار - Rita ERP

## 🎯 نظرة عامة

نظام متكامل لإدارة قوائم الأسعار يشمل:
- ✅ **نظام المقاسات** - إدارة أحجام المنتجات (90×190، 100×200، إلخ)
- ✅ **عائلات المنتجات** - تجميع المنتجات المتشابهة (لايت ريتا، بوكيت، إلخ)
- ✅ **نظام التكلفة المتقدم** - تكاليف مباشرة وغير مباشرة
- ✅ **قوائم أسعار متعددة** - قطاعي، جملة، موزعين، VIP
- ✅ **دعم الضريبة** - أسعار شاملة وغير شاملة
- ✅ **تصدير PDF و Excel** - قوائم أسعار احترافية

## 📏 إدارة المقاسات

### من Admin Panel:
1. اذهب إلى **Admin > Smart Pricing > المقاسات**
2. اضغط **إضافة مقاس**
3. أدخل:
   - **العرض** (سم): مثل 90
   - **الطول** (سم): مثل 190
   - **معامل السعر**: نسبة من السعر الأساسي (1.0 = 100%)
   - **معامل التكلفة**: نسبة من التكلفة الأساسية

### إنشاء مقاسات شائعة تلقائياً:
```
/smart-pricing/price-lists/sizes/bulk-create/
```

### معامل السعر:
يُحسب تلقائياً بناءً على المساحة:
- 90×190 = 1.000 (المرجع)
- 100×200 = 1.170
- 200×200 = 2.339

---

## 📦 إدارة عائلات المنتجات

### إنشاء عائلة جديدة:

1. اذهب إلى **Admin > Smart Pricing > عائلات المنتجات**
2. اضغط **إضافة عائلة منتجات**
3. أدخل:
   - **الكود**: LITE-RITA
   - **الاسم**: لايت ريتا
   - **السعر الأساسي**: سعر أصغر مقاس (90×190)
   - **التكلفة الأساسية**: تكلفة أصغر مقاس
4. اختر **المقاسات المتاحة**
5. احفظ

### حساب السعر التلقائي:
```
سعر المقاس = السعر الأساسي × معامل السعر للمقاس

مثال:
- لايت ريتا 90×190 = 5067 × 1.0 = 5067
- لايت ريتا 200×200 = 5067 × 2.339 = 11,852
```

## 💰 نظام التكلفة

### فئات التكاليف المتاحة:

| الفئة | النوع | مباشرة؟ |
|-------|------|---------|
| مواد خام - فوم | direct_material | ✅ |
| مواد خام - قماش | direct_material | ✅ |
| مواد خام - سوست | direct_material | ✅ |
| أجور عمال مباشرة | direct_labor | ✅ |
| مصاريف تصنيع غير مباشرة | manufacturing_overhead | ❌ |
| مصاريف كهرباء | manufacturing_overhead | ❌ |
| مصاريف إدارية | admin_expense | ❌ |
| مصاريف تغليف | packaging | ✅ |
| مصاريف شحن | shipping | ✅ |

### إضافة تفاصيل التكلفة لنسخة منتج:

1. من Admin، اذهب إلى **نسخ المنتجات**
2. اختر النسخة المطلوبة
3. أضف تفاصيل التكلفة في القسم السفلي

### طرق توزيع التكاليف غير المباشرة:

- **لكل وحدة**: مبلغ ثابت لكل منتج
- **نسبة من التكاليف المباشرة**: مثل 15% من (المواد + الأجور)
- **لكل متر مربع**: للمنتجات كبيرة الحجم
- **لكل ساعة عمل**: حسب وقت الإنتاج

## 📋 قوائم الأسعار

### القوائم المتاحة:

| الكود | الاسم | الخصم | الضريبة |
|-------|------|-------|---------|
| RETAIL | أسعار القطاعي | 0% | غير شامل |
| WHOLESALE | أسعار الجملة | 15% | غير شامل |
| DISTRIBUTOR | أسعار الموزعين | 25% | غير شامل |
| VIP | أسعار عملاء VIP | 10% | غير شامل |
| RETAIL-TAX | قطاعي شامل الضريبة | 0% | شامل 14% |

### إنشاء قائمة جديدة:

1. **Admin > قوائم الأسعار > إضافة**
2. أدخل:
   - **الكود**: SPECIAL
   - **الاسم**: عروض خاصة
   - **نوع القائمة**: مخصص
   - **نسبة الخصم**: 20%
   - **شامل الضريبة**: ✅/❌
   - **نسبة الضريبة**: 14%

### تخصيص أسعار معينة:

يمكنك تحديد سعر مخصص لأي منتج/مقاس يتجاوز الحساب التلقائي:

1. من تفاصيل العائلة
2. أدخل السعر في الخانة المناسبة
3. احفظ

## 📤 تصدير قوائم الأسعار

### من الواجهة:
```
/smart-pricing/price-lists/lists/{id}/export/?format=pdf
/smart-pricing/price-lists/lists/{id}/export/?format=excel
/smart-pricing/price-lists/lists/{id}/export/?format=csv
```

### خيارات التصدير:
- `format`: pdf, excel, csv
- `tax_column`: true/false (عمود الضريبة)
- `show_cost`: true/false (للاستخدام الداخلي)

### تصدير جميع القوائم:
```
/smart-pricing/price-lists/export-all/
```

## 🔧 الصيانة

### تحديث أسعار عائلة:
```python
from smart_pricing.services_price_list import CostCalculationService

family = ProductFamily.objects.get(code='LITE-RITA')
CostCalculationService.update_family_prices(family, base_cost=Decimal('3500'))
```

### حساب هامش الربح:
```python
from smart_pricing.services_price_list import CostCalculationService

margin = CostCalculationService.calculate_margin(
    selling_price=Decimal('5000'),
    cost=Decimal('3500')
)
# {'margin_amount': 1500, 'margin_percentage': 30, 'markup_percentage': 42.86}
```

## ❓ الأسئلة الشائعة

### كيف أضيف منتج جديد؟
1. أضف عائلة منتجات جديدة
2. اختر المقاسات المتاحة
3. حدد السعر والتكلفة الأساسية
4. النظام يحسب باقي الأسعار تلقائياً

### كيف أغير سعر مقاس معين فقط؟
من تفاصيل العائلة، أدخل سعر مخصص في الخانة المطلوبة.

### كيف أصدر قائمة أسعار للعميل؟
1. اذهب لقائمة الأسعار المطلوبة
2. اضغط **تصدير PDF** أو **Excel**
3. القائمة جاهزة للإرسال

### كيف أضيف ضريبة لقائمة موجودة؟
1. عدل قائمة الأسعار
2. فعّل **شامل الضريبة**
3. حدد نسبة الضريبة
4. الأسعار تُحدث تلقائياً
