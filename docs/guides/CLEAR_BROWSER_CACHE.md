# تعليمات مسح الـ Cache من المتصفح
===========================================

## الطريقة السريعة:
اضغط على **Ctrl + Shift + Delete** (أو Cmd + Shift + Delete على Mac)

أو:

## في Google Chrome/Edge:
1. افتح أدوات المطور: F12
2. اضغط بزر الماوس الأيمن على زر التحديث 🔄
3. اختر "Empty Cache and Hard Reload" (إفراغ الذاكرة المؤقتة وإعادة التحميل)

## أو:
1. اذهب للإعدادات Settings
2. Privacy and Security → Clear browsing data
3. اختر "Cached images and files"
4. اضغط Clear data

## ثم:
أعد تحميل الصفحة بالضغط على: **Ctrl + F5**

هذا سيجلب آخر تحديثات CSS و JavaScript من السيرفر.
