تشغيل بدون إنترنت (Windows)

الهدف: إعداد وتشغيل النظام على جهاز لا يتوفر به اتصال إنترنت.

على جهاز متصل بالإنترنت:
1) افتح مجلد المشروع.
2) شغّل make_offline_bundle.bat لتنزيل الحزم إلى vendor\wheels.
3) انسخ مجلد المشروع بالكامل مع vendor\wheels إلى الجهاز الهدف.

على الجهاز الهدف (بدون إنترنت):
1) تأكد من تثبيت Python 3.11+ مضاف للـ PATH.
2) شغّل start_anywhere.bat.
   - سيكتشف vendor\wheels ويثبت الحزم محلياً بدون إنترنت.
3) أكمل الخطوات المعتادة (migrate، collectstatic، تشغيل الخادم محلياً أو LAN).

ملاحظات:
- لو أردت نقل قاعدة البيانات والملفات: انسخ db.sqlite3 ومجلد media أيضاً.
- إن أردت تشغيل LAN، قد تحتاج صلاحية مسؤول لإضافة استثناء جدار الحماية للمنفذ 8000.
