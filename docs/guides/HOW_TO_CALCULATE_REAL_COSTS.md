## 📋 الخطوات العملية

### 1️⃣ حساب سعر السلك الحديد الحقيقي

#### أ) اتصل بالمورد
```
سؤال: كم سعر طن الحديد قطر 2.0 مم؟
الإجابة: مثلاً 20,000 ج/طن
```

#### ب) احسب سعر الكيلو
```
سعر الطن = 20,000 ج
سعر الكيلو = 20,000 ÷ 1,000 = 20 ج/كجم
```

#### ج) سجل الأسعار لكل قطر
| القطر | السعر/طن | السعر/كجم |
|-------|----------|-----------|
| 1.5 مم | ؟؟؟ ج | ؟؟؟ ج |
| 1.8 مم | ؟؟؟ ج | ؟؟؟ ج |
| 2.0 مم | 20,000 ج | 20 ج |
| 2.2 مم | ؟؟؟ ج | ؟؟؟ ج |
| 2.4 مم | ؟؟؟ ج | ؟؟؟ ج |

---

### 2️⃣ حساب وزن السلك في السوست

#### أ) اوزن السوست الفعلية
```
1. خذ 10 سوست من نفس النوع
2. اوزنهم على ميزان دقيق
3. اقسم على 10

مثال:
وزن 10 سوست بونيل = 150 جرام
وزن السوست الواحدة = 150 ÷ 10 = 15 جرام = 0.015 كجم
```

#### ب) سجل الأوزان
| نوع السوست | وزن 10 سوست | وزن الواحدة |
|------------|-------------|-------------|
| بونيل 2.0 مم | 150 جم | 0.015 كجم |
| بونيل 2.2 مم | ؟؟؟ جم | ؟؟؟ كجم |
| Pocket متوسط | ؟؟؟ جم | ؟؟؟ كجم |

---

### 3️⃣ حساب تكلفة العمالة

#### الطريقة الأولى: حسب الإنتاجية
```
راتب العامل اليومي = 200 ج
ساعات العمل = 8 ساعات
إنتاجية العامل = 700 سوست/يوم

تكلفة العمالة = 200 ÷ 700 = 0.29 ج/سوست
```

#### الطريقة الثانية: حسب الوقت
```
راتب العامل بالساعة = 200 ÷ 8 = 25 ج/ساعة
إنتاجية العامل = 90 سوست/ساعة

تكلفة العمالة = 25 ÷ 90 = 0.28 ج/سوست
```

#### ج) سجل التكاليف
| نوع السوست | الإنتاجية/يوم | التكلفة/وحدة |
|------------|---------------|--------------|
| بونيل بسيط | 700 سوست | 0.29 ج |
| Pocket معقد | 300 سوست | 0.67 ج |

---

### 4️⃣ حساب تكلفة القماش (للسوست المنفصلة)

#### أ) قس القماش المستخدم
```
1. قس طول وعرض القماش لكل سوست
2. احسب المساحة
3. اضرب في سعر المتر

مثال:
طول القماش = 8 سم = 0.08 متر
عرض القماش = 6 سم = 0.06 متر
المساحة = 0.08 × 0.06 = 0.0048 متر مربع

إذا كان سعر المتر = 100 ج
تكلفة القماش = 0.0048 × 100 = 0.48 ج
```

---

### 5️⃣ الحساب النهائي

#### مثال كامل: سوست بونيل 2.0 مم

**المدخلات:**
```
✓ سعر السلك: 20 ج/كجم (من المورد)
✓ وزن السوست: 0.015 كجم (من الميزان)
✓ تكلفة العمالة: 0.29 ج (من الإنتاجية)
✓ نسبة الهدر: 3% (من الخبرة)
```

**الحساب:**
```
1. تكلفة السلك = 0.015 كجم × 20 ج/كجم = 0.30 ج
2. تكلفة الهدر = 0.30 × 3% = 0.009 ج
3. تكلفة العمالة = 0.29 ج
4. التكلفة الإجمالية = 0.30 + 0.009 + 0.29 = 0.599 ج
5. التكلفة النهائية = 0.60 ج (بعد التقريب)
```

## 💡 نصائح مهمة

### ✅ افعل
1. **اوزن السوست بانتظام**: كل شهر أو عند تغيير الإنتاج
2. **راقب الإنتاجية**: سجل كم سوست ينتج العامل فعلياً
3. **حدّث الأسعار**: عند تغيير سعر الحديد في السوق
4. **احسب الهدر الفعلي**: من الإنتاج الحقيقي

### ❌ لا تفعل
1. **لا تعتمد على التقديرات**: استخدم قياسات حقيقية
2. **لا تنسى الهدر**: 3-5% هدر طبيعي
3. **لا تهمل تكلفة الكهرباء**: يمكن إضافتها للعمالة
4. **لا تنسى الصيانة**: تكلفة صيانة الماكينات

## 🎯 مثال عملي كامل

### السيناريو
مصنع ينتج سوست بونيل 2.0 مم

### القياسات الفعلية
```
1. سعر السلك من المورد:
   - طن الحديد 2.0 مم = 22,000 ج
   - الكيلو = 22 ج

2. وزن السوست:
   - وزن 10 سوست = 165 جرام
   - وزن الواحدة = 16.5 جرام = 0.0165 كجم

3. الإنتاجية:
   - راتب العامل = 220 ج/يوم
   - الإنتاج = 650 سوست/يوم
   - تكلفة العمالة = 220 ÷ 650 = 0.34 ج

4. الهدر الفعلي:
   - من التجربة = 4%
```

### الحساب
```
تكلفة السلك = 0.0165 × 22 = 0.363 ج
تكلفة الهدر = 0.363 × 4% = 0.015 ج
تكلفة العمالة = 0.34 ج
─────────────────────────────────────
التكلفة الإجمالية = 0.718 ج
التكلفة النهائية = 0.72 ج/سوست
```
