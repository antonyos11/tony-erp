🤖 PROMPT 1: الفحص الشامل (انسخ هذا مباشرة)
═══════════════════════════════════════════════════════════════

أنت خبير في تطوير تطبيقات Django وتحليل الأكواد. أريدك أن تقوم بفحص شامل للقائمة الجانبية (Sidebar) في تطبيق Django وإصلاح جميع المشاكل.

📊 المهام المطلوبة:

1. فحص الروابط المكررة:
   - ابحث عن أي روابط تستخدم نفس data-url-name أكثر من مرة
   - حدد الروابط التي تشير لنفس الصفحة لكن بنصوص مختلفة
   - اقترح حلول: حذف المكررات أو جعل كل رابط يؤدي لوظيفة مختلفة

2. فحص بنية الكود:
   - تأكد من أن كل الروابط داخل Modules منظمة
   - ابحث عن روابط مباشرة خارج Modules
   - اقترح إعادة هيكلة موحدة

3. فحص روابط "قريباً":
   - ابحث عن روابط تؤدي إلى core:coming_soon
   - اقترح إخفاء هذه الوحدات أو إضافة badge "قريباً"

4. فحص الروابط المباشرة:
   - ابحث عن data-url-type="direct" أو روابط بدون data-url-name
   - اقترح تحويلها إلى URL names

5. فحص التداخل والتنظيم:
   - ابحث عن وحدات متشابهة يمكن دمجها
   - اقترح تحسينات في التنظيم

📝 الكود المطلوب فحصه:

[ضع هنا كود HTML للقائمة الجانبية]

🎯 الناتج المطلوب:
1. قائمة بكل المشاكل المكتشفة مع رقم السطر
2. الكود المُصلح لكل مشكلة
3. توصيات للتحسين
4. ملخص بعدد المشاكل المُصلحة

⚠️ ملاحظات مهمة:
- احتفظ بالتنسيق العربي RTL
- احتفظ بالأيقونات والألوان
- لا تحذف أي وحدة إلا إذا كانت فارغة تماماً
- أضف تعليقات توضيحية للتعديلات

🤖 PROMPT 4: تحويل روابط مباشرة
═══════════════════════════════════════════════════════════════

أنا أعمل على تطبيق Django وأريد تحويل جميع الروابط المباشرة إلى URL names.

المطلوب:
1. ابحث عن جميع الروابط ذات data-url-type="direct"
2. لكل رابط مباشر:
   - اقترح URL name مناسب
   - اكتب الكود لإضافته في urls.py
   - اكتب الكود المُعدّل في HTML

الكود:
[ضع الكود هنا]

مثال للناتج:

الرابط المباشر:
<a href="/purchases/vendors/balances" data-url-type="direct">
  أرصدة الموردين
</a>

الحل المقترح:

1. إضافة في purchases/urls.py:
urlpatterns = [
    path('vendors/balances/', views.vendor_balances, name='vendor_balances'),
]

2. التعديل في HTML:
<a href="{% url 'purchases:vendor_balances' %}" data-url-name="purchases:vendor_balances">
  أرصدة الموردين
</a>

🤖 PROMPT 5: إنشاء تقرير تفصيلي

أنت محلل أكواد محترف. أريدك أن تفحص القائمة الجانبية وتنشئ تقرير تفصيلي.

المطلوب:

1. إحصائيات عامة:
   - إجمالي عدد الوحدات (Modules)
   - إجمالي عدد الروابط
   - إجمالي الروابط الفريدة
   - نسبة التكرار

2. تحليل كل وحدة:
   - اسم الوحدة
   - عدد الروابط فيها
   - عدد الروابط الصحيحة
   - عدد الروابط المعطلة
   - عدد الروابط "قريباً"

3. قائمة المشاكل:
   - عدد الروابط المكررة
   - عدد الروابط المباشرة
   - عدد الوحدات الفارغة/المعطلة
   - أقسام متداخلة

4. التوصيات:
   - أولوية عالية (يجب إصلاحها فوراً)
   - أولوية متوسطة (يُفضل إصلاحها)
   - أولوية منخفضة (تحسينات اختيارية)
