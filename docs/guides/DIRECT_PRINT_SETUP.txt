⚡ الخطوات السريعة (5 دقائق):
───────────────────────────────────────────────────────────────────────────

الخطوة 1: التحميل
   افتح: http://72.62.176.249/static/print_agent_windows.zip
   حمّل الملف

الخطوة 2: الاستخراج
   كليك يمين على ZIP
   Extract All → C:\TonyERP\
   (ستظهر مجلد: C:\TonyERP\print_agent_windows)

الخطوة 3: التثبيت
   1. Win + R → cmd → Ctrl + Shift + Enter (كـ Admin)
   2. cd C:\TonyERP\print_agent_windows
   3. pip install websockets pywin32 --user
   4. python -m pywin32_postinstall -install

الخطوة 4: التشغيل
   شغّل: C:\TonyERP\print_agent_windows\run_windows.bat
   (ستظهر نافذة سوداء - اتركها مفتوحة)

الخطوة 5: الاختبار
   افتح: C:\TonyERP\print_agent_windows\test_print.html
   اضغط: "طباعة اختبارية"
   🖨️ طابعتك ستطبع الآن!

───────────────────────────────────────────────────────────────────────────
❌ المشاكل الشائعة والحلول:
───────────────────────────────────────────────────────────────────────────

المشكلة: "Python غير مثبت"
الحل:
   1. حمّل: https://www.python.org/downloads/
   2. أثناء التثبيت: ✅ اختر "Add Python to PATH"
   3. أعد تشغيل Command Prompt
   4. تحقق: python --version

المشكلة: "لا توجد طابعات"
الحل:
   1. تأكد الطابعة موصولة (USB)
   2. Settings → Devices → Printers & Scanners
   3. تأكد أنها في القائمة
   4. أعد تشغيل run_windows.bat

المشكلة: "خطأ في pip"
الحل:
   python -m pip install --upgrade pip
   python -m pip install websockets pywin32 --user
