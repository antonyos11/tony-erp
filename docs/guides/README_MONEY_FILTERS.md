# فلاتر تنسيق المبالغ المالية

تمت إضافة مجموعة فلاتر موحدة لتنسيق القيم المالية عبر النظام.

## الإعدادات الافتراضية
- `DEFAULT_CURRENCY` (افتراضي: `SAR`)
- `DEFAULT_CURRENCY_SYMBOL` (افتراضي: `﷼`)

يمكن تعديلهما عبر متغيرات البيئة.

## الفلاتر المتاحة
### 1) `money`
يعرض الرقم مع تجميع (آلاف) + عدد منازل عشرية افتراضي (2) + رمز العملة.

صيغ `arg` المدعومة:
| مثال | الوصف |
|-------|-------|
| `{{ v|money }}` | استخدام الإعدادات الافتراضية |
| `{{ v|money:'USD' }}` | كود عملة (يحاول إيجاد رمز؛ وإلا يستخدم الكود) |
| `{{ v|money:'USD:$' }}` | تحديد الكود والرمز يدوياً |
| `{{ v|money:'$' }}` | فرض رمز فقط دون تغيير الكود |
| `{{ v|money:'|0' }}` | نفس العملة الافتراضية بلا كسور |
| `{{ v|money:'0' }}` | اختصار: بدون كسور |
| `{{ v|money:'USD|0' }}` | كود + بدون كسور |
| `{{ v|money:'USD|3' }}` | كود + ثلاث منازل |

### 2) `money_plain`
أرقام منسقة (تجميع) بدون رمز عملة.

| مثال | نتيجة |
|-------|--------|
| `{{ v|money_plain }}` | 1,234.50 |
| `{{ v|money_plain:'0' }}` | 1,235 |

### 3) `money_compact`
مثل `money` لكن يحذف `.00` وأصفار الكسور الزائدة.

| إدخال | إخراج (مثال) |
|--------|---------------|
| 1234.00 | 1,234 ﷼ |
| 1234.50 | 1,234.5 ﷼ |
| 1234.5300 | 1,234.53 ﷼ |

## أمثلة سريعة
```django
{{ product.price|money }}
{{ invoice.total|money:'|0' }}     {# بلا كسور #}
{{ payment.amount|money:'USD:$' }}
{{ amount|money_compact }}
{{ amount|money_plain:'0' }}
```

## ملاحظات
- يتم استخدام `django.utils.formats.number_format` لاحترام الإعدادات المحلية.
- القيم غير الصالحة أو `None` تظهر `-`.
- الاحتياطيات `.bak` أنشأها السكربت `scripts/bulk_update_money_filters.py` ويمكن حذفها بعد التحقق.

## سكربت التعديل الآلي
الملف: `scripts/bulk_update_money_filters.py`
- استبدل الأنماط القديمة `{{ x|floatformat:2 }} {% currency_symbol %}` بـ `{{ x|money }}`.
- شمل مسارات: `app/templates`, `dist/TonyERP/app/templates`, `_migration_package/src/templates`.

## إزالة النسخ الاحتياطية (بعد التحقق)
PowerShell:
```powershell
Get-ChildItem -Recurse -Filter *.bak d:\الشامل\الشامل\الشامل\app | Remove-Item
```

## أفكار مستقبلية
- دعم Multi-Currency عبر سياق جلسة أو نموذج فرع.
- Cache للفورمات المتكرر في جداول كبيرة.
- خيار إعداد عالمي لعدد المنازل الافتراضي.
