## 🔧 تحضير بيئة الاختبار

### الخطوة 1: تشغيل الخادم
```bash
cd app
python manage.py runserver
```

### الخطوة 2: تحميل البيانات التجريبية
```bash
python manage.py load_sample_data
python manage.py setup_pos
```

### الخطوة 3: تسجيل الدخول
- **الرابط**: http://127.0.0.1:8000
- **المستخدم**: `superadmin`
- **كلمة المرور**: `admin123`

## 💼 اختبار المبيعات

### السيناريو 1: إنشاء فاتورة بيع

| الخطوة | الإجراء | النتيجة المتوقعة |
|--------|---------|------------------|
| 1 | اذهب إلى: المبيعات > الفواتير | عرض قائمة الفواتير |
| 2 | اضغط "إضافة فاتورة جديدة" | نموذج إنشاء فاتورة |
| 3 | اختر عميل من القائمة | ظهور بيانات العميل |
| 4 | أضف منتج وحدد الكمية | حساب الإجمالي تلقائياً |
| 5 | اضغط "حفظ" | رسالة نجاح + رقم الفاتورة |

### السيناريو 2: طباعة فاتورة
| الخطوة | الإجراء | النتيجة المتوقعة |
|--------|---------|------------------|
| 1 | افتح فاتورة محفوظة | عرض تفاصيل الفاتورة |
| 2 | اضغط "طباعة" | معاينة الطباعة |
| 3 | اضغط Ctrl+P | نافذة الطباعة |

## 📈 اختبار التقارير

| التقرير | المسار | ما يجب التحقق منه |

| تقرير المبيعات | التقارير > المبيعات | إجمالي المبيعات، التفاصيل |

## 🐛 الإبلاغ عن الأخطاء

عند اكتشاف خطأ، سجّل:
1. **الخطوات** لإعادة إنتاج الخطأ
2. **النتيجة المتوقعة** vs **النتيجة الفعلية**
3. **رسالة الخطأ** إن وجدت
4. **لقطة شاشة** إن أمكن
