## 📝 خطوات التجربة السريعة

### الخطوة 1: أضف بيانات تجريبية
1. افتح: `http://169.254.49.211:8000/admin/`
2. اذهب لـ "الحسابات الإلكترونية"
3. أضف محفظة (مثال: فودافون كاش)
4. اذهب لـ "الخزائن"
5. أضف خزينة (مثال: خزينة المعرض الرئيسي)

### الخطوة 2: سجل إيراد تجريبي
1. افتح: `http://169.254.49.211:8000/accounting/entries/revenue/create/`
2. املأ البيانات الأساسية
3. **في قسم "وجهة دخول المبلغ":**
   - اختر "حساب إلكتروني"
   - اختر المحفظة التي أضفتها
4. احفظ

### الخطوة 3: شاهد التقرير
1. افتح: `http://169.254.49.211:8000/accounting/reports/ledger-account/`
2. اختر الحساب
3. اضغط "بحث"
4. ستشاهد الإيراد مع وجهة الدخول!
