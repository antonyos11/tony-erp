# 🏢 دليل نظام إدارة الفروع والمعارض

## نظرة عامة
نظام موحد ومتكامل لإدارة جميع الفروع والمعارض والمستودعات في Tony ERP

---

## 🔗 الروابط الرئيسية

### الداشبورد الرئيسي
- **الرابط:** `/branches/` أو `/dashboard/branches/`
- **الوصف:** لوحة تحكم شاملة تعرض الإحصائيات والفروع النشطة

### إدارة الفروع
- **قائمة الفروع:** `/branches/list/`
- **إضافة فرع:** `/branches/create/`
- **تفاصيل فرع:** `/branches/<id>/`
- **تعديل فرع:** `/branches/<id>/edit/`

### المعارض (Showrooms)
- **قائمة المعارض:** `/showrooms/`
- **إضافة معرض:** `/showrooms/create/`

### التحويلات بين الفروع
- **قائمة التحويلات:** `/branches/transfers/`
- **تحويل جديد:** `/branches/transfers/create/`

### إدارة الموظفين
- **موظفو الفروع:** `/branches/staff/`
- **إضافة موظف:** `/branches/staff/create/`

### المصروفات
- **المصروفات:** `/branches/expenses/`
- **إضافة مصروف:** `/branches/expenses/create/`

### أجهزة نقاط البيع
- **قائمة الأجهزة:** `/branches/pos-devices/`
- **إضافة جهاز:** `/branches/pos-devices/create/`

## 🎯 كيفية الاستخدام

### إضافة فرع جديد

#### الطريقة 1: من الواجهة
1. اذهب إلى `/branches/create/`
2. املأ البيانات المطلوبة
3. احفظ

#### الطريقة 2: من لوحة الإدارة
1. اذهب إلى `/admin/branches/branch/add/`
2. املأ النموذج
3. احفظ

#### الطريقة 3: سكريبت سريع
```bash
# عدل البيانات في الملف أولاً
nano add_branch_quick.py

# ثم شغل السكريبت
python3 add_branch_quick.py
```

#### الطريقة 4: Django Shell
```bash
python3 manage.py shell
```
```python
from branches.models import Branch
from django.contrib.auth import get_user_model
User = get_user_model()
admin = User.objects.filter(is_superuser=True).first()

Branch.objects.create(
    code='BR010',
    name='فرع الخبر',
    branch_type='branch',
    status='active',
    city='الخبر',
    created_by=admin
)
```
