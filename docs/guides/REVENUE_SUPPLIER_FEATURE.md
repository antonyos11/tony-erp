## كيفية الاستخدام

### 1. إضافة إيراد مع مورد
1. انتقل إلى: المحاسبة → قيود الحسابات → إيراد جديد
2. املأ البيانات المطلوبة
3. اختر المورد من القائمة المنسدلة (اختياري)
4. احفظ القيد

### 2. عرض تقرير الموردين الإجمالي
1. انتقل إلى: المحاسبة → قيود الحسابات
2. اضغط على زر "تقرير الموردين"
3. حدد الفترة الزمنية المطلوبة
4. سيعرض التقرير:
   - إجمالي إيرادات كل مورد
   - عدد القيود لكل مورد
   - النسبة المئوية من إجمالي الإيرادات

### 3. عرض تقرير مورد معين
1. من تقرير الموردين الإجمالي
2. اضغط على زر "التفاصيل" بجانب المورد المطلوب
3. سيعرض:
   - معلومات المورد الكاملة
   - إحصائيات (إجمالي، متوسط، عدد)
   - جدول تفصيلي بجميع القيود

## الروابط المباشرة

- قائمة القيود: `/accounting/entries/`
- إنشاء إيراد: `/accounting/entries/revenue/create/`
- تقرير الموردين: `/accounting/entries/revenue/supplier-report/`
- تفاصيل مورد: `/accounting/entries/revenue/supplier/{supplier_id}/`

## الميزات الإضافية

1. **الفلترة حسب التاريخ:** جميع التقارير تدعم الفلترة حسب فترة زمنية محددة
2. **التصميم التفاعلي:** واجهة مستخدم حديثة وسهلة الاستخدام
3. **الأداء المحسن:** استخدام `select_related` لتقليل استعلامات قاعدة البيانات
4. **تقارير شاملة:** إحصائيات ورسوم بيانية لكل مورد
5. **دعم اللغة العربية:** جميع النصوص والواجهات بالعربية
