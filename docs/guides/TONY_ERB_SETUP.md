# Tony ERB - دليل التشغيل والإعداد

## التشغيل السريع

### 1. تشغيل النظام
```bash
# الطريقة الأولى: التشغيل البسيط
start_server.bat

# الطريقة الثانية: سطر الأوامر
python start_network_server.py
```

### 2. الوصول للنظام
```
الرابط: http://[عنوان-IP-الجهاز]:8000
المستخدم الافتراضي: superadmin
كلمة المرور: admin123
```

## كيفية عمل نظام الصلاحيات الجديد

### 1. فحص تلقائي للصلاحيات
النظام يفحص صلاحيات المستخدم تلقائياً ويعرض فقط:
- الوحدات التي له صلاحية فيها
- العناصر الفرعية المسموحة
- الأزرار والروابط المصرح بها

### 2. مستويات الصلاحيات
```
مدير عام (المستوى 5): جميع الوحدات
مدير محاسبة (المستوى 4): المحاسبة + التقارير
مدير مخزون (المستوى 3): المخزون + المشتريات
مدير مبيعات (المستوى 3): المبيعات + CRM
مدير HR (المستوى 3): الموارد البشرية
موظف (المستوى 2): وحدة واحدة محددة
عرض فقط (المستوى 1): قراءة فقط
```

### 3. الوحدات المدعومة
- **المحاسبة**: `accounting`
- **المخزون**: `inventory`  
- **المبيعات**: `sales`
- **المشتريات**: `purchases`
- **الموارد البشرية**: `hr`
- **إدارة العملاء**: `crm`
- **الإنتاج**: `production`
- **التقارير**: `reports`

## حل المشاكل الشائعة

### المشكلة: القوائم لا تظهر
**الحل:** تأكد من:
1. وجود صلاحيات للمستخدم في قاعدة البيانات
2. إضافة context processors في settings.py
3. استخدام {% load tony_erb_tags %} في القوالب

### المشكلة: التصميم لا يظهر
**الحل:** تأكد من:
1. وجود ملف CSS في مجلد static
2. تشغيل `collectstatic` إذا لزم الأمر
3. التأكد من إعدادات STATIC_URL في settings

### المشكلة: الأيقونات لا تظهر
**الحل:**
1. تأكد من اتصال الإنترنت لتحميل Bootstrap Icons
2. أو حمّل الأيقونات محلياً
