# 📖 كيفية إصدار بطاقة تعريف - دليل مصور خطوة بخطوة

## 🎯 الهدف
إصدار بطاقة تعريف لموظف مع QR Code وباركود

---

## 📝 الخطوات التفصيلية

### الخطوة 1️⃣: افتح قائمة البطاقات

**الطريقة الأولى:**
- من القائمة الرئيسية → **الموارد البشرية** → **بطاقات الهوية**

**الطريقة الثانية:**
- افتح الرابط مباشرة: `http://72.62.176.249/hr/id-cards/`

**ما ستراه:**
```
┌─────────────────────────────────────────────┐
│  🎫 قائمة البطاقات التعريفية              │
│  ─────────────────────────────────────────  │
│  [🔍 ابحث...]  [➕ إصدار بطاقة] [📊]      │
│                                             │
│  جدول البطاقات الموجودة...                │
└─────────────────────────────────────────────┘
```

---

### الخطوة 2️⃣: اضغط على زر "إصدار بطاقة"

**أين تجد الزر:**
- في أعلى الصفحة، زر أزرق كبير مكتوب عليه **"➕ إصدار بطاقة"**
- أو في منتصف الصفحة إذا لم تكن هناك بطاقات

**ماذا سيحدث:**
- ستنتقل لصفحة اختيار الموظف

---

### الخطوة 3️⃣: اختر الموظف

**ما ستراه:**
```
┌─────────────────────────────────────────────┐
│  👤 اختيار موظف لإصدار البطاقة            │
│  ─────────────────────────────────────────  │
│  [🔍 ابحث عن موظف...]                     │
│  [القسم ▼]  [الحالة ▼]                    │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │   👤     │  │   👤     │  │   👤     │ │
│  │  أحمد    │  │  محمد    │  │  علي     │ │
│  │ #12345   │  │ #12346   │  │ #12347   │ │
│  │ محاسب    │  │ مبيعات   │  │ مخازن    │ │
│  │ المالية  │  │ التسويق  │  │ المخازن  │ │
│  │[إصدار]  │  │[إصدار]  │  │[إصدار]  │ │
│  └──────────┘  └──────────┘  └──────────┘ │
└─────────────────────────────────────────────┘
```

**كيف تبحث عن الموظف:**

**أ) البحث بالاسم:**
- اكتب اسم الموظف في مربع البحث
- النتائج ستظهر فوراً

**ب) البحث بالرقم الوظيفي:**
- اكتب رقم الموظف (مثل: 12345)
- النتائج ستظهر فوراً

**ج) الفلترة بالقسم:**
- اختر القسم من القائمة المنسدلة
- ستظهر فقط موظفي هذا القسم

**د) الفلترة بالحالة:**
- اختر "نشط" أو "غير نشط"
- ستظهر فقط الموظفين بهذه الحالة

**ملاحظة مهمة:**
- إذا رأيت علامة 🏷️ **"لديه بطاقة"** على بطاقة الموظف، هذا يعني أن لديه بطاقة نشطة بالفعل
- يمكنك إصدار بطاقة جديدة له (ستُلغى القديمة تلقائياً)

---

### الخطوة 4️⃣: اضغط "إصدار بطاقة" للموظف المطلوب

**ماذا تفعل:**
- اضغط على الزر الأزرق **"إصدار بطاقة"** تحت اسم الموظف

**ماذا سيحدث:**
- ستنتقل لصفحة إنشاء البطاقة

---

### الخطوة 5️⃣: املأ بيانات البطاقة

**ما ستراه:**
```
┌─────────────────────────────────────────────┐
│  🎫 إنشاء بطاقة تعريف جديدة               │
│  ─────────────────────────────────────────  │
│                                             │
│  ┌─ بيانات الموظف ────────────────────┐   │
│  │  👤 أحمد محمد                       │   │
│  │  💼 محاسب                           │   │
│  │  🏢 المالية                         │   │
│  │  #️⃣ 12345                           │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  ┌─ اختيار القالب ─────────────────────┐  │
│  │  ⬜ القالب الافتراضي (محدد)        │  │
│  │  ⬜ قالب 1                          │  │
│  │  ⬜ قالب 2                          │  │
│  └─────────────────────────────────────┘   │
│                                             │
│  ┌─ إعدادات البطاقة ───────────────────┐  │
│  │  مدة الصلاحية: [سنة واحدة ▼]       │  │
│  │                                      │  │
│  │  💡 جاهز للإصدار!                  │  │
│  │  اضغط الزر أدناه لإنشاء البطاقة    │  │
│  │                                      │  │
│  │  [رجوع]  [➕ إنشاء البطاقة الآن]   │  │
│  └─────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

**ما يجب عليك فعله:**

**أ) اختيار القالب (اختياري):**
- القالب الافتراضي محدد تلقائياً
- يمكنك اختيار قالب آخر إذا أردت
- اضغط على القالب لتحديده

**ب) تحديد مدة الصلاحية:**
- الافتراضي: **سنة واحدة** (12 شهر)
- يمكنك اختيار:
  - 6 أشهر
  - سنة واحدة ✅
  - سنتان
  - ثلاث سنوات

---

### الخطوة 6️⃣: اضغط "إنشاء البطاقة الآن"

**ماذا تفعل:**
- اضغط على الزر الأزرق الكبير **"➕ إنشاء البطاقة الآن"**

**ماذا سيحدث:**
- سيتم إنشاء البطاقة
- ستظهر رسالة نجاح: **"✅ تم إنشاء بطاقة جديدة للموظف أحمد محمد بنجاح!"**
- ستنتقل تلقائياً لصفحة معاينة البطاقة

---

### الخطوة 7️⃣: معاينة البطاقة

**ما ستراه:**
```
┌─────────────────────────────────────────────┐
│  🎫 EMP-00001-ABC12345                      │
│  أحمد محمد                                  │
│  [✅ فعّالة]  [📜 السجل]                   │
│  ─────────────────────────────────────────  │
│                                             │
│  📅 2026/01/13    📅 2027/01/13             │
│  تاريخ الإصدار   تاريخ الانتهاء           │
│                                             │
│  🖨️ 0            🔍 0                       │
│  عمليات الطباعة  عمليات التحقق             │
│  ─────────────────────────────────────────  │
│                                             │
│  ┌─ الوجه الأمامي ─────────────────────┐  │
│  │  [معاينة البطاقة]                   │  │
│  └─────────────────────────────────────┘   │
│                                             │
│  ┌─ الوجه الخلفي ──────────────────────┐  │
│  │  [معاينة البطاقة]                   │  │
│  └─────────────────────────────────────┘   │
│                                             │
│  ⚙️ الإجراءات المتاحة:                    │
│  [📄 تحميل PDF]  [💳 بطاقة PVC]           │
│  [👤 ملف الموظف]  [➕ بطاقة جديدة]        │
└─────────────────────────────────────────────┘
```

**ما يمكنك فعله الآن:**

1. **تحميل PDF**: لطباعة البطاقة على ورق A4
2. **بطاقة PVC**: لطباعة البطاقة على بطاقة بلاستيكية
3. **ملف الموظف**: للعودة لملف الموظف
4. **بطاقة جديدة**: لإصدار بطاقة جديدة لنفس الموظف

## ❓ الأسئلة الشائعة

**س: ماذا لو كان الموظف لديه بطاقة نشطة؟**
ج: يمكنك إصدار بطاقة جديدة، وستُلغى القديمة تلقائياً.

**س: كم مدة صلاحية البطاقة؟**
ج: يمكنك اختيار من 6 أشهر إلى 3 سنوات (الافتراضي: سنة واحدة).

**س: هل يمكن طباعة البطاقة أكثر من مرة؟**
ج: نعم، يمكنك تحميل PDF أو PVC في أي وقت.

**س: كيف أتحقق من البطاقة؟**
ج: امسح QR Code باستخدام الماسح الضوئي في النظام.
