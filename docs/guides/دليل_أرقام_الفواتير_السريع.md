# كيف تشوف رقم الفاتورة القادم؟ 🔢

## الطرق المختلفة لمعرفة رقم الفاتورة التالي

### 1️⃣ من خلال المتصفح (الأسهل)

**الخطوات:**
1. افتح المتصفح وروح على:
   ```
   http://your-domain.com/sales/next-numbers/
   ```

2. هتشوف صفحة فيها كل أرقام الفواتير التالية:
   - فاتورة مبيعات عادية
   - فاتورة ضريبية - مبيعات
   - فاتورة ضريبية - مرتجع مبيعات
   - فاتورة ضريبية - مشتريات
   - فاتورة ضريبية - مرتجع مشتريات

3. تقدر تنسخ أي رقم بضغطة زر واحدة!

---

### 2️⃣ من خلال سطر الأوامر

**الخطوات:**
```bash
cd /var/www/tony_erp
python3 manage.py show_next_invoice_numbers
```

**النتيجة:**
```
============================================================
أرقام الفواتير التالية
============================================================

فواتير المبيعات:
  → الرقم التالي: INV-202601-000123

الفواتير الضريبية - مبيعات:
  → الرقم التالي: TAX-S-202601-00045

...إلخ
```

---

### 3️⃣ من خلال API (للمطورين)

**JavaScript:**
```javascript
fetch('/sales/api/next-numbers/')
    .then(response => response.json())
    .then(data => {
        console.log('رقم الفاتورة التالي:', data.next_numbers.sales_invoice);
    });
```

**Python:**
```python
from sales.next_invoice_number import preview_invoice_numbers

numbers = preview_invoice_numbers()
print(numbers['sales_invoice'])  # INV-202601-000123
```

## الأرقام اللي هتشوفها

### فاتورة مبيعات عادية
```
INV-202601-000123
│   │      └── رقم تسلسلي (6 أرقام)
│   └────────── السنة والشهر (202601 = يناير 2026)
└────────────── نوع الفاتورة (Invoice)
```

### فاتورة ضريبية - مبيعات
```
TAX-S-202601-00045
│   │ │      └── رقم تسلسلي (5 أرقام)
│   │ └────────── السنة والشهر
│   └──────────── نوع (S = Sales)
└──────────────── فاتورة ضريبية (Tax)
```

## أمثلة عملية

### مثال 1: التخطيط للمعاملات المحاسبية
```
المحاسب: "عايز أسجل قيد محاسبي للفاتورة اللي هتتعمل بكرة"
1. يفتح صفحة الأرقام التالية
2. يشوف الرقم: INV-202601-000456
3. يستخدمه في القيد المحاسبي
4. لما يتعمل الفاتورة، يكون الرقم جاهز
```

### مثال 2: استخدام في Excel
```
1. افتح صفحة الأرقام
2. انسخ الرقم اللي عايزه
3. الصقه في ملف Excel
4. جهز التقرير قبل ما تعمل الفاتورة
```

## أسئلة شائعة

**س: هل الرقم المعروض هو نفسه اللي هيتعمل؟**
ج: في الغالب نعم، إلا لو حد عمل فاتورة جديدة من نفس النوع قبلك.

**س: ممكن أحجز رقم معين؟**
ج: حالياً لأ، لكن هنضيف الميزة دي قريب.

**س: الأرقام بتبدأ من جديد كل شهر؟**
ج: نعم، كل شهر بيبدأ من رقم 1.

**س: إيه الفرق بين INV و TAX؟**
ج: INV للفواتير العادية، TAX للفواتير الضريبية.

## نصائح للاستخدام الأمثل

1. **افتح الصفحة قبل ما تبدأ شغل** عشان تعرف الأرقام اللي هتشتغل بيها
2. **حدث الصفحة لو فضلت مفتوحة فترة طويلة** عشان تشوف آخر تحديث
3. **استخدم زر النسخ** بدل ما تكتب الرقم يدوي
4. **خلي الصفحة في bookmark** عشان توصلها بسرعة
