تشغيل النظام على أي كمبيوتر (Windows)

المتطلبات:
- Windows 10/11
- Python 3.11 أو أحدث مُثبّت (مع خيار Add to PATH)
- اتصال إنترنت لأول مرة لتثبيت الحزم

خطوات سريعة:
1) انسخ مجلد المشروع بالكامل إلى الكمبيوتر الجديد (مثلاً D:\الشامل).
2) افتح المجلد وشغّل الملف start_anywhere.bat بالنقر المزدوج.
3) سيتولى الملف:
   - إنشاء البيئة الافتراضية .venv إن لم توجد
   - تثبيت المتطلبات من requirements.txt
   - تطبيق المهاجرات وجمع الملفات الثابتة
   - تشغيل الخادم
4) اختر وضع التشغيل:
   - 1: محلي فقط http://127.0.0.1:8000
   - 2: شبكة محلية LAN (سيطلب تأكيد، وقد تحتاج تشغيل كمسؤول لإضافة استثناء الجدار الناري)

بيانات الدخول الافتراضية:
- المستخدم: superadmin
- كلمة المرور: admin123

الوصول من الهاتف (LAN):
- تأكد أن الهاتف على نفس شبكة الـ Wi‑Fi
- استخدم عنوان الجهاز الظاهر في الكونسول، مثل: http://192.168.x.x:8000
- إن لم يفتح: اسمح للمنفذ 8000 في جدار الحماية (Private) أو شغّل start_anywhere.bat كمسؤول عند اختيار LAN.

مشاكل شائعة وحلول:
- Python غير موجود: ثبّت Python من https://www.python.org/downloads/ وتأكد من تفعيل “Add to PATH”.
- فشل تثبيت الحزم: تحقق من الإنترنت، ثم أعد تشغيل start_anywhere.bat.
- باث عربي أو مسافات: شغّل start_anywhere.bat بالنقر المزدوج (cmd) لتجنب مشاكل PowerShell.
- تشغيل يدوي موجود أيضاً عبر: setup_windows.bat (إعداد كامل مع بيانات تجريبية) أو start_server.bat (تشغيل سريع للشبكة).
