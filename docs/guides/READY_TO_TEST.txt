🚀 الميزات الجديدة - جربها الآن!
─────────────────────────────────────────────────────────────────────

1️⃣  لوحة الوصول السريع
    📍 http://169.254.49.211:8000/quick/
    
    ✨ ستجد:
    • إحصائيات سريعة لليوم
    • 25 إجراء سريع جاهز
    • التقارير الأكثر استخداماً
    • واجهة حديثة وجميلة

─────────────────────────────────────────────────────────────────────

2️⃣  البحث الشامل الذكي
    ⌨️  اضغط: Ctrl + K
    
    🔍 ابحث عن:
    • المنتجات
    • الفواتير
    • العملاء
    • الموظفين
    
    💡 نتائج فورية أثناء الكتابة!

─────────────────────────────────────────────────────────────────────

3️⃣  اختصارات لوحة المفاتيح
    📍 http://169.254.49.211:8000/quick/shortcuts/
    ⌨️  أو اضغط: Ctrl + /
    
    🎯 أهم الاختصارات:
    
    Ctrl + K            →  البحث السريع
    Ctrl + /            →  دليل الاختصارات
    Ctrl + Shift + I    →  فاتورة مبيعات جديدة
    Ctrl + Shift + P    →  فاتورة مشتريات جديدة
    Ctrl + Shift + N    →  منتج جديد
    Ctrl + Shift + J    →  قيد محاسبي
    Alt + A + C         →  دليل الحسابات
    Alt + R + S         →  تقرير المبيعات

─────────────────────────────────────────────────────────────────────

4️⃣  العمليات الجماعية
    📍 http://169.254.49.211:8000/quick/bulk-actions/
    
    ⚡ يمكنك:
    • تحديث 100+ سجل في دقيقة واحدة
    • تحديث الأسعار بالجملة
    • تحديث المخزون
    • إرسال رسائل جماعية

═══════════════════════════════════════════════════════════════════════

🎓 تمرين سريع (3 دقائق):
─────────────────────────────────────────────────────────────────────

1. سجل الدخول إلى النظام
2. اضغط Ctrl + K
3. اكتب "منتج" أو أي كلمة بحث
4. شاهد النتائج الفورية!
5. اضغط Ctrl + / لرؤية جميع الاختصارات
6. افتح /quick/ لرؤية لوحة الوصول السريع
