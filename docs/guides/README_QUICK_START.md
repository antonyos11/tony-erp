## طريقتان للتشغيل

### الطريقة الأولى: تلقائي (الأسهل)

#### 1. تثبيت Python أولاً:
- اذهب إلى: https://python.org/downloads/
- حمّل Python 3.11+ 
- **مهم:** اختر "Add Python to PATH"
- ثبّت Python وأعد تشغيل الكمبيوتر

#### 2. تشغيل النظام:
انقر نقرة مزدوجة على: **`setup_windows.bat`**

### الطريقة الثانية: يدوي

```cmd
# 1. تثبيت المتطلبات
python -m pip install -r requirements.txt

# 2. إعداد قاعدة البيانات
python manage.py migrate

# 3. جمع الملفات الثابتة
python manage.py collectstatic --noinput

# 4. إنشاء بيانات تجريبية
python manage.py load_sample_data

# 5. فحص النظام
python manage.py system_self_check --fix

# 6. تشغيل الخادم
python manage.py runserver
```

## إدارة العملة الافتراضية (Currency)

### تغيير العملة الافتراضية

1. تأكد من أن العملة المرغوبة موجودة أو استخدم الأمر التالي لإنشائها وجعلها افتراضية:
```cmd
python manage.py switch_currency EGP ج.م "الجنيه المصري" 2
```
الصيغة:
```
python manage.py switch_currency <CODE> <SYMBOL> "<NAME>" <DECIMALS>
```

مثال لليورو:
```cmd
python manage.py switch_currency EUR € "اليورو" 2
```

### ما الذي يفعله الأمر؟
- ينشئ أو يحدّث سجل العملة.
- يضبط `is_default=True` ويعطّل الافتراضية عن البقية.
- يحدث الكاش الداخلي المستخدم في الفلاتر.

### الفلاتر والقوالب
- استخدم `{{ value|money }}` أو `{{ value|money_ctx }}` لعرض الأرقام آلياً بالعملة الحالية.
- تجنّب كتابة الرمز يدوياً (لا تكتب ج.م أو $ أو ج.م داخل f-string).

### تبديل سريع بدون إعادة تشغيل
بعد تنفيذ `switch_currency` افرغ جلسة المتصفح (أو افتح نافذة خاصة) لرؤية الرمز الجديد فوراً.

### فحص النصوص القديمة
يمكن تشغيل أمر فحص النصوص لاستبدال كلمة "ج.م" القديمة (إن وجدت):
```cmd
python manage.py scan_currency_text --dry-run
python manage.py scan_currency_text --commit
```

### استرجاع العملة السابقة
فقط أعد تشغيل `switch_currency` بالمعطيات المطلوبة.

### مشاكل شائعة
| المشكلة | السبب | الحل |
|---------|-------|------|
| ما زال يظهر رمز قديم | جلسة/كاش متصفح قديم | افتح نافذة خاصة أو امسح الجلسة |
| لم يتغير الرمز في بعض الشاشات | نص ثابت في كود قديم | استبدل بـ `|money` أو `|money_ctx` |
| خطأ OperationalError في فحص النصوص | جدول قديم غير محدث | تجاهل أو اكتمِل الترحيلات `migrate` |
