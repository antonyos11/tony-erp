## 1. الملخص التنفيذي | Executive Summary

### نبذة عن النظام
نظام **Tony ERP** هو منصة متكاملة وشاملة لإدارة موارد المؤسسات (ERP)، مصممة خصيصاً للشركات الصغيرة والمتوسطة في منطقة الشرق الأوسط. يتميز النظام بدعم كامل للغة العربية (RTL) ومتوافق مع الممارسات والمعايير المحلية.

### القيمة المقترحة الفريدة (Unique Value Proposition)

| الميزة | الوصف |
|--------|-------|
| **ذكاء اصطناعي حقيقي** | محركات فعلية للتسعير الذكي (Smart Pricing) وخدمة العملاء (WhatsApp AI) |
| **تخصص صناعي دقيق** | نظام متخصص لتصنيع المراتب والمفروشات (من القص إلى التغليف والضمان) |
| **أتمتة كاملة** | من استلام طلب WhatsApp ← إنشاء عرض سعر AI ← أمر تصنيع ← صرف مواد آلي |
| **79 وحدة متكاملة** | تغطية شاملة لجميع جوانب إدارة الأعمال |
| **توافق محلي** | ZATCA، الفوترة الإلكترونية، ضريبة القيمة المضافة |

## 9. واجهة برمجة التطبيقات | API Reference

### 9.1 نقاط النهاية الرئيسية

#### المصادقة
```
POST /api/token/               # الحصول على JWT token
POST /api/token/refresh/       # تحديث token
POST /api/logout/              # تسجيل الخروج
```

#### المنتجات
```
GET    /api/products/          # قائمة المنتجات
POST   /api/products/          # إضافة منتج
GET    /api/products/{id}/     # تفاصيل منتج
PUT    /api/products/{id}/     # تحديث منتج
DELETE /api/products/{id}/     # حذف منتج
POST   /api/products/bulk/     # استيراد جماعي
```

#### الفواتير
```
GET    /api/invoices/          # قائمة الفواتير
POST   /api/invoices/          # إنشاء فاتورة
GET    /api/invoices/{id}/     # تفاصيل فاتورة
POST   /api/invoices/{id}/approve/  # اعتماد فاتورة
GET    /api/invoices/{id}/pdf/      # تصدير PDF
```
