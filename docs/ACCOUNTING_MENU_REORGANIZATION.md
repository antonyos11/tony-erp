## 🎯 الهدف من إعادة التنظيم

تحويل قائمة المحاسبة من **قائمة طويلة مزدحمة (65+ بند)** إلى قائمة منظمة بـ **6 مجموعات واضحة**:

1. **تقليل الفوضى**: من قائمة واحدة طويلة إلى 6 أقسام قابلة للطي
2. **ترتيب منطقي**: حسب سير العمل اليومي (قيود → خزينة → حسابات → تقارير)
3. **إضافة شارات**: للعناصر التي تحتاج متابعة
4. **اختصارات لوحة المفاتيح**: للعمليات الأساسية

## 🎨 التحسينات المطبقة

### 1. إضافة البنود المفقودة
✅ **سند قبض** - عملية يومية أساسية  
✅ **سند صرف** - عملية يومية أساسية  
✅ **حساب جديد** - اختصار سريع  
✅ **الأرصدة النقدية** - نُقلت من التقارير للعمليات اليومية  
✅ **كشف حساب** - تقرير مهم مفقود  
✅ **تقرير مراكز التكلفة** - تحليل مهم  
✅ **السنة المالية** - إعداد أساسي  

### 2. إعادة الترتيب حسب الأولوية
- **لوحة المحاسبة** → الأولى دائماً (نظرة عامة)
- **القيود غير المُرحّلة** → ترتيب 3 (قبل القائمة الكاملة)
- **سند قبض/صرف** → بعد القيود مباشرة
- **ميزان المراجعة** → أول التقارير (الأكثر استخداماً)

### 3. تجميع منطقي داخل كل فئة
#### العمليات اليومية:
- **القيود** (4 بنود)
- **الخزينة** (5 بنود)

#### التعريفات:
- **الحسابات** (3 بنود)
- **الإعدادات** (3 بنود)

#### التقارير:
- **القوائم المالية** (4 تقارير)
- **التقارير التفصيلية** (5 تقارير)

    'order': 2,  # ← جديد!
    # ...
}

# ودالة التجميع تدعم الفرز:

    # ...
