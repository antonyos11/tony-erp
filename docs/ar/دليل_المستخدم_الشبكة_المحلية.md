# دليل تشغيل نظام الشامل على الشبكة المحلية

## مرحباً بك في نظام الشامل للمحاسبة والإدارة

هذا الدليل سيساعدك على تشغيل النظام على الشبكة المحلية ليصبح متاحاً لجميع الأجهزة المتصلة بنفس شبكة الواي فاي.

---

## المتطلبات الأساسية

### جهاز الخادم (Server):
- Windows 10/11
- Python 3.8 أو أحدث
- RAM: 4GB على الأقل
- مساحة تخزين: 10GB على الأقل
- اتصال مستقر بشبكة الواي فاي

### أجهزة العملاء (Clients):
- أي جهاز كمبيوتر أو لاب توب أو تابلت
- متصفح إنترنت حديث (Chrome, Firefox, Edge)
- متصل بنفس شبكة الواي فاي

---

## خطوات تشغيل النظام

### الخطوة 1: إعداد جهاز الخادم

1. **تأكد من اتصال الجهاز بالشبكة:**
   - اتصل بشبكة الواي فاي المراد استخدامها
   - تأكد من استقرار الاتصال

2. **تشغيل النظام:**
   - انتقل لمجلد النظام: `d:\الشامل`
   - انقر نقراً مزدوجاً على ملف `start_server.bat`
   - أو افتح Command Prompt وشغل: `python start_network_server.py`

3. **انتظار التحضيرات:**
   - سيقوم النظام بفحص المتطلبات
   - تحديث قاعدة البيانات
   - إعداد الملفات اللازمة
   - إعداد الجدار الناري تلقائياً

4. **ستظهر معلومات الاتصال:**
   ```
   رابط النظام: http://192.168.1.100:8000
   المدير العام: superadmin
   كلمة المرور: admin123
   ```

### الخطوة 2: الوصول من الأجهزة الأخرى

1. **من أي جهاز آخر على نفس الشبكة:**
   - افتح متصفح الإنترنت
   - اكتب الرابط الذي ظهر على جهاز الخادم
   - مثال: `http://192.168.1.100:8000`

2. **تسجيل الدخول:**
   - اسم المستخدم: `superadmin`
   - كلمة المرور: `admin123`
   - اضغط "دخول"

## إدارة المستخدمين والصلاحيات

### إنشاء مستخدمين جدد:

1. **سجل دخول كمدير عام**
2. **اذهب لإدارة المستخدمين**
3. **اضغط "إضافة مستخدم جديد"**
4. **املأ البيانات:**
   - اسم المستخدم
   - كلمة المرور
   - الاسم بالعربية
   - رقم الموظف
   - اختر الدور المناسب

### الأدوار المتاحة:

| الدور | الوصف | الصلاحيات |
|-------|--------|-----------|
| مدير عام | صلاحيات كاملة | جميع الوحدات |
| مدير محاسبة | إدارة الحسابات والتقارير | المحاسبة + التقارير |
| مدير مخزون | إدارة المخزون والمشتريات | المخزون + المشتريات |
| مدير مبيعات | إدارة المبيعات والعملاء | المبيعات + CRM |
| موظف محاسبة | العمليات المحاسبية اليومية | إدخال قيود |
| موظف مبيعات | فواتير المبيعات | إدخال فواتير |
| مستخدم عرض | عرض التقارير فقط | عرض فقط |

## الأمان والحماية

### ميزات الأمان المدمجة:

1. **تسجيل جميع العمليات:**
   - كل عملية تُسجل مع الوقت والمستخدم
   - سجل أنشطة مفصل لكل مستخدم

2. **إدارة الجلسات:**
   - انتهاء الجلسة بعد فترة عدم النشاط
   - منع الجلسات المتعددة للمستخدم الواحد

3. **تنبيهات الأمان:**
   - تنبيهات عند محاولات الدخول الفاشلة
   - تنبيهات عند انتهاك الصلاحيات

### نصائح الأمان:

- غير كلمات المرور الافتراضية فوراً
- استخدم كلمات مرور قوية
- لا تشارك معلومات تسجيل الدخول
- أغلق النظام عند عدم الاستخدام
- افصل الشبكة عن الإنترنت إذا لم تكن ضرورية

## حل المشاكل الشائعة

### المشكلة: لا يمكن الوصول للنظام من جهاز آخر

**الحلول:**
1. تأكد من اتصال جميع الأجهزة بنفس شبكة الواي فاي
2. تأكد من عدم تفعيل VPN على الأجهزة
3. أعد تشغيل جهاز الخادم
4. تحقق من إعدادات الجدار الناري:
   ```
   Windows + R → "firewall.cpl" → Allow an app → Browse → اختر python.exe
   ```

### المشكلة: بطء في النظام

**الحلول:**
1. أعد تشغيل جهاز الخادم
2. تأكد من قوة إشارة الواي فاي
3. أغلق البرامج غير الضرورية على جهاز الخادم
4. لا تفتح النظام على أكثر من 10 أجهزة في نفس الوقت

### المشكلة: فقدان البيانات

**الحلول:**
1. النظام ينشئ نسخة احتياطية تلقائية يومياً في مجلد `backups`
2. لاستعادة نسخة احتياطية:
   ```
   نسخ ملف النسخة الاحتياطية → لصقه مكان db.sqlite3
   ```

## الدعم التقني

### عند مواجهة مشاكل:

1. **راجع سجل الأخطاء:**
   - مجلد `logs` في مجلد النظام
   - ابحث عن رسائل الخطأ الأخيرة

2. **معلومات النظام:**
   - إصدار Python: `python --version`
   - حالة قاعدة البيانات: تحقق من وجود ملف `db.sqlite3`
   - مساحة القرص المتاحة

3. **التواصل مع الدعم:**
   - اجمع معلومات المشكلة
   - أرفق صورة شاشة للخطأ
   - اذكر الخطوات التي قمت بها

## نصائح الاستخدام الأمثل

### لأفضل أداء:
- أعد تشغيل جهاز الخادم يومياً
- انشئ نسخ احتياطية دورية
- راقب سجلات النظام بانتظام
- درّب المستخدمين على النظام

### للحفاظ على البيانات:
- لا تغلق النظام أثناء عمليات الحفظ
- استخدم UPS لحماية من انقطاع الكهرباء
- راجع التقارير دورياً للتأكد من صحة البيانات
