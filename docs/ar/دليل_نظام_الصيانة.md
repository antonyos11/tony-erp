# دليل نظام الصيانة والمعدات

## نظرة عامة
تم إنشاء نظام الصيانة والمعدات بنجاح كجزء من النظام الشامل للمحاسبة والإدارة.

## المكونات المكتملة

### 1. النماذج (Models)
- **MachineCategory**: فئات الماكينات
- **Machine**: الماكينات والمعدات
- **MaintenanceType**: أنواع الصيانة
- **SparePart**: قطع الغيار
- **MaintenanceRequest**: طلبات الصيانة
- **MaintenanceSchedule**: جدولة الصيانة
- **MaintenanceRecord**: سجلات الصيانة
- **SparePartUsage**: استخدام قطع الغيار
- **MaintenanceChecklist**: قوائم فحص الصيانة

### 2. المسارات (URLs)
تم إنشاء جميع المسارات المطلوبة وربطها بالنظام الرئيسي

### 3. المشاهد (Views)
- لوحة تحكم الصيانة
- قائمة وإدارة الماكينات
- قائمة وإدارة قطع الغيار
- طلبات الصيانة
- جدولة الصيانة
- سجلات الصيانة

### 4. القوالب (Templates)
- لوحة تحكم تفاعلية
- قوائم الماكينات مع فلترة متقدمة
- إدارة قطع الغيار
- نماذج إدخال البيانات

### 5. النماذج (Forms)
نماذج شاملة لجميع العمليات مع التحقق من البيانات

### 6. لوحة الإدارة (Admin)
إعدادات كاملة لإدارة جميع المكونات

## البيانات التجريبية المنشأة

### فئات الماكينات (5 فئات)
- ماكينات الإنتاج الرئيسية
- سيور النقل
- ضواغط الهواء
- مولدات الكهرباء
- مضخات المياه

### أنواع الصيانة (5 أنواع)
- صيانة دورية عامة
- فحص أمان
- إصلاح عام
- تنظيف شامل
- تشحيم وتزييت

### الماكينات (5 ماكينات)
- ماكينة الإنتاج الأولى
- ماكينة التعبئة الرئيسية
- سير النقل المركزي
- ضاغط الهواء الرئيسي
- مولد الكهرباء الاحتياطي

### قطع الغيار (8 قطع)
- فلتر زيت محرك
- حزام نقل
- بوريه كرة
- زيت تشحيم صناعي
- مفتاح كهربائي
- جوان مطاطي
- مرولة ضغط
- فلتر هواء

## روابط الوصول السريع

### الخادم المحلي (Development)
- **النظام الرئيسي**: http://localhost:8000/
- **نظام الصيانة**: http://localhost:8000/maintenance/
- **لوحة الإدارة**: http://localhost:8000/admin/
- **الماكينات**: http://localhost:8000/maintenance/machines/
- **قطع الغيار**: http://localhost:8000/maintenance/spare-parts/
- **طلبات الصيانة**: http://localhost:8000/maintenance/requests/

### ملف الوصول السريع
`d:\الشامل\maintenance_quick_access.html`

## الميزات الرئيسية

### لوحة التحكم
- إحصائيات شاملة للماكينات
- تنبيهات للصيانة المتأخرة
- مراقبة حالة المخزون
- آخر سجلات الصيانة

### إدارة الماكينات
- فلترة وبحث متقدم
- تتبع حالة الماكينات
- إدارة الضمان
- جدولة الصيانة الدورية

### إدارة قطع الغيار
- مراقبة المخزون
- تنبيهات نقص المخزون
- تتبع التكاليف
- إدارة الموردين

### طلبات الصيانة
- إنشاء وإدارة الطلبات
- تتبع حالة الطلبات
- تحديد الأولويات
- إسناد المهام

## التكامل مع النظام

تم ربط نظام الصيانة بالأنظمة التالية:
- **نظام الموارد البشرية**: لإسناد المهام للموظفين
- **نظام المخزون**: لإدارة قطع الغيار
- **النظام المحاسبي**: لتتبع التكاليف
- **نظام الإنتاج**: لمراكز العمل
