# 🚀 دليل سريع: استخدام AI Prompts لإصلاح القائمة الجانبية

## 📂 الملفات المُنشأة:

1. **`AI_PROMPTS_FOR_SIDEBAR_FIX.md`** - دليل شامل مع أمثلة تفصيلية
2. **`PROMPTS_READY_TO_COPY.txt`** - نصوص جاهزة للنسخ مباشرة
3. **`SIDEBAR_ANALYSIS_REPORT.md`** - تقرير تحليل المشاكل
4. **`check_sidebar_links.py`** - سكريبت Python للفحص التلقائي

---

## ⚡ البداية السريعة (3 خطوات)

### الخطوة 1️⃣: افتح ملف الـ Prompts
```bash
# للقراءة فقط
cat /var/www/tony_erp/PROMPTS_READY_TO_COPY.txt

# أو للنسخ
nano /var/www/tony_erp/PROMPTS_READY_TO_COPY.txt
```

### الخطوة 2️⃣: انسخ الـ Prompt المناسب
```
PROMPT 1: فحص شامل (للمبتدئين) ← ابدأ هنا
PROMPT 2: فحص روابط مكررة (محدد)
PROMPT 3: إصلاح فوري (10 دقائق)
PROMPT 4: تحويل روابط مباشرة
PROMPT 5: تقرير تفصيلي
```

### الخطوة 3️⃣: استخدمه مع AI
1. افتح ChatGPT أو Claude
2. الصق الـ Prompt
3. أضف كود HTML للقائمة الجانبية
4. احصل على الحل!

## 🎯 أي Prompt أستخدم؟

| الحالة | الـ Prompt المناسب | الوقت المتوقع |
|--------|-------------------|----------------|
| 🆕 أول مرة/مبتدئ | **PROMPT 1** (الشامل) | 5-10 دقائق |
| 🔥 محتاج حل سريع | **PROMPT 3** (الفوري) | 10 دقائق |
| 🔍 محتاج تقرير مفصل | **PROMPT 5** (التقرير) | 3-5 دقائق |
| 🔄 عندي روابط مكررة | **PROMPT 2** (المكررات) | 2-3 دقائق |
| 🔗 عندي روابط مباشرة | **PROMPT 4** (التحويل) | 5 دقائق |

## 💡 مثال عملي كامل

### السيناريو:
عندك قائمة جانبية فيها روابط مكررة وعايز تصلحها بسرعة

### الخطوات:

**1. افتح ملف الـ Prompts:**
```bash
cat PROMPTS_READY_TO_COPY.txt
```

**2. انسخ PROMPT 2 (فحص الروابط المكررة)**

**3. افتح ChatGPT والصق:**
```
[PROMPT 2 كامل]

الكود:
<li><a data-url-name="partners:customers_list">البحث عن العملاء</a></li>
<li><a data-url-name="partners:customers_list">العملاء</a></li>
<li><a data-url-name="partners:customers_list">قائمة العملاء</a></li>
<li><a data-url-name="sales:invoice_list">المبيعات</a></li>
```

**4. النتيجة من AI:**
```
❌ وجدت روابط مكررة:

1. partners:customers_list (تكرر 3 مرات)
   الحل: احذف الأول والثاني، احتفظ بـ "قائمة العملاء"
   
الكود المُصلح:
<li><a data-url-name="partners:customers_list">قائمة العملاء</a></li>
<li><a data-url-name="sales:invoice_list">المبيعات</a></li>
```

**5. طبّق التعديل:**
- افتح ملف sidebar.html
- احذف الروابط المكررة
- احتفظ بواحد فقط
- احفظ واختبر
