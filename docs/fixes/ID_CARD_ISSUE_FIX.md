# إصلاح زر "إصدار بطاقة" ✅

## المشكلة
كان زر "إصدار بطاقة" في صفحة قائمة البطاقات التعريفية لا يعمل بشكل صحيح لأنه كان يحتاج إلى `employee_id` ولكن لم يكن هناك طريقة لاختيار الموظف.

## الحل المطبق

### 1. إنشاء صفحة اختيار الموظف
تم إنشاء صفحة جديدة تعرض جميع الموظفين النشطين بتصميم جميل وسهل الاستخدام:

**الملفات المضافة:**
- `templates/hr/id_card_select_employee.html` - صفحة اختيار الموظف

**المميزات:**
- ✅ عرض الموظفين في شبكة (Grid) جميلة
- ✅ صور الموظفين أو الأحرف الأولى
- ✅ بحث فوري بالاسم أو الرقم الوظيفي
- ✅ فلترة حسب القسم
- ✅ فلترة حسب الحالة (نشط/غير نشط)
- ✅ عرض علامة للموظفين الذين لديهم بطاقة نشطة بالفعل
- ✅ زر "إصدار بطاقة" لكل موظف

### 2. إضافة View جديد
تم إضافة `id_card_select_employee` في `hr/views.py`:

```python
@login_required

    """صفحة اختيار الموظف لإصدار بطاقة"""
    # جلب الموظفين النشطين
    # إضافة معلومة هل لديهم بطاقة نشطة
    # عرض الصفحة
```

### 3. تحديث URLs
تم إضافة المسار الجديد في `hr/urls.py`:

```python
path('id-cards/select-employee/', views.id_card_select_employee, name='id_card_select_employee'),
```

### 4. تحديث الروابط
تم تحديث جميع أزرار "إصدار بطاقة" لتوجه إلى صفحة اختيار الموظف:

**في `templates/hr/employee_id_cards_list.html`:**
- زر "إصدار بطاقة" في شريط الأدوات
- زر "إصدار بطاقة" في حالة عدم وجود بطاقات

### 5. تحسين التجربة
تم تحديث `id_card_create_single` ليوجه تلقائياً لصفحة اختيار الموظف إذا لم يتم تمرير `employee_id`.

## كيفية الاستخدام

### الطريقة الأولى: من قائمة البطاقات
1. اذهب إلى **الموارد البشرية** → **بطاقات الهوية**
2. اضغط على زر **"إصدار بطاقة"**
3. ستظهر صفحة اختيار الموظف
4. ابحث عن الموظف أو استخدم الفلاتر
5. اضغط على **"إصدار بطاقة"** للموظف المطلوب
6. املأ بيانات البطاقة واضغط **"إنشاء البطاقة"**

### الطريقة الثانية: الرابط المباشر
يمكنك الوصول مباشرة عبر:
```
/hr/id-cards/select-employee/
```
