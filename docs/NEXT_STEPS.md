## 🚀 الخطوات المطلوبة الآن

### 1. إضافة Setting للمخزون (اختياري)

أضف إلى ملف `.env`:
```bash
ALLOW_NEGATIVE_INVENTORY=0
```

- `0` = منع المخزون السالب (موصى به)
- `1` = السماح بالمخزون السالب

### 2. إعادة تشغيل السيرفر

```bash
# إذا كنت تستخدم systemd
sudo systemctl restart gunicorn

# أو إذا كنت في development
python3 manage.py runserver
```

### 3. إعداد الحسابات المحاسبية

من واجهة الإدارة:

1. اذهب إلى: **الإعدادات** → **إعدادات المحاسبة**

2. اختر الحسابات التالية:
   - **حساب العملاء (AR Account):**  
     اختر حساب من نوع "أصول" (مثل: 1210 - العملاء)
   
   - **حساب ضريبة المخرجات (VAT Output):**  
     اختر حساب من نوع "التزامات" (مثل: 2310 - ضريبة القيمة المضافة)

3. احفظ الإعدادات

> **ملاحظة:** حساب إيرادات المبيعات سيتم البحث عنه تلقائياً (أي حساب برقم يبدأ بـ 4xxx من نوع revenue)

## 🧪 اختبار الوظائف الجديدة

### اختبار API

```bash
# Test health endpoint
curl http://localhost:8000/api/health/

# Test with authentication
curl -u admin:yourpassword http://localhost:8000/api/resource/
```

**النتيجة المتوقعة:**
```json
{"status": "ok", "message": "API is working"}
```

### اختبار CRM Workflow

1. **إنشاء فرصة تجارية:**
   - CRM → الفرص التجارية → إضافة جديد
   - أدخل: اسم العميل، القيمة المقدرة، التاريخ المتوقع
   - احفظ

2. **إنشاء عرض سعر من الفرصة:**
   - من صفحة تفاصيل الفرصة
   - اضغط "إنشاء عرض سعر"
   - ✅ تحقق من نسخ البيانات تلقائياً

3. **قبول وتحويل:**
   - قبول عرض السعر
   - اضغط "تحويل إلى فاتورة"
   - ✅ يجب إنشاء فاتورة جديدة
   - ✅ الفرصة تتحدث إلى "ربح"

### اختبار الترحيل المحاسبي

1. **إنشاء فاتورة:**
   - المبيعات → الفواتير → جديد
   - أضف أصناف
   - احفظ

2. **ترحيل الفاتورة:**
   - من صفحة تفاصيل الفاتورة
   - اضغط زر "ترحيل محاسبياً"
   - ✅ يجب ظهور رسالة نجاح

3. **مراجعة القيد:**
   - المحاسبة → القيود اليومية
   - ابحث عن آخر قيد
   - ✅ تحقق من:
     - مدين: حساب العملاء
     - دائن: إيرادات المبيعات
     - دائن: ضريبة القيمة المضافة (إن وجدت)

### اختبار Pagination

1. اذهب إلى **المبيعات** → **الفواتير**
2. إذا كان لديك أكثر من 50 فاتورة:
   - ✅ يجب رؤية أرقام الصفحات
   - ✅ جرّب التنقل بين الصفحات
3. جرّب تغيير عدد العناصر (25/50/100/200)

### اختبار المخزون السالب

**إذا ضبطت `ALLOW_NEGATIVE_INVENTORY=0`:**

1. أنشئ منتج بكمية محدودة (مثلاً: 10)
2. حاول بيع كمية أكبر (15)
3. ✅ يجب ظهور رسالة خطأ: "الكمية المتوفرة في المخزن غير كافية"
